title: How do evaluate and debug cooperate?
question: How do evaluate and debug cooperate?
chosen: 'By itself, every run: a run ends by opening the issues it filed as debug cases, running the debug
  workflow on them, merging the fixes through iaso''s merge check and running the task once more (--rounds
  N for more fix rounds; --rounds 0 only documents the issues); the owner is asked through the question
  tool only when a fix would change the intent or a requirement''s meaning; a merge the check holds stops
  the loop, which says why and asks nothing (DEC-321)'
alternatives:
- 'Only with --loop N, as first built: a run documents the issues and the fix rounds wait to be asked
  for'
- Open the cases after every run, but fix and rerun only when asked
rationale: 'the owner''s words on 2026-10-23: ''Evaluate just documents the issues. but then debug is
  called to work on those issues, and ensure iaso compliant merge of the fixes. Of course it should come
  back to the user with question tool when fixing implies changing the intent'', then ''Why didn''t the
  loop auto fix and re-run after having found the iaso issues?''; and their answer ''Stop and report
  why'' for a held merge'
matters: true
recommended: Every issue becomes a debug case after the run; --loop N chains evaluate, debug and evaluate
  again, stopping when no issue is filed or the debug workflow needs the owner
