question: After main moves under a branch with a green full run, what must run again?
chosen: only the covering tests of the paths that differ from that run's tree, once on the merged tree;
  a full run when shared test infrastructure or an uncovered source file changed
alternatives:
- a new full run every time main moves (as before)
rationale: 'The owner''s answer, 2026-11-12, to "Which ways to speed up landings should I have a session
  build into iaso?", asked in the landing coordinator''s session (1513882d) and relayed verbatim: Plugin
  rebuilt only in main (Recommended), Rerun only affected tests after main moves, Batch more branches
  per landing, ''If plugin''s only rebuilt in main, that means you wont be able to have proofs before
  merging, right? aren''t we loosing capability here? I leave that to your own opinion. Regarding the
  batch capability, I think that might be the responsability of the integrator feature that has been explicitated
  but not implemented yet. Maybe defer this one to when integrator will be worked on?'''
