---
id: INT-100
title: Ended sessions' folders are removed at the next landing
quote: End-of-session hook
readback: When a session closes, iaso marks its .iaso/session/<id>/ folder as ended; the next landing
  removes every marked folder that holds no waiting question (INT-114, SR-340), never its own session's
  and never an unmarked one.
will:
- a SessionEnd hook writes ended.json (the time) in the session's folder
- a resumed session's SessionStart removes its ended.json
- the landing's 'sessions' step removes marked folders that hold no waiting question and names how many
wont:
- no cleanup of folders from sessions that ended before this change
- no age-based deletion
assumptions:
- a folder that cannot be removed (a file still open) stays for the next landing, and so does one that
  still holds a waiting question
mode: incremental
