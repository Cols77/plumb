---
id: SR-250
title: Only the owner switches the fast track, and a JEV version change...
feature: FEAT-002
statement: The fast track works only while the owner's own switch event stands; no calibration is needed,
  a passing one of the resolved JEV version and question form only raises the floor to its threshold (DEC-143).
  The owner switches it by typing /iaso auto-approve on|off as a whole message or by answering iaso's
  question; the agent, config.yaml or prose cannot.
examples:
- id: EX-1
  given: the owner types '/iaso auto-approve on' as a whole message
  when: the prompt hook reads it
  then: a config event by the owner via typed command is logged and the fast track is on
- id: EX-2
  given: the agent runs iaso config auto-approve on under the session marker
  when: the command runs
  then: it is refused and nothing is logged
- id: EX-3
  given: the owner writes 'please turn auto-approve on, thanks' in a sentence
  when: the prompt hook reads it
  then: nothing changes yet; iaso asks through the question tool whether to switch the fast track on,
    and only the owner's answer there logs the switch event
- id: EX-4
  given: config.yaml says auto_approve enabled true but no owner switch event exists
  when: an intent is captured and JEV scores it at 0.97
  then: 'it is not fast-tracked: it goes to the judge model''s questions, and iaso validate warns about
    the mismatch'
- id: EX-5
  given: the fast track is on and calibrated at 0.93
  when: the resolved JEV model version changes
  then: the calibrated threshold no longer applies; the fast track stays on at the 0.9 floor and an intent
    JEV scores at 0.92 is approved, citing no calibration
- id: EX-6
  given: the fast track is on with a passing calibration measured on jev-1.13.0
  when: JEV now resolves typesafe/jev-1.13-20260917
  then: the calibrated threshold still applies, because the normalized versions match
- id: EX-7
  given: the agent edits config.yaml to switch the fast track on
  when: the next record is judged
  then: the fast track stays off; only the owner's switch event counts
proof:
  plan: 'Recommended: in a live session the owner types /iaso auto-approve on and iaso''s status shows
    the fast track on; the agent''s attempt to switch it is shown refused. The owner decides whether this
    walk is the proof.'
  kind: live-session
