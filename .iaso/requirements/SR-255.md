---
id: SR-255
title: Each turn's changes are verified by targeted covering tests, not...
feature: FEAT-001
statement: For the files a turn changes, iaso selects the tests that executed a changed function plus
  the changed requirement's linked tests, read from a grep-able test map; import closure only where no
  recorded test executed the code, saying so; a changed file no test executes or imports gets a bounded
  sample and sets full verification pending, as a change to shared test infrastructure does. Documentation
  selects nothing, and an empty selection runs nothing. Evidence is pinned to tree, import closure, test
  source and environment and reused only on an exact match. At turn end the stop hook asks the agent once
  to run the selection, in parallel, within a time limit the owner can raise; a run cut by the limit keeps
  what finished as evidence. Where the test map cannot be built within the hook's limit (a fresh clone),
  coverage counts as unknown and full verification pending.
examples:
- id: EX-1
  given: a change to one function in src/iaso/approvals.py that 12 tests executed when recorded
  when: iaso selects tests for the change
  then: those 12 tests and the tests linked to the requirement the function implements are selected, not
    the 424 tests whose imports reach approvals.py
- id: EX-2
  given: a new function no recorded test has executed
  when: iaso selects tests
  then: it falls back to the import closure for that file and says the function has no recorded test
- id: EX-3
  given: verify.workers set to 2 and pytest-xdist installed
  when: the selected tests run
  then: they run on two workers
- id: EX-4
  given: a test marked @pytest.mark.sr("SR-003")
  when: iaso tests map runs
  then: test_map.txt has a line mapping SR-003 to that test
- id: EX-5
  given: a test that imports iaso.links
  when: iaso tests map runs
  then: src/iaso/links.py maps to that test
- id: EX-6
  given: a test passed with recorded evidence
  when: nothing in its closure, source or environment changed
  then: the evidence is reused and the test is not run
- id: EX-7
  given: the same test
  when: a module it imports changes
  then: the evidence is not reused and the test is selected
- id: EX-8
  given: only docs/concept.md changed
  when: covering tests are selected
  then: nothing is selected
- id: EX-9
  given: pyproject.toml changed beyond its [project] version line (SR-254 EX-24)
  when: covering tests are selected
  then: status says full verification pending and no full run starts
- id: EX-10
  given: a changed file that no test executes or imports
  when: covering tests are selected
  then: a bounded sample is selected and full verification pending is set
- id: EX-11
  given: a selection whose real run time exceeds its estimate and hits the hard limit
  when: the run times out
  then: the tests that finished before the limit are recorded as evidence and the next selection allows
    for the observed pace
- id: EX-12
  given: a repository whose test map is not built and cannot be built within the hook's time limit (a
    fresh clone)
  when: a turn changes src code and the stop hook (or iaso turn end, or a Codex or Hermes stop) runs
  then: the regression check of this turn's runs still runs and, as SR-373's one next action, comes before
    the covering tests; the summary says full verification pending (coverage unknown), and the map is
    built outside the hook
- id: EX-13
  given: a turn that changed src/iaso/links.py
  when: the stop hook runs
  then: it asks the agent once to run the covering tests; the hook itself runs no test
- id: EX-14
  given: the owner raised the covering-test time limit in the settings
  when: a large selection runs
  then: it runs up to the new limit, and its progress shows while it runs
- id: EX-15
  given: a computed selection that is empty
  when: the agent runs the covering tests
  then: no test runs; the whole suite is never run in its place
