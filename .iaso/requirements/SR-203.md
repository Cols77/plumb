---
id: SR-203
title: iaso explain answers in plain words about a feature, a behaviour...
feature: FEAT-007
statement: '/iaso explain (alias why) takes plain words or a repository path, never an id: words resolve
  to the best-matching records, a path to the requirements that own it. It answers with each record''s
  title, state, the owner''s quote, its examples and their test state, in the owner''s terms; when two
  records match equally it describes both and picks neither; a file no requirement owns is said to be
  uncovered. The command''s argument hint offers plain words.'
examples:
- id: EX-1
  given: any build
  when: the owner asks /iaso why the invoices are rounded
  then: it gives the same answer as /iaso explain the invoices are rounded
- id: EX-2
  given: a requirement titled "Invoice totals are rounded to the cent"
  when: the owner asks /iaso explain how are invoice totals rounded?
  then: it answers with that requirement's title, state, the owner's quote, its examples and their test
    state, not a neighbouring requirement
- id: EX-3
  given: two requirements match "the export" equally
  when: the owner asks about the export
  then: both are described by title in the owner's terms and iaso picks neither
- id: EX-4
  given: billing.py is owned by a requirement and orphan.py by none
  when: the owner asks /iaso explain billing.py, then /iaso explain orphan.py
  then: the first answers with the owning requirement by title; the second says no requirement covers
    that file yet
- id: EX-5
  given: iaso is installed for Claude Code
  when: the /iaso command's argument hint is read
  then: it offers plain words ("explain <a feature, a behaviour or a file>"), never "<ID>"
proof:
  plan: 'Recommended: in a live Claude Code session the owner asks /iaso explain about a behaviour in
    their own words, about a file, and about a word two requirements share; each answer names the requirements
    by title, and the shared word gets both described with none chosen. The owner decides whether this
    is the proof.'
  kind: live-session
