id: SR-345
title: A scripted owner model answers the agent's questions from the...
statement: When the agent's reply ends waiting for the owner (a question through the question tool, or
  a plain question in its reply), a scripted owner (a cheap model given the task's hidden brief and the
  owner's role, never the code) answers it, and the answer is sent as the next owner message, as long
  as the agent asks; when --max-exchanges N is named, a question beyond the N-th exchange of a request
  counts as unanswered in the score and the next scripted request is sent. The scripted owner's answers
  are logged in the transcript as owner messages.
examples:
- id: EX-1
  given: the agent asks which board size the game should have
  when: the turn ends
  then: the scripted owner answers from the brief (a 3 by 3 board) and the answer is the next owner message
- id: EX-2
  given: --max-exchanges 3 and the agent asks a fourth question on the same request
  when: the turn ends
  then: it is not answered, the score counts one unanswered question and the next scripted request is
    sent
- id: EX-3
  given: the agent's reply asks nothing
  when: the turn ends
  then: the next scripted request is sent and the scripted owner is not called
- id: EX-4
  given: the scripted owner is asked
  when: it answers
  then: it sees the brief, the question and the agent's reply, never the scratch repository's code
- id: EX-5
  given: no exchange limit and the agent asks five questions on one request
  when: each turn ends
  then: the scripted owner answers all five and nothing counts as unanswered
