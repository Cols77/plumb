---
id: SR-400
title: A debug work copy is made without the committed log
statement: 'A work copy iaso makes to fix one of its own problems has none of the tracked log entry files,
  so the copy is about the size of the code alone; iaso commands still run in it, and what they build
  there (the cache) is its own and small. A work copy made before this rule is reused as it is, and is
  slimmed only by iaso debug prune --slim: that removes the log folder and the copy''s own cache from
  a copy with no uncommitted change and no fixer running on its case, and only files git can restore.'
examples:
- id: EX-1
  given: a repository whose tracked log holds thousands of entry files
  when: iaso makes the work copy for a debug case
  then: the copy holds the code and the records but none of the tracked log entry files
- id: EX-2
  given: a work copy made without the log
  when: a iaso command runs in it
  then: the command works and the cache it builds there is the copy's own and small
- id: EX-3
  given: a work copy made before this rule, with its full log
  when: iaso reuses it for its case
  then: it is reused as it is and not rebuilt
- id: EX-4
  given: a work copy made before this rule, with its full log and its own cache, no uncommitted change
    and no fixer running on its case
  when: the owner runs iaso debug prune --slim
  then: the copy loses its log folder and its cache, git status there stays clean and the branch is untouched;
    a copy with an uncommitted change or a running fixer is skipped and named
proof:
  plan: in a scratch project with a large tracked log, make a debug work copy and see that it has no log
    entry files, uses the main cache, and is far smaller than a full checkout
  kind: command
  evaluator: true
evidence:

    selfdebug._worktree has no .iaso/log, 0 log entry files, keeps .iaso config/claims, git status clean,
    total ~2.7 KB vs 9 MB for the main log alone. EX-2: `iaso status --root <copy>` returned 0 and built
    a cache of the copy''s own (.iaso/cache, real directory, not a symlink, 738 bytes). EX-3: a pre-rule
    full-log copy (plain git worktree add) was returned by _worktree at the same path with all 3000 log
    files intact. EX-4: `iaso debug prune --slim` slimmed the pre-rule copy (log folder and cache gone,

    so I set selfdebug.FLOOR_GB=0 in my script only. The proof plan says the copy ''uses the main cache'',
    but the statement and EX-2 say the cache is the copy''s own; the tree matches the statement and EX-2.'
