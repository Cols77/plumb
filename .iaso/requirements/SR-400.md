---
id: SR-400
title: A debug work copy is made without the committed log
statement: A work copy iaso makes to fix one of its own problems has none of the tracked log entry files,
  so the copy is about the size of the code alone; iaso commands still run in it, and what they build
  there (the cache) is its own and small. A work copy made before this rule is left as it is.
examples:
- id: EX-1
  given: a repository whose tracked log holds thousands of entry files
  when: iaso makes the work copy for a debug case
  then: the copy holds the code and the records but none of the tracked log entry files
- id: EX-2
  given: a work copy made without the log
  when: a iaso command runs in it
  then: the command works and the cache it builds there is the copy's own and small
- id: EX-3
  given: a work copy made before this rule, with its full log
  when: iaso reuses it for its case
  then: it is reused as it is and not rebuilt
proof:
  plan: in a scratch project with a large tracked log, make a debug work copy and see that it has no log
    entry files, uses the main cache, and is far smaller than a full checkout
  kind: command
  evaluator: true
evidence:

    is clean. The whole copy is about 3.4 KB of files, against about 12 MB for the main log alone. EX-2:
    `iaso status --root <copy>` ran fine; it built a cache of its own in the copy (.iaso/cache, a real
