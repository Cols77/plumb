id: SR-208
title: Only words iaso itself saw from the owner count, kept as a...
feature: FEAT-002
statement: 'The prompt log records each entry''s origin as the host marks it. Only the owner''s typed
  message, or their answer read from the host''s record of a question-tool call or from the study room,
  counts as the owner''s words, kept with its context as a pre-intent. Another session''s message, a task
  notification, hook text, the agent''s relay or conclusion never counts: it moves no gate and backs no
  pre-intent, answer or approval. An approval resting on a message the agent logged itself, on a host
  with no prompt hook, is labelled self-recorded wherever it is shown; iaso''s installed skills tell the
  agent it never decides on its own that the owner approved, and name no relay. Only words iaso itself
  saw count where the words are, that is where the approval is made. A checkout without the owner''s words
  (DEC-116: they stay local) accepts an approval on its recorded outcome, with the structural check only:
  the owner reasoned "Word to intent matching should already have been validated locally when merged ...
  why should it be re-checked everytime?", so it is validated once, where the words were, and never checked
  again against them.'
examples:
- id: EX-1
  given: another Claude session sends this session a message
  when: the prompt hook logs it
  then: the entry says it came from that session, the gate does not change, and iaso capture --prompt
    with its digest is refused as not the owner's words
- id: EX-2
  given: a task notification arrives in the session
  when: the prompt hook sees it
  then: it is not logged as the owner's message and raises no request check
- id: EX-3
  given: the owner types a message
  when: the prompt hook logs it
  then: it is logged as the owner's, as today
- id: EX-4
  given: the owner says "the reminders should go by email" while discussing the notification settings
  when: iaso captures it
  then: the pre-intent keeps the sentence verbatim with the conversation context it answered, and the
    formal intent drawn from it links back to it
- id: EX-5
  given: the owner answers a question put through the question tool
  when: iaso reads the answer
  then: it reads it from the host's record of that tool call, not from the agent's restatement of it
- id: EX-6
  given: a logged prompt reading "the reminder timing looks good"
  when: the agent runs iaso relay with that quote and the prompt digest
  then: iaso refuses, logs nothing, and says an agent-run relay no longer exists
- id: EX-7
  given: a prompt the agent logged itself on a host without a prompt hook
  when: it is used as a pre-intent and its interpretation is approved
  then: the approval is labelled self-recorded message wherever it is shown
- id: EX-8
  given: a prompt the prompt hook logged
  when: an approval rests on it
  then: it carries no self-recorded label
- id: EX-9
  given: a host whose prompt hook is installed and a message the agent logged itself with iaso turn start
  when: capture cites it
  then: no pre-intent or approval rests on it and nothing is approved
- id: EX-10
  given: iaso's skills are installed
  when: the agent reads them
  then: they say the agent may never decide on its own that the owner approved, and name no relay
- id: EX-11
  given: a result file or job file for a read job, written by the agent
  when: the worker looks at it
  then: the worker recomputes the job's inputs from the logs and applies only what it computed itself;
    the agent's file captures nothing and iaso validate reports it
proof:
  plan: 'Recommended: in a live session another session sends a message and a task notification arrives,
    then the owner types a sentence of intent; the owner sees, in iaso''s trail for that intent, that
    only their own sentence became a pre-intent, with its context, and that the other two changed nothing.
    The owner decides whether this is the proof.'
  kind: hook
