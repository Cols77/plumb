id: SR-270
title: The study room draws a question's diagram safely above it
feature: FEAT-007
statement: When a question references a diagram file inside the project, the room shows its extracted
  SVG above the question with readable labels, a text alternative and zoom; a missing, invalid, oversized
  or escaping diagram is replaced by a fallback line with the answers still usable, and a diagram's script
  never runs in the room.
examples:
- id: EX-1
  given: a question references a diagram-mod HTML file with toolbar icons
  when: the question is opened
  then: the architecture SVG is shown above the question with readable labels, a text alternative and
    zoom
- id: EX-2
  given: a diagram is missing, invalid, oversized or its path escapes the project
  when: the question is opened
  then: a clear fallback line is shown and the answer options stay usable
- id: EX-3
  given: a diagram file containing a script
  when: it is drawn
  then: only its SVG is shown; the script never runs in the room
proof:
  plan: 'Recommended for the owner to decide: the owner opens a question whose diagram holds a script
    and one whose diagram is missing; the first shows the drawing with no script run, the second a fallback
    line, and both can be answered.'
