title: An old project is detected and converted to .iaso; only .iaso is...
statement: Only .iaso is a supported records folder. When the agent finds an old-name project, it detects
  it and converts it to .iaso (folder, record text, links and settings), then works on the converted project.
examples:
- id: EX-1
  given: a repository whose records are in the old-name folder
  when: the agent runs iaso status
  then: iaso says it is an old project and converts it to .iaso; the same records and status show afterwards
- id: EX-2
  given: an empty repository
  when: iaso init runs
  then: records live in .iaso/ and no old folder appears
- id: EX-3
  given: this repository's own records
  when: the converter runs on them
  then: the repository holds .iaso/ and no file mentions the old product name

  plan: An independent evaluator converts a copy of an old-name project and checks the records, status
    and a grep for the old name
