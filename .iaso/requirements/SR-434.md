---
id: SR-434
title: The owner's standing choice makes the evaluator check every proof
statement: 'The owner can switch on a standing choice that the independent evaluator checks every proof,
  and switch it back. While it is on, no loop asks the proof-evaluator pick question, a proof''s evaluator
  pick needs no answer of the loop, and iaso runs the evaluator for each delivered proof at the end of
  a build and at landing. Only the owner switches it: in their own terminal (iaso config evaluator always|ask)
  or by typing /iaso evaluator always|ask; an agent''s command, or a config file, switches nothing. Off
  is the earlier rule: the evaluator is offered at each proof question.'
examples:
- id: EX-1
  given: the owner switched the standing evaluator choice on
  when: an intent loop reaches its proof question for a requirement
  then: the question does not offer the evaluator as a pick, and the evaluator checks the proof when it
    is shown working
- id: EX-2
  given: the standing choice is on and the owner answered no proof question in this loop
  when: the agent records the evaluator for a proof
  then: it is accepted, without an answer of the loop
- id: EX-3
  given: the standing choice was never switched on, or the owner switched it back
  when: the agent records the evaluator for a proof the owner did not pick in this loop
  then: it is refused, as before
- id: EX-4
  given: the standing choice is on
  when: a proof agreed as shown after landing has landed
  then: the evaluator checks it and the owner is not asked
- id: EX-5
  given: an agent runs iaso config evaluator always, or edits config.yaml to say so
  when: iaso reads the choice
  then: the choice stays as the owner left it
- id: EX-6
  given: the standing choice is on
  when: the owner types /iaso evaluator ask
  then: the evaluator is offered at each proof question again

    return
