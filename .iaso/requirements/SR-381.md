---
id: SR-381
title: A hook starts iaso with the platform's own venv interpreter first
statement: When a repository's .venv holds both or either layout, the plugin's hooks and panel try Scripts/python.exe
  first on Windows and bin/python first on every other OS
examples:
- id: EX-1
  given: a Linux machine whose repository .venv holds only bin/python
  when: the panel looks for iaso's interpreter
  then: it runs .venv/bin/python
  quote: support both windows and linux
  prompt: 546335cc35de6aad
- id: EX-2
  given: a Linux machine whose repository .venv holds both Scripts/python.exe (copied from Windows) and
    bin/python
  when: a iaso hook starts
  then: it runs .venv/bin/python, not the Windows executable
- id: EX-3
  given: a Windows machine whose .venv holds Scripts/python.exe
  when: a iaso hook starts
  then: it runs .venv/Scripts/python.exe as before
proof:
  plan: on Linux, reload plugins and see iaso's panel start instead of 'failed to start .venv/Scripts/python.exe'
  kind: live-session
