id: SR-246
title: Code is judged against its requirements edge by edge, weakest...
feature: FEAT-005
statement: For a scope along existing links (intent, feature, requirement, example, test, code, evidence),
  iaso builds a fidelity packet with a fingerprint, names empty families as gaps, asks the judge cascade,
  never the coding agent, one question per edge and lists edges weakest first, never creating, removing
  or marking an edge. With no judge, edges are listed unjudged with the cause.
examples:
- id: EX-1
  given: a requirement with its second example linked to no test
  when: the scope is aligned
  then: it reports the gap "<requirement>/EX-2 has no test"
- id: EX-2
  given: the judge answering no for the requirement-to-code edge
  when: the scope is aligned
  then: that edge is listed first and every link state is unchanged
- id: EX-3
  given: no judge set up
  when: the scope is aligned
  then: 'every edge is listed as unjudged with no score, it prints "judging unavailable: no judge", and
    the gap is still reported'
- id: EX-4
  given: a requirement with implemented_by and verified_by links
  when: its fidelity packet is built
  then: the packet holds the statement, examples, linked file contents and test evidence
- id: EX-5
  given: a fidelity edge JEV scores below its threshold
  when: the edge is judged
  then: the judge model judges it; the coding agent that wrote the code does not
- id: EX-6
  given: the owner asks in plain words whether the code still does what a requirement says
  when: the agent answers
  then: it runs the alignment on that requirement itself; the owner never types a command or an id
proof:
  plan: 'Recommended: in a scratch repository with one requirement whose example has no test and a judge
    scripted to answer no on its code edge, the owner asks in plain words whether the code still does
    what the requirement says; the agent''s answer names the gap and the weakest edge first, and the status
    shows every link unchanged. The owner decides whether this is the proof.'
