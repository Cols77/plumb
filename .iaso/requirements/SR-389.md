title: iaso names the model of a stage by one of four capability levels

  workflows), the stage names one of four capability levels: Haiku-like, Sonnet-like, Opus-like, Fable-like.
  The model of each level is a setting, so a model that is not Anthropic''s can fill a level; unset, the
  levels are Haiku, Sonnet, Opus and Fable.'

  then: the stage's agent runs on Sonnet

  when: it starts a stage at that level
  then: the stage's agent runs on the model given

  when: iaso's self-fix starts its fix stage

  when: iaso reads its settings
  then: it refuses the setting and names the four levels
