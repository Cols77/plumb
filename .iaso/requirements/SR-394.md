id: SR-394
title: An idle loop is reopened in a new interactive session when the...
statement: 'For an intent loop no session works on, the owner''s press on its row in the loops pane, or
  the same asked of the agent of any session, opens a new interactive Claude Code session in its own window,
  named after the loop, on the loop''s branch. The new session takes the loop over (the old session''s
  copy is marked handed over) and starts from iaso''s brief of the loop: its goal, the step it is at,
  what is done and what is left, its records, its plan and its branch. The old conversation is not resumed.
  No session opens without the owner''s press. The press is answered at once: iaso says it is opening
  the session, and pressing again while it opens opens no second one. A loop that already has a live session
  is not offered. When no window can be opened, iaso says so, gives the command that opens the session
  by hand, and changes nothing.'
examples:
- id: EX-1
  given: an idle intent loop at build with 3 of 4 plan items built
  when: the owner presses reopen on its row
  then: a new interactive Claude Code session opens in a window on that loop's branch, named after the
    loop, and its first turn starts from the loop's goal, its step, the item left, its records and its
    plan
- id: EX-2
  given: the new session has opened on the loop
  when: the loops are listed
  then: the loop is live at the new session, and the old session's copy says handed over
- id: EX-3
  given: seven idle loops and no press of the owner
  when: any time passes
  then: no session opens
- id: EX-4
  given: a loop with a live session
  when: its row is shown
  then: reopening is not offered
- id: EX-5
  given: an idle loop that was opened in the main checkout and has no branch of its own
  when: it is reopened
  then: the session opens in a new worktree made for it, since main's checkout refuses edits
- id: EX-6
  given: the owner tells the agent of a session to reopen the idle card-store loop
  when: the agent runs iaso's reopen command on it
  then: the same new session opens, as from the pane
- id: EX-7
  given: no terminal window can be opened on this machine
  when: the owner presses reopen
  then: iaso says so, gives the command that opens the session by hand, and the loop stays idle and untouched
- id: EX-8
  given: the owner presses reopen on an idle loop's row and its window takes a few seconds to appear
  when: the press is made, and the owner presses again before the window shows
  then: iaso says at once that it is opening a new session on that loop, the row reads opening a new session,
    and the second press opens nothing more; a failed open can be pressed again
