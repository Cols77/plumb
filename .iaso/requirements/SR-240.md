---
id: SR-240
title: The judge's premise is found wherever the owner's words were logged
feature: FEAT-008
statement: The judge reads the owner's message from the main checkout's session log in any worktree of
  the repository, and from the worktree's own log too, the latest entry of a digest winning; a checkout
  that is not a worktree reads only its own log; a fresh clone with no session log judges against the
  record's pre-intent. Nothing is copied between logs.
examples:
- id: EX-1
  given: a fresh clone with no session log and a record whose pre-intent holds the owner's sentence and
    its context
  when: the judge runs
  then: it judges the record against that pre-intent
- id: EX-2
  given: an intent whose prompt digest names a message the hook logged in the main checkout
  when: the judge runs in a worktree of that repository
  then: the premise is the whole message, as in the main checkout, and no line is copied into the worktree
- id: EX-3
  given: a worktree with its own session log holding a line the main checkout lacks
  when: a prompt is looked up
  then: both logs are read and the latest entry of a digest wins
- id: EX-4
  given: a checkout that is not a worktree
  when: a prompt is looked up
  then: only its own log is read
proof:
  plan: After the landing, in a live session in a worktree, the owner states a small intent; the judge's
    verdict on it is the same as in the main checkout and the worktree's log gains no copied line. The
    evaluator checks it from the session logs of both checkouts.
  kind: live-session
  post_merge: true
  evaluator: true
