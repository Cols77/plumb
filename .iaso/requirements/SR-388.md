id: SR-388
title: iaso's self-fix runs in separate stages, several cases side by side
statement: 'iaso''s self-fix of a debug case runs as separate stages by separate agents: a diagnosis that
  reads only and names the cause and the code path, a fix that writes the failing test and the change,
  and a review by an agent that did not write the fix and sees only the case, the change and the records
  it touches; iaso''s own checks then run as before. Each stage names a capability level, as already decided:
  the Sonnet-like level for the cause, the test, the fix and the review, and a round that failed is retried
  one level up. A round that fails hands the review''s and the checks'' findings to the next round. Open
  cases are worked side by side, each in its own worktree, up to the worker''s limit; only their test
  runs wait behind the one-heavy-job lock.'
examples:
- id: EX-1
  given: a planted defect in a iaso step
  when: the self-fix runs
  then: the case's log names three stages with the model of each, the diagnosis changed no file, and the
    review ran as a different agent run than the fix
- id: EX-2
  given: a fix whose test passes but does not exercise the cause the diagnosis named
  when: the review ends
  then: the round fails, nothing is committed, and the next round is given the review's finding
- id: EX-3
  given: 3 open cases and a limit of 2
  when: the background self-fix runs
  then: two cases are worked at once in their own worktrees and their test runs go one at a time
- id: EX-4
  given: three rounds that each failed the review or the checks
  when: the third ends
  then: nothing is committed and the case is a defect report naming the rounds, as before
- id: EX-5
  given: the same planted defects
  when: they are fixed the old way and the staged way
  then: the owner is shown, side by side, how many were fixed, in how many rounds and in what wall time
