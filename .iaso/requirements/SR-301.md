---
id: SR-301
title: A landing job never disturbs another intent loop
feature: FEAT-006
statement: 'The landing job writes only main''s tree and log: it never changes another branch or worktree,
  including a worktree''s uncommitted work, never removes a folder that holds a worktree, and never changes
  another session''s loop file or gate (but the folder of a session whose SessionEnd hook marked it ended
  and that holds no waiting question goes, SR-338); it keeps any document or record another in-flight
  branch or worktree changed until that work lands; its repins and compaction merge into an in-flight
  branch without conflict. Only a finished worktree, or an idle debug work copy (a debug work copy with
  no commit of its own, no uncommitted changes and no open problem), is removed at a landing.'
examples:
- id: EX-1
  given: a loop open in another worktree with its gate closed
  when: a different branch lands on main
  then: that worktree's gate and loop file are unchanged
- id: EX-2
  given: a superseded document that an in-flight branch changed
  when: the tidy runs at another landing
  then: the document stays until that branch lands
- id: EX-3
  given: the landing repinned links and compacted the log
  when: an in-flight branch later merges main
  then: git merges with no conflict and iaso validate is clean
- id: EX-4
  given: a document another worktree changed without committing
  when: the tidy runs at a landing that names it
  then: the document and the worktree's change stay
- id: EX-5
  given: a folder named for the tidy that holds a worktree
  when: the tidy runs
  then: the folder and the worktree stay
proof:
  plan: 'This work''s landing with the hand clean-up''s worktree still present: its files, loop and gate
    are unchanged afterwards.'
  kind: command
