id: SR-356
title: A fix counts only once proven in the plugin Claude Code runs
statement: A debug case is fixed only when its fix is in main, the plugin Claude Code loads runs that
  build, and the original symptom has been checked again live; until then it stays open as landed, not
  proven. When its symptom is seen again, the old case is reopened with its history and the owner is told
  it came back.
examples:
- id: EX-1
  given: a fix for answers dropped after a plugin upgrade is merged to main
  when: the session still runs the old cached plugin
  then: the case reads landed, not proven and is not closed
  quote: That shows a gap in the way iaso helps debugging and fixing issues
  prompt: 7de21ead90d4109e
- id: EX-2

  when: the same symptom appears in a later session
  then: the old case is reopened with its history and the owner is told it came back
