id: SR-379
title: The skills are one rulebook
statement: 'Each rule the agent follows lives in exactly one skill: iaso-records carries the per-message
  loop and the question rules, and every other skill and the /iaso command point to it; iaso-clarify
  triggers only when a request creates or changes intent or a spec session is accepted; a ten-line glossary
  defines band, room, loop pane, stale link, repin, relink, reword, intent conflict; no skill cites a
  record id; the question-pacing sentence appears once; the /iaso command grants no git command that
  deletes or commits, and the pre-tool and edit-check hooks time out at 10 s. Stage A of the intent loop
  runs in the main session; stages B and C may run as workflow phases once the owner opts in. The README
  is one page and the command reference is generated from the help text.'
examples:
- id: EX-1
  given: the five skills and the command
  when: their text is searched for the question rules
  then: the rules appear in iaso-records only and the others say where they are
- id: EX-2
  given: an ordinary tidy-up request
  when: skills are matched
  then: iaso-clarify does not trigger
- id: EX-3
  given: the word 'repin' in a skill
  when: the agent reads it
  then: the glossary defines it
- id: EX-4
  given: the /iaso command's allowed tools
  when: they are read
  then: git rm, git commit, git merge and git checkout --ours/--theirs are not pre-approved
- id: EX-5
  given: an intent loop in stage A
  when: a blocking question arises
  then: it is asked from the main session with the question tool, never from a workflow agent
- id: EX-6
  given: the README
  when: it is read
  then: it is one page and names no retired command
