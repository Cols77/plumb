---
id: SR-444
title: Codex hooks need no PATH lookup
statement: iaso hosts install codex writes each hook command with its program as an absolute path, so
  a Codex process with a narrower PATH than the installing shell still runs iaso's hooks
examples:
- id: EX-1
  given: uv is found at ~/.local/bin/uv when iaso hosts install codex runs
  when: the hooks are written
  then: each hook command starts with the absolute path of uv
- id: EX-2
  given: the venv launcher .venv/bin/python
  when: the hooks are written
  then: each hook command starts with the repository's absolute .venv/bin/python
- id: EX-3
  given: a Codex session whose PATH has no ~/.local/bin, as the app-server daemon under systemd
  when: the owner sends a message
  then: the prompt hook runs and logs the message via the hook
proof:
  plan: 'a fresh Codex session started with the daemon''s PATH logs its prompt via hook (before the fix:
    no record)'
  kind: hook
