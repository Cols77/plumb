---
id: SR-304
title: A pasted /iaso intent opens the loop
feature: FEAT-008
statement: When the owner's message is a paste that begins with /iaso intent or /iaso clarify, optionally
  followed by the owner's own words, iaso treats it as that command with the paste's words and the owner's
  words as the request. Other iaso commands still count only when typed.
examples:
- id: EX-1
  given: the owner pastes '/iaso intent keep iaso fit' and adds 'also fix the worktrees'
  when: intent open runs
  then: a loop opens with both parts as the request
- id: EX-2
  given: the owner pastes '/iaso auto-approve on'
  when: iaso reads it
  then: it is not taken as the command
- id: EX-3
  given: a paste whose text only mentions /iaso intent in its middle
  when: iaso reads it
  then: no loop opens
proof:
  plan: The message of this loop, replayed, opens a loop.
  kind: command
