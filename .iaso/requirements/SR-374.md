id: SR-374
title: iaso tells the agent one table of insights by condition
statement: 'What iaso tells the coding agent is one table, condition to insight, that every hook reads
  and that nothing else prints: (1) at session start, resume or after compaction: the intent being worked
  on in one line (title, loop step, what is left), the questions waiting on records its own branch changes
  (SR-361), the open known issues, the records changed since the agent last saw them; (2) at each message:
  the records the request touches that are new or changed, the intent being worked on when the message
  does not say it, another branch changing the same record; (3) at an edit: the requirement and examples
  the file serves, its covering tests, the links the edit made stale; (4) at a failing test: regression
  on confirmed behaviour or never passed, and the example it proves; (5) at a symptom matching a known
  issue: the issue with its fix or workaround; (6) before a commit or merge: what would hold it; (7) at
  turn end: the one next action; (8) when a check was cut or no judge is reachable: the skipped step,
  once. Each fact is said once per session per state; nothing when nothing applies. The agent gets the
  full picture of any condition on demand with one command, iaso context.'
examples:
- id: EX-1
  given: the conversation was compacted while an intent loop is open
  when: the next message arrives
  then: the agent is told the intent's title, the loop's step and what is left, in one line
- id: EX-2
  given: a message that does not name the intent being worked on
  when: the prompt hook runs
  then: the intent line is printed once; the next message that names it prints nothing
- id: EX-3
  given: the agent edits a file linked to a requirement
  when: the edit completes
  then: the agent reads the requirement's title, its examples, its covering tests and any link the edit
    made stale
- id: EX-4
  given: a test fails that never passed before
  when: the agent reads the result
  then: iaso says it is not yet passing and names the example it proves, and never calls it a regression
- id: EX-5
  given: the agent reports a symptom that matches an open known issue
  when: the prompt hook reads it
  then: the known issue, its cause and its fix or workaround are printed once
- id: EX-6
  given: the agent is about to merge a branch
  when: it runs the merge check
  then: only what would hold the merge is printed
- id: EX-7
  given: a hook was cut by its budget
  when: it ends
  then: the skipped step is named once in the session
- id: EX-8
  given: the agent runs iaso context edit src/iaso/stop.py
  when: the command returns
  then: 'it prints the full picture of that condition: requirement, examples, tests, links, drift, in
    plain text'
- id: EX-9
  given: a session start in a repository with 400 proposed records and 150 stale links
  when: the brief prints
  then: it shows what changed since the agent last saw it and what blocks now, and no counts
- id: EX-10
  given: a vendored example file under a skill's vendor folder, owned by no requirement
  when: the trace runs
  then: it is listed as untraced like any other copied file (SR-353)
- id: EX-11
  given: a commit that changed one file
  when: the evidence of a test that covers other files is checked
  then: that evidence is still fresh
