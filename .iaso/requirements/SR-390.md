id: SR-390
title: One command lists every loop of the project from any session
statement: 'From any session of the project, in the main checkout or any of its worktrees, one iaso command
  lists every loop of the project: the intent loops of every session, the problems iaso is fixing itself
  and the evaluate runs. Each row gives the loop''s kind, what it is meant to achieve in plain words,
  its progress, what is left to do, what it waits for when it waits, and the branch it runs on. Loops
  with a live session come first; a loop nobody works on any more is listed below them as idle since its
  last activity. A finished loop is not listed. The command changes nothing.'
examples:
- id: EX-1
  given: session A in the main checkout has an intent loop whose clarify gate passed and whose plan has
    3 of 7 items written, and session B runs in a worktree
  when: B asks for the loops
  then: it lists A's loop with its intent's read-back as the goal, 'plan · 3/7', build and proven left,
    and the branch it runs on
- id: EX-2
  given: an intent loop opened in a worktree
  when: a session in the main checkout asks for the loops
  then: that loop is listed
- id: EX-3
  given: an intent loop still clarifying with no intent record written
  when: it is listed
  then: its goal is the owner's opening words, cut to one line
- id: EX-4
  given: an intent loop whose build has 3 of 4 plan items built
  when: it is listed
  then: what is left names the plan item not built and the proof not shown yet
- id: EX-5
  given: an intent loop whose gate refused, or that waits on the owner's answer
  when: it is listed
  then: its row says what it waits for
- id: EX-6
  given: an intent loop opened three weeks ago by a session that is gone
  when: the loops are listed
  then: it comes after the live loops, marked idle since that date
- id: EX-7
  given: a loop taken over by another session
  when: the loops are listed
  then: it is listed once, at the session that holds it now
- id: EX-8
  given: no loop of any kind
  when: the loops are asked for
  then: it says no loop is open
