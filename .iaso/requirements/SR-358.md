---
id: SR-358
title: An out-of-date iaso shows red in the band
statement: 'At every prompt of every session, iaso compares three builds of itself - the plugin the session
  runs, the main of iaso''s local clone when there is one, and the main of iaso''s repository (the one
  the plugin names) - and the band shows a red line for each misalignment naming both builds and the fix.
  The running plugin and local main are compared by their vendored source digest (the plugin behind local
  main or ahead of it or differing: reload plugins), and the plugin Claude Code installed, or local main
  when none is installed, is compared with the repository''s main by commit, as the local clone''s history
  orders them (behind: update the plugin and reload plugins, or pull main; ahead of it: push main). A
  build is named by its short digest or commit; the version (0.1.<commit count>, SR-377) may stand beside
  it (DEC-389). The band always shows the version of the plugin the session runs, whether the builds align
  or not. When the repository cannot be read the band says it could not check, not in red. Nothing is
  reinstalled or pushed by iaso.'
examples:
- id: EX-1
  given: iaso's repository main was rebuilt after Claude Code cached iaso
  when: the band draws
  then: it shows a red line with the running and the repository's builds and how to update
  quote: always ensure that claude code runs with the latest version of iaso, otherwise add a warning
    in red in the band
  prompt: 7de21ead90d4109e
- id: EX-2
  given: the red line shows
  when: the owner updates and reloads the plugin and the session runs the repository's build
  then: the line is gone
- id: EX-3
  given: local main was rebuilt after the session loaded the plugin
  when: the next prompt arrives
  then: the band shows the plugin behind local main, with both builds, and to reload plugins
- id: EX-4
  given: local main holds builds not pushed to iaso's repository
  when: the band draws
  then: it shows local main ahead of the repository with both builds and to push main
- id: EX-5
  given: iaso's repository cannot be read
  when: the band draws
  then: it says iaso could not check its repository, in a plain line, never red
- id: EX-6
  given: a session whose plugin is version 0.1.1717 and whose builds align, or whose repository cannot
    be read
  when: the band draws
  then: its first line shows 0.1.1717, with no red line
  quote: Yes, always show it
proof:
  plan: after landing, in a session on an older build, the band shows the red line; after a reload it
    is gone
  kind: live-session
  post_merge: true
