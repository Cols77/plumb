---
id: SR-284
title: The Hermes adapter writes iaso's block into the one context file...
feature: FEAT-004
statement: 'Hermes reads one context file, so the Hermes adapter writes iaso''s instruction block where
  Hermes looks: the first of .hermes.md and HERMES.md that exists, when it is nonempty; otherwise the
  first nonempty of AGENTS.override.md, AGENTS.md and CLAUDE.md, CLAUDE.md included although it is Claude
  Code''s file. An empty file is left unchanged, and no AGENTS file is created to shadow another. Uninstalling
  keeps a block in a file another host may share and explains why.'
examples:
- id: EX-1
  given: only a nonempty CLAUDE.md exists
  when: the Hermes adapter is installed
  then: CLAUDE.md receives the block with its text retained, and no AGENTS file is created
- id: EX-2
  given: a nonempty .hermes.md and a nonempty CLAUDE.md
  when: the Hermes adapter is installed
  then: .hermes.md receives the block and CLAUDE.md is unchanged
- id: EX-3
  given: an empty .hermes.md and a nonempty CLAUDE.md
  when: the Hermes adapter is installed
  then: CLAUDE.md is selected and the empty Hermes file remains unchanged
- id: EX-4
  given: an empty .hermes.md and a nonempty HERMES.md
  when: the Hermes adapter is installed
  then: HERMES.md and the empty .hermes.md are left untouched, and the block goes to the first nonempty
    of AGENTS.override.md, AGENTS.md and CLAUDE.md
- id: EX-5
  given: nonempty AGENTS.override.md and AGENTS.md exist
  when: the Hermes adapter is installed
  then: only AGENTS.override.md receives the block
- id: EX-6
  given: the Claude context file has a iaso block
  when: the Hermes adapter is uninstalled
  then: the block is kept and its shared or unknown ownership is explained
proof:
  plan: 'Recommended: in a scratch repository holding only a nonempty CLAUDE.md, the agent sets iaso up
    for Hermes and shows the owner the diff: the block added to CLAUDE.md, no AGENTS.md created. The owner
    decides whether this is the proof.'
