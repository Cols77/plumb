---
id: SR-226
title: The edit gate cannot be switched off by accident
feature: FEAT-001
statement: 'The edit gate is enforced wherever the session runs: a settings file that allows iaso''s
  hook command without running it, or a session started in a subfolder of an adopted repository, still
  has edits refused while the gate is closed; iaso''s plugin hooks stand down only for a legacy install
  that already runs iaso''s hooks, so nothing runs twice.'
examples:
- id: EX-1
  given: .claude/settings.json allows Bash(iaso hook prompt:*) but runs no iaso hook
  when: an edit tool is called while the gate is closed
  then: the edit is refused
- id: EX-2
  given: Claude Code started in src/ of an adopted repository
  when: an edit tool is called while the gate is closed
  then: the edit is refused
- id: EX-3
  given: a legacy install whose hook commands run iaso hook
  when: a hook fires
  then: the plugin's hook does nothing, so nothing runs twice
proof:
  plan: 'Recommended for the owner to decide: with the gate closed in a scratch repository, the owner
    starts Claude Code in its src/ folder and sees the agent''s edit refused.'
  kind: hook
