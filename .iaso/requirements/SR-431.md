title: New repositories keep their records in .iaso, old ones keep .iaso
statement: iaso init creates .iaso/; a repository that already has .iaso/ keeps using it unchanged, with
  no migration.

- id: EX-1
  given: an empty repository
  when: iaso init runs
  then: records live in .iaso/ and no .iaso/ appears
- id: EX-2
  given: a repository with .iaso/ and confirmed records
  when: iaso status runs
  then: the same records and status as before the rename are shown
