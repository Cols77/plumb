id: SR-413
title: The judge and build classes hold what is broken or set aside
statement: At every prompt iaso compares the three builds of itself as before and, when they are misaligned,
  the band shows one build chip in red; the build class of the pane lists each misalignment as a red row
  naming both builds, expanded to the fix. When iaso's repository cannot be read the build class says
  it could not check, never in red. When a judge is broken (it cannot run at all, such as a missing key)
  the band shows one judge chip in red and the judge class lists the judge with the exact cause in plain
  words, until it answers again. When a judge ran but could not settle a record, the judge class says
  so in plain colour with the cause, and no chip is red. A judge's question iaso set aside is a row of
  the judge class in plum, naming the question and expanded to why; it is never called unreachable. Nothing
  is reinstalled or pushed by iaso.
examples:
- id: EX-1
  given: iaso's repository main was rebuilt after Claude Code cached iaso
  when: the band draws
  then: it shows one build chip in red; the pane's build class shows the running and the repository's
    builds and how to update
- id: EX-2
  given: the owner updates and reloads the plugin
  when: the band draws again
  then: the build chip is gone
- id: EX-3
  given: iaso's repository cannot be read
  when: the owner opens the build class
  then: it says iaso could not check its repository, in plain colour, and the band's chip is not red
- id: EX-4
  given: the JEV key is missing and a record needs judging
  when: the band draws
  then: 'one judge chip in red; expanded in the pane: JEV judge, no key, with the variable it looked for'
- id: EX-5
  given: the judge answered with a one-option question iaso set aside
  when: the owner opens the judge class
  then: one row in plum names the question, expanded to why it was set aside; no row says no judge can
    be reached
- id: EX-6
  given: the judge ran on a record and could not settle it
  when: the band draws and the owner opens the judge class
  then: no chip is red; one plain row names the record and why the judge could not settle it

    the rows and their detail; after a reload the build chip is gone; screenshots as evidence'
