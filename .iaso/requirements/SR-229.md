---
id: SR-229
title: A big request's set is repaired by the agent until it is clean
feature: FEAT-007
statement: iaso checks a big request's set for structural gaps (a requirement with no example, a will
  against a won't) and hands each fixable gap to the agent, never to the owner, until the check is clean;
  a set that is not clean cannot be approved. A trade-off between the owner's own lines is the one thing
  asked, as one question that becomes a decision that matters.
examples:
- id: EX-1
  given: a big set where one requirement has no example
  when: iaso checks the set
  then: the gap goes to the agent, the agent adds the example, and the next check is clean
- id: EX-2
  given: a set whose will "email the reminders" goes against its won't "keep email addresses"
  when: iaso checks the set
  then: the owner is asked one question about that trade-off through the question tool, recorded as a
    decision that matters
- id: EX-3
  given: a set that is not clean
  when: approval of the set is sought
  then: it is refused, naming the gaps to the agent
- id: EX-4
  given: any gap the agent can fix
  when: the owner's views are drawn
  then: the owner never sees it
proof:
  plan: 'Recommended for the owner to decide: in a live session a big request whose set lacks an example
    is repaired by the agent with nothing shown to the owner, and a will against a won''t reaches the
    owner as one question.'
  kind: live-session
