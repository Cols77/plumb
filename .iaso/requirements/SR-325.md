---
id: SR-325
title: Every iaso failure opens a debug case at once
feature: FEAT-008
statement: 'When a iaso hook, job or command errors, a step refuses what a requirement says it handles,
  or a judge job fails for the third turn end in a row after retries with a larger budget each time (a
  failure of the environment, such as a usage limit reached, the claude command missing or the API down,
  is not the job''s failure and never counts toward the three), iaso writes one debug case (what failed,
  where, the log entry, state open) the moment it happens, in the background and without holding the turn;
  the turn-end line stays quiet about it. iaso debug lists the open cases and runs them on demand: it
  reruns each case''s step once, says what each did and what it still needs, and counts the cases open
  and resolved.'
examples:
- id: EX-1
  given: a iaso hook raises an error during a turn
  when: the error is caught
  then: one debug case is written with the error and its log entry, the turn is not held, and the turn-end
    line says nothing about it
- id: EX-2
  given: the repin step refuses a link it should handle (a decision pinned to a reworded requirement)
  when: the turn-end check runs
  then: one debug case is written naming the link and the refusal, and the owner is asked nothing
- id: EX-3
  given: three open cases
  when: the agent runs iaso debug
  then: each case's step is rerun once and the output lists each case as resolved, would resolve or open
    with why, and counts them
- id: EX-4
  given: a case whose rerun passes
  when: iaso debug finishes
  then: the case is marked resolved and the next iaso debug counts it resolved
- id: EX-5
  given: a judge job that failed at a turn end
  when: it is retried at the next turn end
  then: it runs with a larger budget than the last time; after its third failure in a row one debug case
    is written for it and the job is not queued again by the turn end; a failure of the environment (usage
    limit, claude missing, API down) counts for nothing, neither toward the three nor as a reset
