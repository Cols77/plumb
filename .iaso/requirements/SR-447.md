title: The owner drops an intent loop they no longer want
statement: iaso intent drop removes every copy of one open intent loop, in this checkout and the main
  checkout, so no new session reopens it, and releases the edit gate of the session that held it; it changes
  nothing when no loop or more than one loop matches.
examples:
- id: EX-1
  given: a loop taken over from session A by session B, with A's edit gate closed
  when: the owner drops it
  then: neither copy remains and A's gate is open
- id: EX-2
  given: two open loops of two sessions
  when: a drop names neither
  then: it says more than one matches and drops nothing; naming one session drops only that loop
