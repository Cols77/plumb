id: SR-362
title: The agent puts the judge's questions to you in your terms; nothing...
statement: 'The coding agent receives each judge question before the owner does and asks it in the owner''s
  terms, with no record id, merging questions that hinge on one principle. It asks every one: it never
  drops, answers, defaults or sends back a question itself. A point the owner already answered is not
  raised again: when the judge asks the same principle about the same record in new words, iaso sets it
  aside as answered, and the judge is told never to ask again what the owner''s answers already answered.
  An answer that leaves the point open, such as ''I don''t know'', is not asked right back but may be
  asked again in a later round.'
examples:
- id: EX-1
  given: a judge question naming SR-265 and its example
  when: the agent asks it
  then: the owner sees it in plain words about the turn-end line, with no id
- id: EX-2
  given: the owner answered a question on one principle about a record by picking one of its options
  when: the judge raises the same principle about that record in new words
  then: it is set aside as answered and the owner is not asked again
- id: EX-3
  given: the agent finds a question obvious, irrelevant or already answered
  when: it handles the question
  then: 'it asks it all the same: it can reword and merge, but has no way to drop it or send it back'
- id: EX-4
  given: the owner answered a question on one principle
  when: the judge raises a question on another principle about the same record
  then: that question is asked
- id: EX-5
  given: a judge question that still uses iaso's own words, such as a record number or 'settled'
  when: it reaches the agent
  then: it is marked for the agent to put in the owner's terms, with the key the agent needs to reword
    it; it is never set aside on the band for its wording
- id: EX-6
  given: the agent asked a judge question in its own words and registered that wording only afterwards
  when: it registers the wording
  then: the owner's earlier answer answers the judge's question, which is not asked again, and the judge
    reads that answer
- id: EX-7
  given: the owner answered a question with 'I don't know'
  when: the judge reads that answer
  then: it does not ask the same point right back; a later judge round may ask it again

    again in new words; the owner is not asked it, and the agent asks every question that does reach it
    without sending any back.'
