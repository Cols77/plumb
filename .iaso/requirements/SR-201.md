---
id: SR-201
title: A commit is warned, never held, when the judge says its diff does...
feature: FEAT-002
statement: At commit, the judge reads the diff against each requirement the commit's trailer claims; when
  it says the diff does not serve one, iaso prints a one-line warning and the commit goes through, the
  trailer check's result unchanged. With no judge it says judging is unavailable and warns nothing by
  rule.
examples:
- id: EX-1
  given: a commit claiming the requirement for reports that only changes src/app/report.py
  when: the commit-msg hook runs and the judge answers that the diff does not serve that requirement
  then: it prints one warning line naming the requirement and the commit goes through; the trailer check's
    result is unchanged
- id: EX-2
  given: no judge can be reached
  when: the diff-serves check runs for the same commit
  then: it prints one line that judging is unavailable, no warning decided by rule, and the commit goes
    through
proof:
  plan: 'Recommended for the owner to decide: in a scratch repository, the agent commits a change to the
    report module claiming an unrelated requirement; the commit goes through and its output carries one
    warning line naming that requirement.'
  kind: hook
