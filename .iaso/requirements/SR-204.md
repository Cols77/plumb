---
id: SR-204
title: Everything the owner reads speaks at the owner's level
feature: FEAT-007
statement: No text the owner sees (status, turn-end line, questions, /iaso answers, errors, merge and
  push reports, the study room) names a shell command, a record number without its title, a file or test
  name or an internal code; it names things by title and the owner's words and explains any needed idea
  first in one plain sentence. Owner quotes stay verbatim. Records the agent writes are checked and reworded
  before the owner sees them.
examples:
- id: EX-1
  given: a push carrying a requirement not yet approved
  when: the push check reports
  then: it names the requirement by its title, says iaso will ask through the question tool if anything
    needs the owner's arbitration, and names no command to run, no way to skip the check and no record
    number
- id: EX-2
  given: a merge where code tied to a requirement changed
  when: the merge report lists it
  then: it names that requirement by its title, any question for the owner comes through the question
    tool, and it names no command to run
- id: EX-3
  given: a turn that touched a decision
  when: the turn-end line is shown
  then: it names the decision by its question in plain words, never by its number alone
- id: EX-4
  given: the owner asks why a merge is held, and the answer needs the idea that iaso remembers the exact
    wording approved
  when: the agent or iaso answers
  then: the answer first says in one plain sentence that iaso remembers the exact wording approved and
    checks again when it changes, then uses it
- id: EX-5
  given: the README
  when: both checks (shell commands, inner workings) run on its owner sections
  then: they find nothing, and the agent's command reference sits in its own section
- id: EX-6
  given: the agent writes a requirement whose statement uses one of iaso's internal terms
  when: iaso records it
  then: iaso refuses it and tells the agent which words to put in the owner's terms; the owner is asked
    nothing
- id: EX-7
  given: a record quotes the owner's own words, and those words mention a command
  when: iaso records it
  then: the owner's words are kept exactly as the owner said them
- id: EX-8
  given: the owner asks what drifted, asks to see a requirement in full, or asks whether a requirement
    does what they meant
  when: the agent shows iaso's answer
  then: it names each requirement by its title and its examples in plain words, says what to do next in
    plain words or a /iaso command without an id, and shows no record number, fingerprint, folder or
    file name or command to run unless the owner asks for detail
- id: EX-9
  given: one record approved by the judge and one by the owner's own answer
  when: the owner asks about either
  then: it says "judge-approved" with its judge, model and score (SR-251) or "confirmed by you", never
    a bare "approved"
- id: EX-10
  given: the owner's Windows console, where piped output is cp1252
  when: the agent shows any iaso answer with glyphs
  then: the glyphs print as UTF-8 and the answer never fails on encoding, for every command iaso still
    has (triage is removed, SR-380)
proof:
  plan: 'Recommended: the two owner-text checks (shell commands, inner workings) run over every owner
    surface and pass; then in a live session the owner sees a held merge report, a turn-end line and a
    /iaso explain answer, each naming things by title with no command, id or file name. The owner decides
    which of these is the proof.'
  kind: command
