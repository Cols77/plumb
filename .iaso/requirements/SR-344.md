id: SR-344
title: iaso evaluate runs a task's scripted requests through a cheap...
statement: 'iaso evaluate <simple|complex> [--model haiku|sonnet] creates a fresh scratch repository
  (git init, iaso init, iaso hooks install), then sends the task''s scripted owner requests one per
  turn to a headless Claude Code session resumed between turns, loading the scratch repository''s own
  settings and the task''s brief for the agent appended to its system prompt. A run has no limit unless
  one is named: --max-turns N caps the agent''s turns per request, --max-minutes N the run''s time, --max-exchanges
  N the owner''s answers per request, and --no-limits runs without any; when none of these is given, nothing
  runs and the command says to ask the owner with the question tool. The run''s folder under .iaso/eval/runs/<stamp>-<task>-<model>/
  holds transcript.jsonl (every owner message and agent reply), score.json, issues.jsonl and a copy of
  the scratch repository''s .iaso/ records and log. Without the claude command or the model, it prints
  one line saying what is missing and runs nothing.'
examples:
- id: EX-1
  given: the claude command is on this machine
  when: iaso evaluate simple runs with a scripted model double
  then: a scratch repository is made with iaso set up, each of the task's requests is sent as one turn,
    and the run's folder holds transcript.jsonl, score.json, issues.jsonl and the copied .iaso/
- id: EX-2
  given: --model sonnet
  when: the run starts
  then: every agent turn is run with the sonnet model and the run's folder is named for it
- id: EX-3
  given: no claude command on this machine
  when: iaso evaluate simple runs
  then: one line says the claude command was not found and no scratch repository is made
- id: EX-4
  given: --max-turns 7 or --max-minutes 2 is named and a request's agent turns reach it
  when: the turn ends
  then: the request is marked capped in the transcript and the next request is sent
- id: EX-5
  given: neither a limit nor --no-limits is given
  when: iaso evaluate simple runs
  then: nothing runs and one line says the limits are the owner's choice, to ask with the question tool
- id: EX-6
  given: --no-limits
  when: the run starts
  then: no turn cap and no time limit is passed to the agent's session
