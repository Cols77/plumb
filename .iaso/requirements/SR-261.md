---
id: SR-261
title: A commit names the requirements it serves in a trailer, checked at...
feature: FEAT-003
statement: 'A commit message''s SR: trailer lines name the requirements the commit serves, in order. Once
  trailers are required, the commit-msg check rejects a message naming an unknown requirement or none,
  except a revert, merge or fixup message whose staged paths are all exempt.'
examples:
- id: EX-1
  given: require_trailer is true and git writes a revert, merge or fixup message for a commit whose staged
    paths are all exempt
  when: the commit-msg hook checks the message
  then: the commit is accepted without an SR trailer, and a plain message still needs one
- id: EX-2
  given: 'a commit message with the trailer line "SR: SR-003, SR-004"'
  when: the trailer is parsed
  then: SR-003 and SR-004 are claimed, in order
- id: EX-3
  given: require_trailer is true
  when: a commit message names SR-999, which does not exist
  then: the commit-msg check rejects it
proof:
  plan: 'Recommended for the owner to decide: in a scratch repository with trailers required, the agent
    commits once naming a requirement that does not exist (refused) and once with a valid trailer (accepted).'
  kind: hook
