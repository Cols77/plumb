id: SR-373
title: A turn ends with one next action for the agent and at most one...
statement: 'At a turn''s end iaso gives the agent exactly one next action chosen from what the turn changed:
  run the covering tests of the code it edited when they lack a fresh run; propose a requirement for a
  file no requirement owns; repin or relink the links it moved; or the judge''s questions when they block
  its next task. The owner gets one plain line only when something needs them (a regression on confirmed
  behaviour, a merge that waits, a question); otherwise only the status line moves. Inside an intent loop
  the band shows the step and nothing else is printed. There are no cards: nothing the owner reads and
  presses, no card store, no offers, no full-card text. Nothing is repeated once said in the session.
  In main''s checkout a stale link is not this next action: it is resolved on a branch (SR-384).'
examples:
- id: EX-1
  given: the turn edited code whose covering tests have no fresh passing run
  when: the turn ends
  then: the agent is told once to run those tests and nothing else
- id: EX-2
  given: the turn edited a file no requirement owns
  when: the turn ends
  then: the agent is told to propose a requirement for it at its next step
- id: EX-3
  given: the turn moved code so three links went stale
  when: the turn ends
  then: the agent is told to repin or relink those three links
- id: EX-4
  given: the turn edited nothing (an answer, a chat, a read)
  when: the turn ends
  then: iaso prints nothing and the status line is unchanged
- id: EX-5
  given: a test that passed on confirmed behaviour now fails
  when: the turn ends
  then: the owner sees one line naming the behaviour and the agent is told it is a regression
- id: EX-6
  given: an intent loop is open
  when: the turn ends
  then: the band shows the loop's step and nothing is printed to the owner
- id: EX-7
  given: the same next action was given earlier in the session and nothing changed
  when: the turn ends
  then: it is not repeated
- id: EX-8
  given: the stop hook's work would take longer than its budget
  when: the turn ends
  then: the read-back and the next action are printed within seconds and the rest is computed in the background
    and delivered at the next message
proof:
  plan: 'In a live session on this repository: a turn that edits code ends within seconds with one next
    action for the agent; a turn that edits nothing ends with no iaso output; the band and status line
    carry the rest.'
  kind: live-session
