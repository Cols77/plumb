id: SR-158
title: The agent can suggest how to resolve a conflict
statement: The agent can store a suggested resolution for a conflict (keep one side, or a combined version
  it proposes) with a one-line reason; the conflict card shows that option first, marked recommended,
  with the reason; the suggestion chooses nothing
examples:
- id: EX-1
  given: a merge conflict between main and feat-x on a requirement, where feat-x only fixes a typo main
    also has
  when: the agent suggests keeping feat-x's version because it only corrects the wording
  then: the card lists 'Keep feat-x's version' first, marked recommended, with that reason, and the conflict
    stays open until the owner presses
- id: EX-2
  given: the agent proposes a combined version and suggests it
  when: the card is drawn
  then: the combined version is first and recommended, with the agent's reason
- id: EX-3
  given: a conflict with no suggestion
  when: the card is drawn
  then: it shows no recommended option, as today
