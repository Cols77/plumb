---
id: SR-063
title: Every hook output is a deduplicated delta within a token budget
feature: FEAT-005
statement: All agent-facing lines from every hook and from the host-neutral API go through one emitter
  that drops a line already emitted this session for the same record, hash and state (or the same text),
  enforces the per-hook token budget (never cutting a must line, or a one-shot line whose source the hook
  consumed when it read it), names cut records with plumb show without marking them seen, and injects
  nothing when nothing is new; details come only through plumb show.
examples:
- id: EX-1
  given: 10 prompts about the same three unchanged records
  when: the prompt hook runs each time
  then: each record's line is injected once
- id: EX-2
  given: an untraced-change instruction already emitted for src/app/mul.py
  when: the next prompt hook runs with the path still untraced
  then: the instruction is not repeated
- id: EX-3
  given: SR-004 changed after its line was injected
  when: the next prompt mentions it
  then: its line is injected once more with the new state
- id: EX-4
  given: a queued untraced-change instruction for src/app/mul.py, whose note the hook consumes when it
    reads it, and relevant records that fill hooks.prompt_tokens
  when: the prompt hook runs
  then: the instruction is injected all the same; a one-shot line (queued instruction or escalation) is
    never cut by the budget
- id: EX-5
  given: the owner types the same words ("continue", "ok") in two turns of one session
  when: each turn's stop finds covering tests without fresh evidence, or each prompt follows a stated
    set
  then: each turn blocks once with the covering-tests instruction, and each prompt carries the relay line;
    a per-turn line is deduplicated within its turn, never for the whole session
