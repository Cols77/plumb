---
id: SR-077
title: A quick merge check holds open intent conflicts
feature: FEAT-006
statement: 'plumb check --merge and plumb merge-check list every open intent conflict as a card and wait
  for the owner''s choice (exit 4). /plumb init and plumb hooks install also install, by default, a quick
  merge-time check as git''s pre-merge-commit hook (R17): it holds a merge carrying an open intent conflict,
  a touched requirement not yet confirmed, a file no requirement declares or two records holding one ID,
  and it runs no test suite (the one full run happens at push, in the pre-push hook); a foreign hook is
  left untouched.'
examples:
- id: EX-1
  given: a merge result with IC-001 open
  when: plumb check --merge main runs
  then: it exits 4 and shows the conflict card
- id: EX-2
  given: the pre-merge-commit hook is installed
  when: git merge produces IC-001
  then: git does not record the merge commit and the output names the conflict and /plumb conflicts
- id: EX-3
  given: a foreign pre-merge-commit hook
  when: the install runs
  then: the foreign hook is untouched and the output says how to call plumb from it
- id: EX-4
  given: the quick merge check is installed
  when: git merge runs on a branch whose tests were never run
  then: the check reports what holds the merge without starting any test run
- id: EX-5
  given: a repository adopted with /plumb init
  when: git hooks are listed
  then: the quick merge check is installed and the full test run stays at push
- id: EX-6
  given: a merge held by IC-001
  when: the owner chooses a side and the touched requirements are confirmed
  then: the quick check passes and the merge can be finished
- id: EX-7
  given: JEV is configured and a merge leaves IC-001 open
  when: the pre-merge-commit or the pre-push hook shows its card
  then: no judgment is requested and nothing is written to the log; the card shows a judgment only when
    one is already logged
- id: EX-8
  given: a repository adopted with /plumb init or plumb hooks install
  when: git hooks are listed
  then: the quick merge check and the pre-push hook (the one full test run) are both installed, and a
    pre-push hook plumb did not write is left untouched
