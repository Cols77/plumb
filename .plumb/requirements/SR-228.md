---
id: SR-228
title: A big request gets the intent loop suggested once, in one line
feature: FEAT-007
statement: 'plumb suggests the intent loop once, in one line and never as a question, for a big request:
  more than 3 requirements, more than one feature, a contradicted confirmed record, shared surfaces, hard-to-undo
  effects, two open decisions that matter, or a diff past 400 lines or 10 files. A declined suggestion
  is not repeated for that intent.'
examples:
- id: EX-1
  given: a prompt matching records of FEAT-001 and FEAT-003
  when: the escalation check runs
  then: it suggests the intent loop in one line with the reason "touches 2 features", never as a question
- id: EX-2
  given: a turn whose diff has 450 changed lines and no approved set
  when: the turn ends
  then: the agent is told in one line that the intent loop is suggested, with the reason 'diff past 400
    lines'
- id: EX-3
  given: the owner declined the suggestion for an intent
  when: the same trigger fires again for that intent
  then: no suggestion is shown and an escalation-declined event exists
proof:
  plan: 'Recommended for the owner to decide: in a live session the owner asks for a change touching two
    features and sees the one-line suggestion once; declining it, the owner does not see it again for
    that intent.'
  kind: live-session
