title: The question tool by default; a card only for a complex decision,...
statement: 'plumb''s skills tell the agent to ask with Claude Code''s question tool by default, and to
  use a card only for a complex decision: one whose answer must change the owner''s records (confirm,
  conflict, stale link, a decision that matters) or that has more than one option with a real trade-off
  or a costly wrong pick; the card shows the full context and the pros and cons of each option, so the
  owner can study it'
examples:
- id: EX-1
  given: the agent needs to know which of two files the owner meant
  when: it follows the skill
  then: it asks with the question tool
  quote: Make sure that question tool are prefered usually unless cards make sense
  prompt: 1b4f94eb55289dea
- id: EX-2
  given: a merge conflict on a record
  when: the agent follows the skill
  then: it leaves the conflict on its card and does not ask with the question tool
- id: EX-3

  when: the agent follows the skill
  then: a card, with both ways, what each costs and what it keeps, so the owner can study it
  quote: Cards are only for complex decisions to make, allowing to see tradeoffs, context presented fully,
    and allowing the user to really study the pros and cons
  prompt: 16346cb668cf73ed
