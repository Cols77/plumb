id: SR-211
title: The owner arbitrates a conflict through a question, with the...
feature: FEAT-006
statement: A conflict between two versions of intent is put to the owner as one question through the question
  tool, or in the browser study room when there is more to study. The agent may store a suggested resolution
  (one side, or a combined version) with a one-line reason; it is shown first, marked recommended, and
  chooses nothing. plumb reads the owner's answer, or a chat reply that clearly picks a version, by meaning;
  the agent never relays it.
examples:
- id: EX-1
  given: a merge conflict between main and feat-x on a requirement, where feat-x only fixes a typo main
    also has
  when: the agent suggests keeping feat-x's version because it only corrects the wording
  then: the question lists "Keep feat-x's version" first, marked recommended, with that reason, and the
    conflict stays open until the owner answers
- id: EX-2
  given: the agent proposes a combined version and suggests it
  when: the question is drawn
  then: the combined version is first and recommended, with the agent's reason
- id: EX-3
  given: a conflict with no suggestion
  when: the question is drawn
  then: it shows no recommended option
- id: EX-4
  given: 'an open merge conflict on a requirement and the owner replies in chat: keep feat-x''s version'
  when: plumb reads the message
  then: the requirement takes feat-x's version, the conflict closes citing the owner's words, and nothing
    was run by the agent
- id: EX-5
  given: the same conflict
  when: the agent runs plumb conflict relay, or conflict choose with a quote, with the owner's words
  then: it is refused with exit 3 and nothing is chosen
- id: EX-6
  given: 'the owner replies: keep feat-x''s version but change the title'
  when: plumb reads the message
  then: feat-x's version is chosen, and the title change is reworded by the agent into an edit that goes
    through the judge cascade; the owner is not asked again
- id: EX-7
  given: the same conflict
  when: the owner picks "Keep main's version" in the question tool
  then: main's version is chosen
- id: EX-8
  given: the skills and the command's allowed tools
  when: they are read
  then: no conflict relay, quoted choose or typed choose command is named
- id: EX-9
  given: a conflict whose two versions need diagrams to compare
  when: plumb puts it to the owner
  then: it is offered in the browser study room with its diagrams, and the answer there closes it
- id: EX-10
  given: a merge brings two versions of one requirement
  when: the owner is asked
  then: one question through the question tool (or the study room) shows both versions and what each means,
    with 'keep this one', 'keep the other' and 'both' as options
proof:
  plan: 'Recommended: two worktrees change the same requirement differently and are merged; the owner
    sees one question in the question tool with the agent''s recommended version first and its reason,
    picks one, and sees the merge proceed citing their answer. The owner decides whether this is the proof.'
  kind: live-session
