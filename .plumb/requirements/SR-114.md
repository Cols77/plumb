id: SR-114
title: 'The repin check is a cascade: JEV clears the easy links, Sonnet...'
statement: 'For a stale link whose tests pass, JEV is asked first whether the change leaves what the requirement
  relies on as it was; above a threshold set on the labelled repin set with no false repin, the link is
  repinned without asking Sonnet. Otherwise Sonnet judges with the requirement and the diff, and its unchanged
  verdict repins. When Sonnet says the change matters, Opus investigates instead of judging again: it
  checks the requirement against its intent and the change against the turn that made it (SR-113), and
  prepares either a rewording of the record, the change sent back to development, or a card asking the
  owner to decide, saying what is wrong in plain words.'
examples:
- id: EX-1
  given: an edit adds a new command to commands.py and JEV gives 0.9 that SR-003's repin path is untouched,
    above the calibrated threshold
  when: the link is resolved
  then: it is repinned on JEV's answer and Sonnet is not asked
- id: EX-2
  given: JEV gives 0.4 for SR-009's brief link
  when: the link is resolved
  then: Sonnet judges it with the requirement and the diff; on unchanged it is repinned
- id: EX-3
  given: Sonnet says SR-081 changed because the heuristic it describes was removed
  when: the link is resolved
  then: Opus finds SR-081 disagrees with INT-029 and proposes the rewording; it is not sent back to development
- id: EX-4
  given: Sonnet says SR-038 changed, SR-038 agrees with INT-029, and the change came from a turn about
    cold-start timing
  when: Opus investigates
  then: it sends the change back to development with that turn and the broken example
- id: EX-5
  given: Opus cannot tell whether the change was wanted
  when: it investigates
  then: the owner gets a card naming the intent, the requirement, the change and what is unclear, with
    suggested options
- id: EX-6
  given: no labelled set has set JEV's threshold yet, or JEV is unreachable
  when: a link is resolved
  then: JEV is skipped and Sonnet judges; nothing is repinned on a guess
