---
id: SR-188
title: a retired example keeps no test
statement: 'a retired example keeps no test: when a record is superseded, the tests that verified its
  examples are unlinked, and a test that then covers no live example is dropped; the superseding record
  keeps only the tests of what it states'
examples:
- id: EX-1
  given: SR-002 supersedes SR-001 and SR-001/EX-1 is still verified by tests/test_a.py, which SR-002 does
    not verify
  when: plumb validate runs
  then: 'it warns [retired-example] that SR-001/EX-1 is retired by SR-002 but still verified by tests/test_a.py
    and says to retire the test too: unlink it, and drop it when it covers nothing else; it never says
    to move the test to SR-002 or to keep SR-001'
- id: EX-2
  given: the owner confirmed SR-001, SR-002 supersedes it, and SR-001#3 is the only test of SR-001 EX-2
  when: plumb unlink SR-001#3 --note "DEC-065" runs
  then: 'the link is removed: a superseded record''s example is retired, so the only-test refusal does
    not protect it'
- id: EX-3
  given: a test function whose sr markers name only superseded records and that no live record links to
  when: its retired examples are unlinked
  then: the test function is deleted (the whole file when nothing live remains); a test a live record
    still links to stays and only loses the retired id from its marker
- id: EX-4
  given: SR-001 has two tests verifying EX-1, tests/test_a.py and tests/test_b.py, and SR-002 supersedes
    it verifying neither
  when: plumb validate runs
  then: both links are warned, one per link, not only the last one
- id: EX-5
  given: a commit with trailer SR-001 that unlinks tests/test_a.py from SR-001 and deletes the file
  when: plumb claims check runs over it
  then: 'tests/test_a.py is declared: a path a claimed record linked in the commit''s parent counts, since
    a deleted file can no longer be linked'
proof:
  plan: plumb validate on the worktree prints no retired-example warning and the 36 old links are gone;
    plumb claims check --range main..HEAD lists no undeclared path although the commits delete test files
  kind: command
