---
id: SR-329
title: The landing job commits main's uncommitted shared log entries
feature: FEAT-006
statement: At each landing the tidy commit also takes every uncommitted entry of a shared log kind in
  main's checkout, whichever session wrote it; local kinds stay ignored, and judgment entries go to their
  archive segment instead (SR-376). A merge into main no longer counts main's own uncommitted shared entries
  as a hold.
examples:
- id: EX-1
  given: 820 uncommitted shared entries in main written by three sessions
  when: a branch lands
  then: the landing's tidy commit holds all of them and git status under .plumb/log is clean of shared
    kinds
- id: EX-2
  given: uncommitted verdict and gate entries in main
  when: a branch lands
  then: they stay ignored and uncommitted
- id: EX-3
  given: uncommitted shared entries in main
  when: a branch is merged into main
  then: the merge check does not hold it for them
- id: EX-4
  given: a shared entry written in main after the tidy commit started
  when: the next landing runs
  then: that landing commits it
proof:
  plan: 'The next real landing: main''s checkout shows no uncommitted shared entry after it.'
  kind: command
