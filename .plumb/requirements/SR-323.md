---
id: SR-323
title: Local log entries already committed leave the tree once
feature: FEAT-006
statement: One commit removes from the tree every committed entry of a local kind, keeping them on disk
  where they are and in git history; nothing else in the repository changes.
examples:
- id: EX-1
  given: about 22,000 committed entries of local kinds
  when: the removal commit lands
  then: git ls-files under .plumb/log lists none of them and the files are still on disk
- id: EX-2
  given: the removal commit
  when: plumb validate runs
  then: it reports no log error
proof:
  plan: The log's file count in the tree before and after the landing.
  kind: command
