---
id: SR-343
title: plumb's own failures start the debug workflow by itself, and a...
statement: When plumb's execution shows a defect in plumb itself, the debug workflow starts on its own,
  separately from the owner's work, and when its fix lands the session that detected it is released
examples:
- id: EX-1
  given: a defect in plumb's outcome is detected in a session
  when: it is detected
  then: a debug case runs in the background without the owner asking
  quote: when an issue is found in the outcome of plumb execution, it automatically improves itself
- id: EX-2
  given: the debug fix for that case is merged
  when: it lands
  then: the session that detected the issue is released
  quote: once the plumb debug workflow outcome is merged, it should unlock the current session that detected
    the issue
- id: EX-3
  given: a landing whose step fails or that finds validate errors, a stale link and a judge question
  when: the landing ends
  then: the failed step and the validate errors open debug cases queued for the background self-debug
    job; the stale link and the judge question stay with the agent at its next turn
  quote: Defects bg, records agent
- id: EX-4
  given: a self-fix committed on its debug branch whose review passed
  when: the agent's next prompt arrives
  then: its plumb line names the debug branch as ready to land through the normal merge check; plumb itself
    never merges it and the owner is not asked
  quote: Land it like any branch
- id: EX-5
  given: a debug case opened in a session that kept working
  when: the case's fix branch is in main
  then: that session's next plumb line says the defect it hit is fixed and what to retry; no other session
    is told and nothing held the session meanwhile
  quote: Keep working, told when fixed
- id: EX-6
  given: the owner or the agent notices a wrong result, not a crash
  when: they run plumb debug report with what they saw in words
  then: a debug case opens with those words and the session, and the same background self-debug job is
    queued
  quote: Anyone flags it
proof:
  plan: a detected defect opens a case, runs, lands, and the session is released
  kind: other
