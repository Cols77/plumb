---
id: SR-051
title: The pre-push hook runs plumb merge-check
feature: FEAT-003
statement: plumb merge-check --install-pre-push writes a git pre-push hook running merge-check in hook
  mode against the remote ref (or the merge base with the default base for a new branch) and exits with
  the report's code; a foreign pre-push hook is left untouched and reported; --uninstall-pre-push removes
  only plumb's hook; plumb init and plumb hooks install install it by default with the quick merge check
  (R17; the merge runs no tests because the one full run happens at push).
examples:
- id: EX-1
  given: a repository with a foreign pre-push hook
  when: plumb merge-check --install-pre-push runs
  then: the foreign hook is unchanged and the command reports it
- id: EX-2
  given: plumb's pre-push hook and a branch whose report exits 4
  when: git push runs
  then: the push is refused
