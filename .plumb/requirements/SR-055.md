---
id: SR-055
title: plumb hosts install pi writes a thin Pi extension
feature: FEAT-004
statement: plumb hosts install pi renders a TypeScript extension that maps Pi's session start, input,
  tool result and agent end events to plumb hook calls, shows owner lines and the status in Pi, sends
  a block at most once, and registers the /plumb command, with no dependency beyond Pi's extension API
  and Node.
examples:
- id: EX-1
  given: a repository
  when: plumb hosts install pi runs
  then: the rendered extension names each mapped event and the plumb hook commands
- id: EX-2
  given: a stop output with a block and stop_active true
  when: the extension handles agent end
  then: no follow-up message is sent
- id: EX-3
  given: the Pi adapter installed, and the agent's shell with the environment it gives (the marker pi
    where the adapter sets it, none otherwise) and no terminal
  when: the agent runs plumb approve SR-001 with "y" piped on stdin
  then: it exits 3 and no approval is written
- id: EX-4
  given: the extension not loaded (an untrusted project)
  when: plumb hosts status pi runs
  then: 'it prints "no session marker on this host: owner-only commands require an interactive terminal"
    with the trust model, says where prompts come from, and counts the confirmations resting on a self-recorded
    message (R13 Q4)'
