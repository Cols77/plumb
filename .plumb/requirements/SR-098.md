id: SR-098
title: A mixed answer list confirms its yes items
statement: plumb's reader reads the owner's whole message and gives each record shown its own answer (accepted,
  rejected, change asked, or open); no relay confirms the yes items of a mixed answer list.
examples:
- id: EX-1
  given: 'the owner''s words "INT-006: yes. INT-013: no. INT-016: We don''t want token budget."'
  when: 'the agent relays INT-006 quoting "INT-006: yes"'
  then: INT-006 is confirmed
- id: EX-2
  given: the same words
  when: the agent relays INT-016
  then: 'it is refused: the owner''s words ask to change INT-016'
- id: EX-3
  given: 'the owner''s words "INT-006: yes. Actually I''d rather sleep on all of this."'
  when: the agent relays INT-006
  then: 'it is refused: a reservation that names nothing holds back every record'
- id: EX-4
  given: the owner's words "INT-016:" at the end of one line and "We don't want token budget" at the start
    of the next
  when: the agent relays INT-016
  then: 'it is refused: the correction is placed on INT-016 across the line break'
- id: EX-5
  given: the owner's words "Confirm SR-097, SR-098, INT-24"
  when: the agent relays SR-098
  then: 'SR-098 is confirmed: a mistyped ID (INT-24) is neither an objection nor a plain-words reference
    to other records'
