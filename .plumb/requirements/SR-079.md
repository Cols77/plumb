---
id: SR-079
title: Awareness reads other worktrees read-only, cheaply and cached
feature: FEAT-006
statement: Each worktree's hooks publish the records its branch is changing to its own gitignored .plumb/cache/changing.json,
  recomputed only when its HEAD or its changed paths moved; other worktrees read those files and git's
  worktree and ref files directly, never writing into another worktree, taking a lock or holding a lease;
  branches without a worktree are scanned at session start only, within a time cap, and cached by branch
  tip; the overlap check adds at most 50 ms to a warm hook.
examples:
- id: EX-1
  given: five other worktrees
  when: the prompt hook computes overlaps with warm caches
  then: it takes under 50 ms and starts no git process
- id: EX-2
  given: a branch whose tip has not moved since the last scan
  when: a session starts
  then: no git command runs for that branch
- id: EX-3
  given: another worktree
  when: the awareness check runs
  then: no file in that worktree is created or modified
- id: EX-4
  given: a worktree that was removed while its changing.json path is still recorded
  when: the check runs
  then: that worktree is ignored
