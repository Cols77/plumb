---
id: SR-049
title: Claims, links and confirmed-example tests hold the merge
feature: FEAT-003
statement: plumb merge-check holds the merge with exit 1 when a commit's changed paths are not declared
  by its claimed SRs, when a touched record has a stale or dangling link, or when log integrity fails,
  and with exit 5 when a confirmed example's acceptance test fails or lacks a pass on the current code;
  the precedence stays 1, then 5, then 4.
examples:
- id: EX-1
  given: a commit claiming SR-004 that changes an undeclared path
  when: plumb merge-check main runs
  then: it names the path with the fix and exits 1
- id: EX-2
  given: a touched SR whose implemented_by link is stale
  when: plumb merge-check main runs
  then: it names the moved end and plumb repin and exits 1
- id: EX-3
  given: a confirmed example whose acceptance test fails and an unconfirmed touched record
  when: plumb merge-check main runs
  then: it exits 5
- id: EX-4
  given: require_trailer is true and git writes a revert, merge or fixup message for a commit whose staged
    paths are all exempt
  when: the commit-msg hook checks the message
  then: the commit is accepted without an SR trailer, and a plain message still needs one
