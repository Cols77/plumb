id: SR-043
title: The plumb-clarify skill scales clarification to the request and asks only what matters
feature: FEAT-002
statement: plumb installs a plumb-clarify skill, written for plumb, that the agent loads whenever a request
  creates or changes intent; it chooses trivial, incremental or escalated depth and asks only questions
  whose answer changes what gets built. Per SR-131 it raises at most one blocking choice card per turn
  (asked with the question tool by default), turns a gap with a recommended answer into a labelled assumption,
  and stops asking once the owner says go or ok; a choice answer confirms nothing by itself. It ends by
  recording the read-back as proposed records next to the code (plumb capture), so clarifying and recording
  are one step. plumb clarify gives it the depth and drops drafted questions that records or defaults
  already answer.
examples:
- id: EX-1
  given: a request that maps to confirmed SR-004 with no flag
  when: plumb clarify runs
  then: depth is trivial and no question is returned
- id: EX-2
  given: the ambiguous request "let users export their data" and four drafted questions, one answered
    by a confirmed record and one whose options build the same thing
  when: plumb clarify --questions runs
  then: exactly the two questions that matter are returned, ranked
- id: EX-3
  given: two decisions that matter recorded from questions asked outside a card
  when: the next stop hook runs
  then: only the first is asked in that message
- id: EX-4
  given: a request with two gaps, one with a better-supported answer
  when: the agent clarifies it
  then: the supported answer becomes a labelled assumption and only the other gap is raised, as one blocking
    choice card; the agent asks nothing more in that message
