title: The installer sets up hooks, status line, guard and commit hook idempotently
feature: FEAT-001
statement: plumb hooks install writes the hooks, the status line, the session marker, the deny rules,
  the skill, the CLAUDE.md block and the git commit-msg hook, and running it twice changes nothing.

  when: plumb hooks install runs twice

  when: the agent runs plumb approve
  then: a deny rule and the session marker refuse it
