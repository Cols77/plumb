---
id: SR-189
title: A worktree judges against the prompt log of its main checkout
statement: The hook logs the owner's prompts in the main checkout's .plumb/session/prompts.jsonl; a worktree
  of the same repository finds that log through git's common directory, so calibration, judge jobs, repins
  and captures run in a worktree see the owner's whole logged message exactly as the main checkout does
examples:
- id: EX-1
  given: an intent whose prompt digest names a message the hook logged in the main checkout
  when: plumb jev calibrate runs in a worktree of that repository
  then: the intent's premise is the whole message, as in the main checkout
  quote: Try to find the question that answers globally to the questions you have
  prompt: 1b1e36e84c989a38
- id: EX-2
  given: the same worktree
  when: plumb capture --prompt <digest> runs there
  then: the prompt is found without copying any line into the worktree
- id: EX-3
  given: a worktree with its own prompts.jsonl holding a line the main checkout lacks
  when: a prompt is looked up
  then: both logs are read and the latest entry of a digest wins
- id: EX-4
  given: a checkout that is not a worktree
  when: a prompt is looked up
  then: only its own log is read, as today
proof:
  plan: 'a scratch repository with a logged prompt and a worktree of it: run plumb capture and the premise
    check from the worktree and show the whole message found'
  kind: command
