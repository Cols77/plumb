---
id: SR-030
title: A confirmed example's acceptance test cannot change, or be rewritten to pass, unseen
feature: FEAT-001
statement: An owner approval of a requirement pins the content hash of each verified_by end. A confirmed
  requirement whose verified_by end changed since then is an unconfirmed edit ("acceptance test changed")
  in plumb status, plumb drift, the stop summary and plumb validate --merge, which waits for the owner
  (exit 4) and shows the test's diff next to the example it verifies. A recorded regression is resolved
  only by a pass on the test body that passed before it; a pass after the test was changed marks it hidden,
  and a hidden regression of a confirmed example is a regression question in the stop hook and holds the
  merge (exit 5) until the original test passes again or the owner confirms the change.
examples:
- id: EX-1
  given: confirmed SR-001 with EX-1 "given a=1 and b=2 ... then it returns 3" verified_by tests/test_mod.py,
    a passing full run, then add() changed to subtract and the run reporting the regression
  when: the agent rewrites the test to assert add(1, 2) == -1, it passes, and plumb validate --merge BASE
    runs
  then: it lists SR-001 as "(acceptance test changed)" with EX-1 and the test diff, lists the failing
    acceptance test as "regression, hidden", and exits 5
- id: EX-2
  given: the same turn
  when: the stop hook runs
  then: it blocks once with "regression hidden" naming SR-001 EX-1, and the summary lists the changed
    acceptance test and the question instead of "questions none"
- id: EX-3
  given: the same change
  when: plumb status and plumb drift run
  then: both name SR-001's changed acceptance test and the hidden regression
- id: EX-4
  given: a confirmed acceptance test extended with a new passing test, no regression
  when: plumb validate --merge BASE runs
  then: SR-001 waits as "acceptance test changed" and the merge exits 4 until the owner confirms it
- id: EX-5
  given: a regression on test body h1
  when: a pass comes on test body h2, then a pass on h1
  then: the first pass marks it hidden; only the pass on h1 resolves it
