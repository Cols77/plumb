id: SR-156
title: Answers to the question tool are kept as the owner's words
statement: When Claude Code's question tool returns the owner's answers, plumb logs each question, the
  options shown and the answer as the owner's words for the session; such an answer never confirms, rejects
  or changes a record
examples:
- id: EX-1
  given: the agent asks 'Run the slow tests now or later?' with the question tool
  when: the owner picks 'later'
  then: plumb's log holds that question, both options and 'later' as the owner's answer in this session
  quote: Then yes for 1
  prompt: 1b4f94eb55289dea
- id: EX-2
  given: the owner's question-tool answer says 'yes, confirm SR-005'
  when: it is logged
  then: 'SR-005 is not confirmed: only a card press or the owner''s typed command confirms'
- id: EX-3
  given: the owner dismisses the question without answering
  when: the tool returns
  then: nothing is logged as an answer
proof:
  plan: 'a live session: the agent asks with the question tool, the owner answers, plumb log shows the
    entry and no record changes'
  kind: live-session
