---
id: SR-020
title: A regression is a previously passing test that now fails
feature: FEAT-001
statement: A regression is an existing test node that previously passed (or passed flaky) with recorded
  evidence and now fails, even if its source changed since; only a new test that starts red is exempt,
  shows as not yet passing and never interrupts.
examples:
- id: EX-1
  given: tests/core/test_links.py::test_pin_drift passed with recorded evidence
  when: it now fails
  then: it is a regression and the owner is asked
- id: EX-2
  given: a new test written test-first
  when: it fails on its first run
  then: it is not yet passing, not a regression, and nothing interrupts
- id: EX-3
  given: a test that passed with recorded evidence and whose source was then edited
  when: it now fails
  then: it is still a regression, noted test source changed since the pass
