id: SR-362
title: The agent puts the judge's questions to you and pushes back on the...
statement: The coding agent receives each judge question before the owner does and asks it in the owner's
  terms, with no record id, merging questions that hinge on one principle. When a question looks obvious
  or already answered by the owner's words, the agent sends it back to the judge with its reason; the
  judge withdraws it, quoting what answers it, or keeps it, and only a kept question is asked. The agent
  never drops, answers or defaults a question itself; every push-back and its outcome is logged.
examples:
- id: EX-1
  given: a judge question naming SR-265 and its example
  when: the agent asks it
  then: the owner sees it in plain words about the turn-end line, with no id
- id: EX-2
  given: the owner answered the same thing an hour earlier in the session
  when: the judge raises the question
  then: the agent sends it back quoting that answer, the judge withdraws it, and the owner is not asked
- id: EX-3
  given: the agent sends a question back as obvious and the judge disagrees
  when: the judge rules
  then: the question is kept and asked, its meaning unchanged
- id: EX-4
  given: the agent finds a question irrelevant
  when: it handles the question
  then: it cannot drop it; only the judge's withdrawal removes it, and the log shows the push-back and
    the ruling
