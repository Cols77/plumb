---
id: SR-391
title: Each problem plumb is fixing itself is a row of the loop list
statement: 'In the loop list, the debug loop is one row per problem plumb is fixing itself: the symptom
  in plain words as what is to be achieved, where its fix stands (open, fix being written, tests, landed,
  checked live) and what is left before it is fixed. A problem that needs the owner says so. A resolved
  problem is not listed.'
examples:
- id: EX-1
  given: a problem whose fix is written and whose tests are running
  when: the loops are listed
  then: its row gives the symptom in plain words, the fix written and the tests running, and landing and
    the live check as left
- id: EX-2
  given: a problem whose fix is in main and not yet checked live
  when: the loops are listed
  then: its row reads landed, not checked live, with the live check left
- id: EX-3
  given: a problem plumb could not put right, ending as a defect report or a question to the owner
  when: the loops are listed
  then: its row says it waits for the owner
- id: EX-4
  given: a problem resolved and proven
  when: the loops are listed
  then: it is not listed
proof:
  plan: 'Before landing: with a problem open and one landed but not checked live, the command lists both
    with symptom, fix state and what is left.'
  kind: command
