---
id: SR-392
title: Each evaluate run is a row of the loop list
statement: 'In the loop list, the evaluate loop is one row per evaluate run still going: the task and
  the model, what the run measures as what is to be achieved, the round it is at of the rounds asked,
  the problems it filed, and what is left. A run that stopped on a held merge says why. A run that ended
  is not listed; its score stays in its run folder.'
examples:
- id: EX-1
  given: plumb evaluate simple with two fix rounds asked, in its first fix round
  when: the loops are listed
  then: its row reads simple, the model, round 1 of 2, the problems filed so far, and the fix round and
    the rerun as left
- id: EX-2
  given: an evaluate run stopped because the merge of a fix is held
  when: the loops are listed
  then: its row says it stopped and why
- id: EX-3
  given: an evaluate run that ended with its score written
  when: the loops are listed
  then: it is not listed
proof:
  plan: 'Before landing: while an evaluate run is going, the command run from another session lists it
    with its task, model, round and what is left.'
  kind: command
