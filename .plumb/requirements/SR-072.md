---
id: SR-072
title: The merge check reports ID collisions
feature: FEAT-006
statement: plumb check --merge and plumb merge-check on a merge result report every ID collision (two
  records with one ID, or a record file left unmerged because both sides added it) with exit 1 and the
  plain fix "/plumb merge-fix", in the same report as the other merge-boundary checks, also when they
  run as the pre-merge-commit or pre-push hook.
examples:
- id: EX-1
  given: a merge result in which two record files both declare SR-070
  when: plumb check --merge main runs
  then: it exits 1, names both files and says /plumb merge-fix fixes it
- id: EX-2
  given: an in-progress merge with a requirement file both sides added
  when: the merge check runs on it
  then: it exits 1 with the collision named
- id: EX-3
  given: merge-fix has renumbered the collision
  when: the check runs again
  then: no collision is reported
