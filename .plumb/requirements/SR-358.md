id: SR-358
title: An out-of-date plumb shows red in the band
statement: When the plumb build Claude Code runs differs from main's build (the vendored source digest),
  the band shows a red line saying plumb is older than main, built when, and to reload plugins, until
  the session runs the current build. Nothing is reinstalled by plumb.
examples:
- id: EX-1
  given: main's plugin was rebuilt after Claude Code cached plumb
  when: the band draws
  then: it shows the red older than main line with how to fix it
  quote: always ensure that claude code runs with the latest version of plumb, otherwise add a warning
    in red in the band
  prompt: 7de21ead90d4109e
- id: EX-2
  given: the red line shows
  when: the owner reloads plugins and the session runs main's build
  then: the line is gone
proof:
  plan: after landing, in a session on an older build, the band shows the red line; after a reload it
    is gone
  kind: live-session
  post_merge: true
