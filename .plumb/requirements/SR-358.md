---
id: SR-358
title: An out-of-date plumb shows red in the band
statement: At every prompt of every session, plumb compares three builds of itself by their vendored source
  digest - the plugin the session runs, the main of plumb's local clone when there is one, and the main
  of plumb's repository (the one the plugin names) - and the band shows a red line for each misalignment
  naming both builds by their short source digest, with the version (0.1.<commit count>, SR-377) beside
  the digest when it is shown (DEC-389), and the fix - the plugin behind local main (reload plugins),
  the plugin ahead of it, local main or the plugin behind the repository (update), or ahead of it (push
  main). When the repository cannot be read the band says it could not check, not in red. Nothing is reinstalled
  or pushed by plumb.
examples:
- id: EX-1
  given: plumb's repository main was rebuilt after Claude Code cached plumb
  when: the band draws
  then: it shows a red line with the running and the repository's builds and how to update
  quote: always ensure that claude code runs with the latest version of plumb, otherwise add a warning
    in red in the band
  prompt: 7de21ead90d4109e
- id: EX-2
  given: the red line shows
  when: the owner updates and reloads the plugin and the session runs the repository's build
  then: the line is gone
- id: EX-3
  given: local main was rebuilt after the session loaded the plugin
  when: the next prompt arrives
  then: the band shows the plugin behind local main, with both builds, and to reload plugins
- id: EX-4
  given: local main holds builds not pushed to plumb's repository
  when: the band draws
  then: it shows local main ahead of the repository with both builds and to push main
- id: EX-5
  given: plumb's repository cannot be read
  when: the band draws
  then: it says plumb could not check its repository, in a plain line, never red
proof:
  plan: after landing, in a session on an older build, the band shows the red line; after a reload it
    is gone
  kind: live-session
  post_merge: true
