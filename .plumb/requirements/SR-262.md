title: plumb's git hooks are installed on adoption and leave hooks plumb...
feature: FEAT-003
statement: Adopting a repository installs the quick merge check and the pre-push hook. A hook plumb did
  not write is never changed; the agent is told how to call plumb from it.
examples:
- id: EX-1
  given: a repository with a foreign pre-push hook
  when: plumb installs its pre-push hook
  then: the foreign hook is unchanged and the agent is told how to call plumb from it
- id: EX-2
  given: a foreign pre-merge-commit hook
  when: plumb installs its hooks
  then: the foreign hook is untouched and the agent is told how to call plumb from it
- id: EX-3
  given: a repository plumb adopted
  when: git hooks are listed
  then: the quick merge check and the pre-push hook (the merge check with covering tests, and the full
    suite only when full verification is pending) are both installed, and a pre-push hook plumb did not
    write is left untouched

    hook; the hook is unchanged, the agent says how to call plumb from it, and the quick merge check is
    listed among git''s hooks.'
