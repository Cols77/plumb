---
id: SR-148
title: plumb unlink removes one link and says why
statement: plumb unlink <record#n> --note <why> removes link n from the record, renumbers the links after
  it, logs an unlink event with the removed link, its pin, the note and the renumbering, and prints each
  new link id
examples:
- id: EX-1
  given: 'SR-124 has links #0..#22 and #5 points at plugin/hooks/trial.test.tsx, which no longer exists'
  when: plumb unlink SR-124#5 --note "the test moved to tests/plugin/mod" runs
  then: 'SR-124 has 22 links, the old #6 is now #5, the output lists each renumbered link, and the events
    log holds one unlink entry naming SR-124#5, its target, pin and note'
  quote: remove/move a link
  prompt: 02c090e63309bddb
- id: EX-2
  given: 'a record with no link #40'
  when: plumb unlink SR-124#40 --note x runs
  then: it exits 1 saying there is no link SR-124#40, and the record file is unchanged
- id: EX-3
  given: any link
  when: plumb unlink runs without --note
  then: it exits with a usage error and changes nothing
- id: EX-4
  given: a link that is the only verified_by link of an example the owner confirmed, and its target still
    exists
  when: plumb unlink runs on it
  then: it is refused, saying the confirmed example would lose its only test and naming plumb relink instead;
    the record is unchanged
- id: EX-5
  given: a dangling link that is the only verified_by link of a confirmed example
  when: plumb unlink runs on it
  then: it is removed (a dangling link proves nothing) and the output says the example now has no test

  plan: 'run plumb unlink on SR-124#5, #12 and #19 (dangling) and show plumb validate no longer reports
    them'
