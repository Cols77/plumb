---
id: SR-056
title: plumb hosts install hermes writes a thin Hermes plugin
feature: FEAT-004
statement: plumb hosts install hermes renders a Hermes plugin (plugin.yaml and register(ctx)) that registers
  the plumb command and, where the installed Hermes supports them, lifecycle hooks calling the host-neutral
  API; otherwise the context-file block and the CLI-only fallback.
examples:
- id: EX-1
  given: the rendered plugin and a fake ctx
  when: register(ctx) runs
  then: a plumb command is registered and each registered hook returns TurnOutput lines
- id: EX-2
  given: a fake ctx without hook registration
  when: register(ctx) runs
  then: only the command is registered and no error is raised
- id: EX-3
  given: the Hermes adapter installed, and the agent's shell with the environment it gives (the marker
    hermes where the adapter sets it, none otherwise) and no terminal
  when: the agent runs plumb approve SR-001 with "y" piped on stdin
  then: it exits 3 and no approval is written
- id: EX-4
  given: the plugin not loaded (project plugins not enabled)
  when: plumb hosts status hermes runs
  then: 'it prints "no session marker on this host: owner-only commands require an interactive terminal"
    with the trust model, says where prompts come from, and counts the confirmations resting on a self-recorded
    message (R13 Q4)'
