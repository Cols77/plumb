---
id: SR-099
title: Assess Claude-to-Hermes compatibility
statement: Plumb shall provide an evidence-based assessment of how its Claude Code integration maps to
  current Hermes, distinguishing directly reusable core behavior, adapter work, and unsupported gaps.
examples:
- id: EX-1
  given: the repository already contains a Hermes adapter
  when: the assessment compares it with the Claude Code integration
  then: it identifies the host-neutral core and reports what is already translated
- id: EX-2
  given: current Hermes lifecycle hooks and plugin loading rules differ from the adapter's assumptions
  when: compatibility is assessed
  then: the report names each mismatch and the adapter work needed rather than claiming full compatibility
- id: EX-3
  given: the owner asked how much can be translated, not to install or enable it
  when: the assessment completes
  then: no Hermes configuration is changed and no adapter is installed
