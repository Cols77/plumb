title: Everything about verdicts follows judge_model
statement: 'The judge model setting (understand.judge_model, haiku by default) is the model for verdicts
  and for everything that measures or guards them: the evaluation run over the labelled set names and
  uses it, and the calibration fingerprint that suspends settling records it; understand.model stays the
  model that reads the owner''s words (clarify, read, tidy)'

  then: the fingerprint names sonnet as the judge model
- id: EX-3

  then: Haiku reads the owner's words, as understand.model says

  given: judge_model changes after a logged calibration
  when: the stale check runs
  then: settling is suspended until the evaluation set passes again, as for a prompt change
