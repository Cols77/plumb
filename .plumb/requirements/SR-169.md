id: SR-169
title: The edit gate answers to this session’s own message, under one digest
statement: The gate that holds the agent’s edits is keyed by session and by the digest the prompt hook
  logged for the owner’s message; the request check and the gate use that same digest, so a check that
  answers ready opens the gate it closed, and a message in another session, even with the same text, never
  holds this one
examples:
- id: EX-1
  given: the owner types the same text in two sessions and one session’s card holds its gate
  when: the other session’s check answers ready
  then: the other session’s gate opens
- id: EX-2
  given: the hook logged the owner’s message under digest A
  when: the request check runs
  then: it reports digest A and opens the gate closed under A; never a second digest for the same message
- id: EX-3
  given: the gate is closed by a question card
  when: the owner answers that card
  then: the gate opens; no clarify rerun is needed
proof:
  plan: two live sessions typing the same text; the gate file of each shows its own state
  kind: hook
