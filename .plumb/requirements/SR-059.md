statement: For each imported SR, a pi-agent-factory consent record with decision approve, reviewer human
  and the consent phrase whose requirement_sha256 matches the source SR file's current content yields
  one approval by import citing the consent path and digest; every other imported record is proposed;
  plumb validate re-checks every by import approval.

  when: the import runs
  then: it is ignored and the SR is proposed
