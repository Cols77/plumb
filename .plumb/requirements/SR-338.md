---
id: SR-338
title: A landing removes the folders of ended sessions
statement: The SessionEnd hook marks .plumb/session/<id>/ with ended.json; the next landing removes each
  marked folder except its own session's, and leaves every unmarked folder and every marked one that still
  holds a waiting question (SR-340, INT-114).
examples:
- id: EX-1
  given: a session's folder exists
  when: the SessionEnd hook runs for that session
  then: the folder holds ended.json with the time
  quote: End-of-session hook
- id: EX-2
  given: two session folders, one marked ended and one not
  when: a landing runs
  then: the marked folder is removed, the unmarked one stays, and the landing line names one ended session
    folder removed
- id: EX-3
  given: the landing's own session folder is marked ended
  when: a landing runs for that session
  then: its folder stays
- id: EX-4
  given: a session marked ended is resumed
  when: its SessionStart hook runs
  then: ended.json is removed and the folder is kept by the next landing
- id: EX-5
  given: a session folder marked ended that still holds a waiting question
  when: a landing runs
  then: the folder stays, with its question, until the question is answered or withdrawn
proof:
  plan: end a session, land a merge, see its .plumb/session/<id>/ folder gone and the landing line name
    it
  kind: hook
