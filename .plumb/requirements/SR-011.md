---
id: SR-011
title: Edits are tracked without blocking
feature: FEAT-001
statement: The post-edit hook records each edited path for the session and never blocks or fails the agent's
  tool call, even when plumb itself fails.
examples:
- id: EX-1
  given: an agent edits src/plumb/links.py
  when: the post-edit hook runs
  then: the path is recorded in the session's touched list and the hook exits 0
- id: EX-2
  given: plumb's session directory cannot be written
  when: the post-edit hook runs
  then: it exits 0 and logs the error
