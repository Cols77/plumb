---
id: SR-075
title: Record files merge field by field
feature: FEAT-006
statement: 'plumb hooks install declares a merge driver for record files (in .plumb/.gitattributes and
  the repository''s git config, idempotent, removed by uninstall); the driver merges a record field by
  field against the merge base, so non-overlapping changes merge automatically: links added on either
  side, independent fields, list items and examples added on both sides (a clashing new EX number is renumbered
  inside the record), and formatting differences never conflict.'
examples:
- id: EX-1
  given: one side adds a verified_by link to SR-005 and the other side adds an implemented_by link
  when: git merges them
  then: SR-005 has both links and nothing conflicts
- id: EX-2
  given: one side changes SR-005's title and the other adds an example EX-4
  when: git merges them
  then: the result has the new title and EX-4, with no intent conflict
- id: EX-3
  given: both sides add a new example numbered EX-3 with different content
  when: git merges them
  then: the incoming one becomes EX-4 and its verified_by link's example is rewritten to EX-4
- id: EX-4
  given: plumb hooks install ran twice
  when: .plumb/.gitattributes and git config are read
  then: the plumb-record driver is declared once and other attributes are kept
