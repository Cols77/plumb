---
id: SR-062
title: The full intent card appears only when it matters, and its verbosity is full, compact or off
feature: FEAT-005
statement: The end-of-turn summary shows the four-line intent card (intent and state with the action;
  will, won't, assumptions; examples; tests) only for a new or changed intent awaiting the owner, a trigger,
  a regression or the owner's request; present.card full, compact or off sets how much else appears, and
  off never hides a trigger question. A card shows its record in full, so it counts as shown for the stated
  set.
examples:
- id: EX-1
  given: a turn that captured INT-030, proposed
  when: the stop hook runs in compact mode
  then: the summary shows the INT-030 intent card with "say ok to confirm"
- id: EX-2
  given: a turn that only changed code under confirmed records with fresh tests
  when: the stop hook runs in compact mode
  then: no intent card is shown
- id: EX-3
  given: present.card off and a regression
  when: the stop hook runs
  then: the regression card is shown
- id: EX-4
  given: present.card off and a turn whose proposed records the triage rates faithful
  when: the stop hook runs
  then: the offer line is not shown and no triage group is pinned in the stated set, so no later "ok"
    relays a group the owner never saw
- id: EX-5
  given: a confirmed INT-001 "add a sub function" and the judge flagging the request "sub should return
    a float instead" as a possible change of SR-002
  when: the agent changes only code and the turn ends on any host
  then: the owner sees no Intent change card; a card appears only when the agent edits the flagged record
    or writes a record that links to it
- id: EX-6
  given: a confirmed intent gains a new requirement that is only proposed
  when: its intent card is shown (capture or the end-of-turn summary)
  then: the new requirement's examples are labelled proposed and the confirmed requirement's examples
    confirmed, never with the intent's state
