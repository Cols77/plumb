---
id: SR-383
title: A new intent rewrites the existing record that covers it instead...
statement: When the intent loop captures a request whose topic an existing intent, requirement or decision
  already covers, it updates or supersedes that record in place; it creates a new record only when none
  covers the topic.
examples:
- id: EX-1
  given: an existing requirement states a behaviour and the owner restates it with a change
  when: the loop captures it
  then: that requirement is reworded or superseded and no near-duplicate requirement, decision or intent
    is added
- id: EX-2
  given: the request matches no existing record
  when: the loop captures it
  then: a new record is created
proof:
  plan: a test captures a restated requirement and shows the existing record edited or superseded with
    no new near-duplicate; a topic nothing covers still creates one
  kind: command
