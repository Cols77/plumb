id: SR-193
title: /plumb intent opens the intent loop on command
statement: 'Typing /plumb intent <words> opens one interactive loop for that intent: the clarifier asks
  every blocking question through the question tool, checks each answer against the confirmed records
  as it goes and asks about any contradiction or extension it finds, writes the intent candidates, and
  passes them through one judge gate with a fix loop until only low findings remain. An ordinary message
  opens no loop.'
examples:
- id: EX-1
  given: no loop is open
  when: the owner types /plumb intent add multiply next to add
  then: the blocking questions come through the question tool, as many as there are gaps, and no record
    is written until the intent is clear
  quote: AI comes back with questions using the question tool with clarification questions.
  prompt: 38baaadbee5c1487
- id: EX-2
  given: an intent candidate contradicts a confirmed requirement's example
  when: the loop checks the candidate
  then: the contradiction is put to the owner as a question before the candidate is written, naming the
    requirement
- id: EX-3
  given: the judge gate finds a high finding on a candidate
  when: the gate runs
  then: the candidate is fixed and judged again, and the loop ends only when every finding left is low
- id: EX-4
  given: no loop is open
  when: the owner types make the status line show the branch name
  then: no loop opens and no model runs
