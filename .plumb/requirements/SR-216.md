---
id: SR-216
title: An open question lives only while it stands
feature: FEAT-008
statement: Right after a repin, relink or unlink, plumb withdraws by itself an open stale-link question
  whose link is current again or gone; a judge question whose records are all approved or superseded,
  that a newer request replaced, or whose branch was merged or is gone is no longer asked. Each withdrawal
  is logged; the owner's turn-end text says nothing about it (SR-373); withdrawing approves nothing and
  the records stay as they were.
examples:
- id: EX-1
  given: an open stale-link issue on a requirement's covering test
  when: the agent repins that link after its tests pass
  then: the issue is withdrawn at once and logged, and the owner's turn-end text says nothing about it
    (SR-373)
- id: EX-2
  given: an open judge-cascade question about a requirement's wording
  when: that requirement is superseded
  then: 'the question is no longer asked: the requirement was replaced'
- id: EX-3
  given: an open question about an intent and its three requirements
  when: all four become approved, by the owner's answer or by judge validation
  then: the question is no longer asked
- id: EX-4
  given: an open stale-link issue whose link is still stale
  when: the turn ends
  then: the issue stays
- id: EX-5
  given: an open question asking which findings to resolve, then a newer request from the owner naming
    them
  when: the newer request is captured
  then: the older question is withdrawn and only what the new request leaves open, if anything, remains
- id: EX-6
  given: an open question from a previous session whose branch is gone
  when: the status is shown
  then: it is not listed
- id: EX-7
  given: a withdrawn question
  when: the status is shown
  then: its records are still listed as not yet approved
- id: EX-8
  given: an open question two of whose three records are approved
  when: the turn ends
  then: the question stays, now about the one record left
- id: EX-9
  given: a requirement is superseded while the owner is answering its question in the question tool
  when: the answer arrives
  then: the answer is captured as intent against the replacing requirement, and the old question is withdrawn
    without asking again
- id: EX-10
  given: a branch with two open questions
  when: it is merged into main, or the remote copy of the branch is merged
  then: both questions are withdrawn and logged; no owner line names them (SR-373)
- id: EX-11
  given: an open question on a feature branch
  when: main is merged into that feature branch
  then: nothing is withdrawn
- id: EX-12
  given: a branch made from main that is not yet merged, with an open question
  when: the turn ends
  then: the question stays
proof:
  plan: 'Recommended for the owner to decide: in a live session, leave a stale link and an open question,
    then repin the link and have the records approved; the next plumb line names both withdrawals by title,
    the status no longer lists them, and the records'' state is unchanged by the withdrawal itself.'
  kind: live-session
