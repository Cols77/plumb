---
id: SR-047
title: plumb merge-check requires every touched requirement confirmed and lists approvals the owner did
  not type
feature: FEAT-003
statement: plumb merge-check BASE puts every touched requirement, with its intents and the decisions that
  matter, that is not confirmed at its current hash to the owner in one trigger-2 question and exits 4;
  it lists every agent-relayed approval with its quote and every auto-jev approval with its score for
  the owner's glance, with the revoke command; plumb validate --merge is its report-only form and both
  give the same exit.
examples:
- id: EX-1
  given: a branch that changes SR-034's implementing file while SR-034 is proposed
  when: plumb merge-check main runs
  then: it lists SR-034 awaiting confirmation and exits 4
- id: EX-2
  given: an auto-jev approval of INT-030 in the range
  when: plumb merge-check main runs
  then: the glance lists INT-030 with its score, model version and plumb revoke INT-030
- id: EX-3
  given: any branch
  when: plumb merge-check --no-run and plumb validate --merge run on the same tree
  then: both exit with the same code
- id: EX-4
  given: an agent-relayed approval resting on a message the agent recorded itself (a host without a prompt
    hook)
  when: plumb merge-check main runs
  then: its glance line is labelled "self-recorded message"
