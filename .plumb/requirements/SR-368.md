id: SR-368
title: plumb itself offers a study asked in plain words
statement: When the owner asks for a study, in any words, the agent recognises it from its understanding
  of the request, never because plumb matched words, and proposes the idea through plumb's built-in study
  command so the band offers it and the owner picks the depth there. plumb's records skill names those
  commands and their order, so the agent never has to find out how plumb makes studies.
examples:
- id: EX-1
  given: no study idea waits
  when: the owner writes 'I'd like a study of how merges are held'
  then: the agent proposes the study 'how merges are held' through plumb's study command, the band offers
    it, and the agent runs no search to find out how
  quote: if it is a feature, shouldnt it be builtin and not request the coding agent to discover the proejct?
  prompt: bcee0f05b14e8bf4
- id: EX-2
  given: the owner writes 'study the failing test and fix it'
  when: the agent reads it
  then: no study is offered
- id: EX-3
  given: the owner writes any message mentioning a study
  when: plumb's prompt hook reads it
  then: plumb proposes nothing itself; only the agent's understanding offers a study
- id: EX-4
  given: the owner asks for a study
  when: the agent reads plumb's records skill
  then: it names the study commands in order - propose, wait for the depth, gather, add
