---
id: SR-281
title: A project set up the old way keeps working, and moves to the...
feature: FEAT-007
statement: In a project where plumb's settings, command and skills were copied in, plumb's checks run
  once per turn whether or not the plugin is also active, under the version 2 rules. Asked to move to
  the plugin, plumb removes only what it wrote and left unchanged, points git's checks at its launcher,
  and names what the owner changed and it kept.
examples:
- id: EX-1
  given: a project set up the old way, with the plugin also installed
  when: a turn runs
  then: each of plumb's checks runs once and the owner sees one summary
- id: EX-2
  given: that project, where the owner edited the copied /plumb command and added a Claude Code setting
    of their own
  when: the owner says "move plumb to the plugin"
  then: plumb's own settings and the unchanged copied skills are removed, the edited command and the owner's
    own setting stay and are named, and git's checks call plumb's launcher
- id: EX-3
  given: a project set up the old way, on a machine without the plugin (a teammate, a build server)
  when: a turn runs
  then: 'the project''s own copied checks run plumb once each, with the version 2 behaviour the plugin''s
    would have: no approval command, no card, questions only'
proof:
  plan: 'Recommended: in a scratch project set up the old way with one edited copied file, the owner says
    "move plumb to the plugin" and sees plumb''s own copies go, the edited file stay and be named, and
    a turn afterwards show one summary. The owner decides whether this is the proof.'
  kind: live-session
