---
id: SR-140
title: The pane draws a diagram the skill produced, on every surface
statement: Given an HTML file or a bare SVG written with the architecture-diagram skill, the diagram pane
  draws it as Svg on the desktop app and VS Code, and in the terminal as box-drawing text with the same
  boxes, labels and arrows, readable at 110 columns; a file that holds no SVG is refused with a plain
  line saying so
examples:
- id: EX-1
  given: the skill's example diagram with eight component boxes and nine arrows
  when: /diagram show <file> runs in the terminal
  then: the pane shows eight boxes with their labels and nine arrows between the right boxes, nothing
    overlapping
- id: EX-2
  given: the same file
  when: the pane is drawn on the desktop app
  then: it is the file's SVG, drawn as one Svg element
- id: EX-3
  given: a box whose label is wider than the box at terminal scale
  when: it is drawn in the terminal
  then: the label wraps or is cut with an ellipsis inside the box; no character overlaps another
- id: EX-4
  given: a file with no <svg>
  when: /diagram show runs
  then: the pane says the file holds no diagram and draws nothing else
