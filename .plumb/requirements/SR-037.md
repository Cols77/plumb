---
id: SR-037
title: An escalated spec is a set of records the owner approves by one set-hash approval
feature: FEAT-002
statement: An escalated spec is an INT with mode escalated and a members list. plumb spec show prints
  every member in full with the set hash; plumb spec approve (owner's terminal, refused under the session
  marker) or plumb relay --set with the owner's affirming words writes one approval pinning the set hash
  over the sorted member hashes and every member's hash. Code for the escalated work waits for that approval;
  an edit of a member afterwards unconfirms that member and the set.
examples:
- id: EX-1
  given: INT-021 escalated with members SR-070 and SR-071
  when: the owner runs plumb spec approve INT-021
  then: one approval event carries the set hash of the sorted [id, hash] pairs and confirms all three
    records
- id: EX-2
  given: the session marker is set
  when: plumb spec approve INT-021 runs
  then: it exits 3 and writes nothing
- id: EX-3
  given: the set is approved
  when: SR-071 is edited
  then: SR-071 is an unconfirmed edit and the set shows as unconfirmed
