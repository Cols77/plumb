---
id: SR-250
title: Only the owner switches the fast track, and a JEV version change...
feature: FEAT-002
statement: The fast track works only while the owner's own switch event stands and calibration passes
  for the resolved JEV version; a change of JEV version beyond its normalized form suspends it. The owner
  switches it by typing /plumb auto-approve on|off as a whole message or by answering plumb's question;
  the agent, config.yaml or prose cannot.
examples:
- id: EX-1
  given: the owner types '/plumb auto-approve on' as a whole message
  when: the prompt hook reads it
  then: a config event by the owner via typed command is logged and the fast track is on
- id: EX-2
  given: the agent runs plumb config auto-approve on under the session marker
  when: the command runs
  then: it is refused and nothing is logged
- id: EX-3
  given: the owner writes 'please turn auto-approve on, thanks' in a sentence
  when: the prompt hook reads it
  then: nothing changes yet; plumb asks through the question tool whether to switch the fast track on,
    and only the owner's answer there logs the switch event
- id: EX-4
  given: config.yaml says auto_approve enabled true but no owner switch event exists
  when: an intent is captured and JEV scores it at 0.97
  then: 'it is not fast-tracked: it goes to the judge model''s questions, and plumb validate warns about
    the mismatch'
- id: EX-5
  given: the fast track is on and calibrated
  when: the resolved JEV model version changes
  then: the fast track is suspended and the status says it is recalibrating
- id: EX-6
  given: the fast track is on with a passing calibration measured on jev-1.13.0
  when: JEV now resolves typesafe/jev-1.13-20260917
  then: the fast track stays on, because the normalized versions match; a jev-1.14 answer still suspends
    it
- id: EX-7
  given: the agent edits config.yaml to switch the fast track on
  when: the next record is judged
  then: the fast track stays off; only the owner's switch event counts
proof:
  plan: 'Recommended: in a live session the owner types /plumb auto-approve on and plumb''s status shows
    the fast track on; the agent''s attempt to switch it is shown refused. The owner decides whether this
    walk is the proof.'
  kind: live-session
