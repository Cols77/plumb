id: SR-328
title: The self-debug workflow stands alone in plumb
feature: FEAT-008
statement: 'The self-debug workflow is plumb''s own: a plumb command and the plugin''s skill define its
  stages and gates, it needs no other plugin or skill, and it runs through the host''s workflow mechanism
  with the cheapest model that fits each stage. Every question to the owner goes through the question
  tool.'
examples:
- id: EX-1
  given: only the plumb plugin installed
  when: plumb debug runs a case through to a fix
  then: every stage runs from plumb's own command and skill, and nothing of another plugin is read
- id: EX-2
  given: a case whose evidence stage runs
  when: the model is chosen
  then: it is the smallest configured model; the cause, test and fix stages take the middle one, and the
    largest is used only after a failed round
proof:
  plan: 'Acceptance tests with a scripted dispatcher: the stages run with no other plugin present and
    the model chosen for each stage is recorded.'
