---
id: SR-005
title: Only the owner's explicit words confirm a record
feature: FEAT-001
statement: A record is never confirmed by the coding agent's own reading of the owner's words. An agent-run
  relay of the owner's prose (plumb relay) is refused and records nothing. Silence or an unclear reading
  confirms nothing, and no fixed word rules (affirmation, negation, question, objection or reservation
  words) decide an approval. The owner confirms a record with plumb approve in their own terminal, with
  an Accept button, or with their own message logged by the prompt hook, handled as SR-101 says. The session
  marker refuses plumb approve and plumb revoke for the agent. On every host, an owner-only command writes
  only after a y/N answered in an interactive terminal, so an agent shell without the marker is refused
  too.
examples:
- id: EX-1
  given: PLUMB_AGENT_SESSION is set in the agent's shell
  when: the agent runs plumb approve SR-001
  then: plumb refuses with exit 3 and writes nothing
- id: EX-2
  given: a logged prompt reading "SR-001 looks good, approved"
  when: the agent runs plumb relay for SR-001 with that quote and the prompt digest
  then: plumb refuses, logs nothing, and says an agent-run relay no longer exists
- id: EX-3
  given: a logged prompt reading "no, do not approve SR-001"
  when: the agent relays SR-001 quoting "approve SR-001"
  then: plumb refuses and nothing is confirmed
- id: EX-6
  given: a host whose adapter cannot set PLUMB_AGENT_SESSION, and the agent's shell has no terminal
  when: the agent runs plumb approve SR-001 (or approve --proposed, revoke, tests waive) with "y" piped
    in
  then: plumb refuses with exit 3 and writes nothing
