---
id: SR-005
title: Only the owner's explicit words confirm a record
feature: FEAT-001
statement: A record is confirmed only by the owner's plumb approve in their own terminal or by an agent-relayed
  approval that carries the owner's verbatim quote and the digest of the logged prompt it came from; the
  quote must affirm (no negation, no question) and each record must be in the stated set and shown there
  in full, or be named in the quote; the session marker refuses plumb approve and plumb revoke for the
  agent; silence confirms nothing.
examples:
- id: EX-1
  given: PLUMB_AGENT_SESSION is set in the agent's shell
  when: the agent runs plumb approve SR-001
  then: plumb refuses with exit 3 and writes nothing
- id: EX-2
  given: a logged prompt reading "SR-001 looks good, approved"
  when: the agent relays SR-001 with that quote and the prompt digest
  then: an agent-relayed approval with the quote and digest is logged
- id: EX-3
  given: a logged prompt reading "no, do not approve SR-001"
  when: the agent relays SR-001 quoting "approve SR-001"
  then: 'plumb refuses: a negated affirmation confirms nothing'
- id: EX-4
  given: a prompt that neither affirms nor objects
  when: the agent tries to relay it as an approval
  then: plumb refuses and nothing is confirmed
- id: EX-5
  given: a stated record the reply before the prompt did not show in full (cut by the summary cap)
  when: the agent relays it on the owner's bare "ok"
  then: plumb refuses unless the quote names the record's ID
