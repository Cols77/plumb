id: SR-005
title: Only the owner's explicit words confirm a record
feature: FEAT-001
statement: A record is confirmed only by the owner's plumb approve in their own terminal or by an agent-relayed
  approval that carries the owner's verbatim quote and the digest of the logged prompt it came from; the
  quote must affirm (no negation, no question) and each record must be in the stated set and shown there
  in full, or be named in the quote; the session marker refuses plumb approve and plumb revoke for the
  agent, and on every host an owner-only command writes only after a y/N answered in an interactive terminal,
  so an agent shell without the marker is refused too; silence confirms nothing.
examples:
- id: EX-1
  given: PLUMB_AGENT_SESSION is set in the agent's shell
  when: the agent runs plumb approve SR-001
  then: plumb refuses with exit 3 and writes nothing
- id: EX-2
  given: a logged prompt reading "SR-001 looks good, approved"
  when: the agent relays SR-001 with that quote and the prompt digest
  then: an agent-relayed approval with the quote and digest is logged
- id: EX-3
  given: a logged prompt reading "no, do not approve SR-001"
  when: the agent relays SR-001 quoting "approve SR-001"
  then: 'plumb refuses: a negated affirmation confirms nothing'
- id: EX-4
  given: a prompt that neither affirms nor objects
  when: the agent tries to relay it as an approval
  then: plumb refuses and nothing is confirmed
- id: EX-5
  given: a stated record the reply before the prompt did not show in full (cut by the summary cap)
  when: the agent relays it on the owner's bare "ok"
  then: plumb refuses unless the quote names the record's ID
- id: EX-6
  given: a host whose adapter cannot set PLUMB_AGENT_SESSION, and the agent's shell has no terminal
  when: the agent runs plumb approve SR-001 (or approve --proposed, revoke, tests waive) with "y" piped
    in
  then: plumb refuses with exit 3 and writes nothing
- id: EX-7
  given: a reply stated INT-001, SR-001 and DEC-001 and the owner answered "SR-001 is ok but DEC-001 is
    wrong, use floats"
  when: the agent relays all three quoting "SR-001 is ok" or "ok"
  then: plumb refuses (an objection is not an approval, and an ok naming records confirms only those);
    relaying SR-001 alone confirms it and DEC-001 stays proposed
- id: EX-8
  given: the owner answered "ok" to a reply in an earlier session
  when: the owner answers "ok" again to a later reply and the agent relays its stated records with that
    digest
  then: 'the records are confirmed: the latest logged prompt with that digest is checked against the reply
    before it'
- id: EX-9
  given: the reply showed INT-005 and SR-005 (pow, given 2 and 3 it returns 8)
  when: the owner writes "No, the pow example is wrong, it should return 9. Ok, carry on with the tests"
    and the agent relays INT-005 SR-005 with the quote "Ok, carry on with the tests"
  then: the relay is refused (an objection naming the records in plain words is not an approval) and the
    prompt hook's relay line leaves INT-005 and SR-005 out
