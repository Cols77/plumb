---
id: SR-327
title: Self-debug elsewhere runs only by configuration
feature: FEAT-008
statement: In a repository that is not plumb's own, a debug case whose rerun fails again ends with a defect
  report to the agent (the case, its log entry, the repro and what is missing) and changes nothing, unless
  the configuration turns self-debug on and names plumb's source checkout; then the fix is made and landed
  on a branch of that checkout as in plumb's own repository. Turned on without a source checkout, plumb
  says once what is missing and reports the defect. When issue reporting is turned on in the configuration
  and the gh command is available, the defect report is also filed once per case as an issue on plumb's
  GitHub repository, carrying plumb's own log entry and the repro and never the repository's records or
  code.
examples:
- id: EX-1
  given: another repository with self-debug off
  when: a case's rerun fails again
  then: the case ends with a defect report and no code outside .plumb changes
- id: EX-2
  given: another repository with self-debug on and plumb's source checkout named
  when: a case's rerun fails again
  then: the fix lands on a branch of that checkout, with its test, nothing stale and the review logged,
    and the repository itself is untouched
- id: EX-3
  given: self-debug on without a source checkout
  when: a case's rerun fails again
  then: plumb says once that the source checkout is missing and the case ends with a defect report
- id: EX-4
  given: another repository with issue reporting turned on and the gh command available
  when: a case ends with a defect report
  then: one issue is filed on plumb's GitHub repository with the case, plumb's log entry and the repro,
    none of the repository's records or code, and the same case files no second issue
- id: EX-5
  given: another repository with issue reporting off, or without the gh command
  when: a case ends with a defect report
  then: the report stays local to the agent and no issue is filed
proof:
  plan: 'Acceptance tests: a scratch repository that is not plumb''s own, with the switch off, on with
    a source, and on without one, ends each case as stated.'
