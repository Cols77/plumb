---
id: SR-038
title: Intent-change flags score contradiction and extension against confirmed examples
feature: FEAT-002
statement: The intent-change flag compares a request with the examples of matched confirmed records through
  the judgment backend (heuristic by default) and flags only a contradiction (the request negates or replaces
  a confirmed then or statement) or an extension (new behaviour beside a confirmed one); a mention with
  tidy-up words is benign and never flagged, and a proposed record never feeds the flag.
examples:
- id: EX-1
  given: SR-001 confirmed with EX-1 "add(1, 2) returns 3"
  when: the prompt is "make add subtract"
  then: a contradicts flag on SR-001 names EX-1
- id: EX-2
  given: the same confirmed SR-001
  when: the prompt is "add a multiply function next to add"
  then: an extends flag on SR-001 is raised
- id: EX-3
  given: the same confirmed SR-001
  when: the prompt is "also tidy the add docstring for SR-001"
  then: no flag is raised
- id: EX-4
  given: a fixture of at least 30 labelled prompts
  when: the heuristic scores it
  then: every contradicts prompt is flagged and no benign prompt is
