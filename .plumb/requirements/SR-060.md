id: SR-060
title: The import is idempotent and shows a dry-run diff
feature: FEAT-004
statement: plumb import pi-agent-factory --dry-run prints a plan of create, update, unchanged and skip
  per record with the changed fields and writes nothing; applying the same source twice changes no file
  and appends no event the second time; a changed source updates the record under its plumb ID and re-pins
  its links, leaving it proposed unless a consent pins the new content.
examples:
- id: EX-1
  given: a scratch target and a source
  when: plumb import --dry-run runs
  then: it prints create lines for every record and the target is unchanged
- id: EX-2
  given: a target after one import
  when: the same import runs again
  then: no file changes and no import event is appended
- id: EX-3
  given: the source SR-003 statement changed
  when: the import runs again
  then: the diff shows update SR-003 statement and the record is rewritten and proposed
