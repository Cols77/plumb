---
id: SR-069
title: A confirmation resting on a message the agent recorded itself is...
feature: FEAT-002
statement: On a host without a prompt hook a chat ok can still confirm, but every confirmation whose cited
  prompt was not recorded by the prompt hook carries self_recorded and is shown as self-recorded message
  wherever its confirmation is shown (plumb show, the confirmation counts, the merge-boundary glance and
  the host status).
examples:
- id: EX-1
  given: a prompt the agent logged itself on a host without a prompt hook
  when: the agent relays the owner's ok from it
  then: the approval confirms the record and is labelled self-recorded message in plumb show and the confirmation
    counts
  quote: Q4 YES, LABELLED
- id: EX-2
  given: a prompt the prompt hook logged
  when: the agent relays the owner's ok from it
  then: the approval carries no self-recorded label
- id: EX-3
  given: a host whose prompt hook is installed (the claude-code marker, or Codex once its hook has logged
    a prompt) and a message the agent logged itself with plumb turn start
  when: the agent relays an ok from it (by IDs, --group, --set), declines an escalation with it, or capture
    cites it for auto-approval
  then: the relay and the decline are refused with exit 3, no auto-approval rests on it, and nothing is
    confirmed
