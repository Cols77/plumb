id: SR-271
title: A question about structure or flow comes with a diagram
feature: FEAT-007
statement: When a question for the owner is about which parts talk to which, an order of steps or where
  something lives, the agent draws the answer space with the diagram mod's architecture-diagram skill,
  which lives in its own repository beside plumb, and the question goes to the study room with the diagram
  above it; a question about wording or scope gets no diagram and goes through the question tool.
examples:
- id: EX-1
  given: a question asking which of three hooks should write host.json
  when: the agent prepares it
  then: it writes a diagram of the three hooks and the file, and the question goes to the study room with
    that diagram above it, drawn as the file's SVG
- id: EX-2
  given: a question asking whether 'the findings' means the ones listed above
  when: the agent prepares it
  then: no diagram is drawn and the question goes through the question tool
- id: EX-3
  given: the diagram mod is not installed
  when: a structural question is prepared
  then: the question still goes out without a diagram, and the agent says once that the diagram mod would
    draw it
- id: EX-4
  given: plumb's Claude Code plugin
  when: it is installed
  then: it ships no diagram skill or diagram mod of its own
proof:
  plan: 'Recommended for the owner to decide: in a live session on a scratch repository the owner asks
    something that raises a structural question (which hook writes a file); the agent draws it with the
    diagram mod, the plumb line says a question waits in the study room, and the owner sees it there with
    the diagram above it; a wording question in the same session arrives through the question tool with
    no diagram.'
  kind: live-session
