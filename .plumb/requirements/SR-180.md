---
id: SR-180
title: The four queued browser integration defects are fixed and guarded
statement: Stale-link action state persists to its own store; an invalid button index leaves no false
  recovery handoff; a left-open turn-built card's fresh offer passes presentation validation; a custom
  combination requested for an unresolved conflict is not reported done. Each fix carries a regression
  test.
examples:
- id: EX-1
  given: A stale-link card is answered in the browser
  when: The server restarts and the card is drawn again
  then: The answer is still recorded and the card shows its settled state
  quote: Stale-link/drift action state is not persisted to its separate store.
- id: EX-2
  given: A press names a button index the offer does not have
  when: The next prompt hook runs for that session
  then: No recovery handoff is delivered; the press was refused and nothing durable remains
  quote: An invalid button index leaves an intent that becomes a false recovery handoff.
- id: EX-3
  given: A card built at turn time was left open
  when: The browser draws it again
  then: Its fresh offer passes validation and its buttons work
  quote: A left-open turn-built card's fresh offer fails presentation validation.
- id: EX-4
  given: A conflict card has no resolution yet
  when: The owner asks for a custom combination
  then: The card stays open awaiting the combination and is not shown as done
  quote: Requesting a custom combination for an unresolved conflict reports it done.
proof:
  plan: Run tests/browser and show the four regression tests passing
  kind: command
