title: When no judge can be reached, plumb says so and blocks the step...
statement: When no judge can be reached (no key, timeout, API down), plumb says so once and the step that
  needed it (auto-approval, settling, triage, calibration, the stale check) waits until a judge is back;
  nothing is decided by rule; work that needs no judge goes on, and the request check keeps its build-anyway-or-wait
  card
examples:
- id: EX-1
  given: the judge’s key is missing
  when: auto-approval would run
  then: one line says the judge is unreachable and the approval waits; nothing is approved by rule
  quote: Say so and block
  prompt: 03a951b08a8ba7c1
- id: EX-2
  given: the judge’s key is missing
  when: the agent edits a file and the turn ends with no stale link
  then: work goes on; the turn is not held
- id: EX-3
  given: the judge is back
  when: the waiting step runs again
  then: it completes and the line is gone
