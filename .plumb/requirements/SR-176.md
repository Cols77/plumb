title: Browser resolves Plumb issues through existing core semantics
statement: The local browser workspace lists source-session issues, full explanations, evidence and existing
  actions. Browser answers preserve exact-content approval and offer provenance without changing another
  surface's credentials, and remain distinct from verified repair completion.

- id: EX-1

  when: The owner selects a supported answer
  then: Plumb records that action against exactly the displayed content and the browser shows its actual
    resulting state
- id: EX-2
  given: A displayed record changes before its answer
  when: The old action is submitted
  then: The changed content is not approved and the browser explains the stale answer
- id: EX-3
  given: A Claude mod is already registered
  when: The browser opens and resolves an issue
  then: The mod registration is preserved and both surfaces retain valid distinct provenance
proof:
  plan: Run real-server browser decisions on isolated records and assert stored core approval, stale rejection
    and preserved mod credentials.
