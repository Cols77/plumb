---
id: SR-082
title: plumb installs as a Claude Code plugin and runs its own private copy of its tools
feature: FEAT-007
statement: 'plumb''s repository offers plumb as a Claude Code plugin: the /plumb command, the plumb and
  plumb-clarify skills, plumb''s background checks (at session start, on each message, after each edit,
  at the end of each answer, and the guard that keeps the agent from confirming for you) and the in-app
  panels. Installed with Claude Code''s own plugin commands, all of it is built into every project. Everything
  the plugin runs uses plumb''s own private copy of its tools, kept per user and per plugin version and
  built from the copy of plumb the plugin carries; never the project''s own development setup (ruling
  R15).'
examples:
- id: EX-1
  given: a machine with Claude Code and uv but no plumb anywhere
  when: the owner adds plumb's plugin list and installs the plumb plugin with Claude Code's plugin commands,
    then opens a session in any project
  then: /plumb, the plumb skills and the background checks are available, and nothing was written into
    that project
- id: EX-2
  given: an adopted project whose own development setup holds no plumb, or another plumb version
  when: any background check, the /plumb command or an in-app panel runs plumb
  then: it runs the plugin's own copy of plumb and uses nothing from the project's setup
- id: EX-3
  given: plumb's private copy of its tools is missing or older than the plugin
  when: the first session starts
  then: it is set up once in the background, the owner sees one plain line saying plumb is getting ready,
    and checks that cannot run yet stay silent
- id: EX-4
  given: the plugin and plumb's plugin list
  when: Claude Code's plugin validation runs on each
  then: both pass, and the validation lists what the in-app panels respond to
