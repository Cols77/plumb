---
id: SR-048
title: Exactly one full-suite run clears full verification pending, with evidence pinned to identity
feature: FEAT-003
statement: plumb merge-check runs the full suite at most once per invocation, only when full verification
  is pending or touched acceptance tests are unverified and no owner waiver covers the change, and reuses
  a passing full run on an identical tree and environment identity; a failed run is never repeated in
  the same invocation; a green report appends one merge-evidence event pinning the run, the tree and the
  environment identity.
examples:
- id: EX-1
  given: uv.lock changed since the last full run
  when: plumb merge-check main runs
  then: the full suite runs once and full verification pending is cleared when it passes
- id: EX-2
  given: the full run fails a test
  when: plumb merge-check main finishes
  then: it ran the suite once, exits 5 and writes no merge-evidence event
- id: EX-3
  given: a passing full run on the same tree and environment identity
  when: plumb merge-check main runs
  then: no suite runs and the report says full run reused
