---
id: SR-263
title: The owner's status shows where intent stands, in one line
feature: FEAT-005
statement: A one-line status, in the host's status line and plumb's small band above the prompt, shows
  the state (aligned, awaits you, drift, failing, regression), the intent in plain words and the counts
  with how many the judge approved, read from the session state file without loading records or running
  tests; the band can be hidden.
examples:
- id: EX-1
  given: a snapshot with 12 of 14 requirements agreed, 2 of them approved by the judge, and one question
    waiting for the owner
  when: the status line renders
  then: it shows "awaits you", the intent title and "12/14 agreed (2 by the judge)", with no record id
- id: EX-2
  given: no judge approval exists
  when: the status renders
  then: no "by the judge" count appears
- id: EX-3
  given: the ASCII setting is on
  when: the status renders
  then: it contains only ASCII characters
- id: EX-4
  given: a session state file written by the last hook
  when: the status line runs
  then: it prints one line from that file without reading the records
- id: EX-5
  given: nothing awaits the owner
  when: the band draws
  then: it is one line (the state and a plain summary of the intent) with a Hide button
- id: EX-6
  given: records written this turn that the judges are still checking, and no question waiting
  when: the status renders
  then: 'it does not say "awaits you": the records count as plumb''s work in progress, not as something
    for the owner to read'
proof:
  plan: 'Recommended for the owner to decide: in a live Claude Code session on an adopted scratch repository,
    the owner sees the status line and the band read ''aligned'' with the intent in plain words; the agent
    then raises one question and the status reads ''awaits you''.'
  kind: live-session
