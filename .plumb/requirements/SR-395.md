id: SR-395
title: The owner's message is sent from the loop list to the session...
statement: 'For a loop a session is working on, the owner can send that session a message: typed on the
  loop''s row in the loops pane where Claude Code allows typing there, or told to the agent of any session,
  which sends the owner''s words unchanged with a plumb command. The words must be the owner''s own: a
  message the owner did not type is refused. The target session receives the words labelled as the owner''s
  message sent through plumb''s loop list: before its next step when it is working; when it is waiting
  at its prompt, its own band starts its turn at once so it reads the message; where no band runs in that
  session, at its next turn. The row shows whether the message is sent and not read yet, or delivered.
  A message to a loop no session works on is refused, saying the loop can be reopened.'
examples:
- id: EX-1
  given: a session is building the card-store loop
  when: the owner types 'skip the colours slice' on that loop's row and sends it
  then: that session receives 'skip the colours slice' labelled as the owner's message from the loop list
    before its next step, and the row shows delivered
- id: EX-2
  given: the owner tells the agent of another session 'tell the card-store loop to rebase on main'
  when: the agent sends it with plumb's command
  then: the target session receives 'rebase on main' in the owner's words, unchanged
- id: EX-3
  given: an agent asks plumb to send words the owner did not type in its session
  when: the send is asked
  then: it is refused and nothing is sent
- id: EX-4
  given: the target session is waiting at its prompt and cannot be woken
  when: a message is sent to its loop from the pane
  then: the row shows sent, not read yet, until that session's next turn, where it is delivered once
- id: EX-5
  given: a loop no session works on
  when: a message is sent to it
  then: it is refused, saying no session works on it and that it can be reopened
- id: EX-6
  given: Claude Code gives the pane no way to type
  when: the owner opens a working loop's row
  then: the row says to tell the agent what to send
- id: EX-7
  given: the target session waits at its prompt with plumb's band running
  when: a message is sent to its loop, from the pane or by an agent
  then: that session starts a turn by itself, receives the words labelled as the owner's message from
    the loop list, once, and the row shows delivered
proof:
  plan: 'Before landing: from one session, plumb''s send command passes the owner''s typed words to a
    second live session, which shows them at its next step, and words the owner did not type are refused.
    After landing and a plugin reload: the same typed on the row in the loops pane; screenshots of both
    sessions opened on the owner''s screen.'
