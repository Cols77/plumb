---
id: SR-264
title: plumb's band connects at session start, or says once why it is off
feature: FEAT-005
statement: At session start plumb's band finds plumb's Python and connects, also when the session-start
  check is cut by its time limit or the repository still has plumb's older per-repository hooks; when
  it cannot connect it says why in one line once per session, and a failure to record its connection never
  fails the hook.
examples:
- id: EX-1
  given: no Python for plumb is found
  when: a session starts
  then: one dim line says plumb's band is off because no Python for plumb was found
- id: EX-2
  given: plumb refuses the band's hello
  when: a session starts
  then: one line says the band is off and gives plumb's reason
- id: EX-3
  given: the band connects
  when: a session starts
  then: no such line appears
- id: EX-4
  given: the session-start check is cut by its time limit
  when: a session starts in an adopted repository with the plugin enabled
  then: host.json names the Python and the band shows above the prompt
- id: EX-5
  given: the repository also has plumb's older per-repository hooks
  when: a session starts
  then: the band runs plumb with the repository's Python and shows
- id: EX-6
  given: host.json cannot be written
  when: a session starts
  then: the hook still answers and nothing fails
proof:
  plan: 'Recommended for the owner to decide: the owner starts a live session with no Python for plumb
    available and sees one line saying why the band is off; with Python back, the band shows and no such
    line appears.'
  kind: live-session
