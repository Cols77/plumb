---
id: SR-112
title: 'Only the owner confirms a record: their typed command, a button,...'
feature: FEAT-008
statement: 'A record is confirmed only by the owner: a typed /plumb approve or confirm naming IDs, a button
  press, an owner-only command in their own terminal after a y/N answered there, or the owner''s free-prose
  message read by the reader (SR-101), which confirms an item only when the message is in the prompt log,
  the item was shown in full at that version and the reader accepted it with enough confidence. No fixed
  words (affirmation, objection, scope or reservation rules) are used to understand the owner, and an
  agent-run relay of the owner''s prose no longer exists. The session marker refuses plumb approve and
  plumb revoke for the agent, and on every host an owner-only command writes only after a y/N answered
  in an interactive terminal, so an agent shell without the marker is refused too; silence confirms nothing,
  and an unclear reading confirms nothing and asks once.'
examples:
- id: EX-1
  given: PLUMB_AGENT_SESSION is set in the agent's shell
  when: the agent runs plumb approve SR-001
  then: plumb refuses with exit 3 and writes nothing
- id: EX-2
  given: a host whose adapter cannot set the session marker, and an agent shell with no terminal
  when: the agent runs plumb approve SR-001 (or approve --proposed, revoke, tests waive) with "y" piped
    in
  then: plumb refuses with exit 3 and writes nothing
- id: EX-3
  given: the previous reply showed SR-001 in full and the owner's message is in the prompt log
  when: the owner writes "SR-001 looks good, approved" and the reader accepts it
  then: SR-001 is confirmed, recorded with the owner's words
- id: EX-4
  given: the previous reply showed INT-001, SR-001 and DEC-001
  when: the owner writes "SR-001 is ok but DEC-001 is wrong, use floats"
  then: SR-001 is confirmed, DEC-001 gets a change asked and INT-001 stays open; no word list decided
    any of it
- id: EX-5
  given: a record the previous reply did not show in full
  when: the owner writes a bare "ok"
  then: that record is not confirmed
- id: EX-6
  given: the reader is unsure what the owner meant
  when: the message is read
  then: nothing is confirmed and the owner is asked once
- id: EX-7
  given: an agent writes an approval entry by hand with an owner quote
  when: plumb checks the log
  then: 'the entry is not accepted: only the worker''s re-checked entries and the owner''s own commands
    confirm'
