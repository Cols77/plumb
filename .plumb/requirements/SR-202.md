---
id: SR-202
title: The owner reaches every plumb capability in plain words, never an...
feature: FEAT-007
statement: Every capability the owner acts on or needs to see is reached through /plumb (also /plumb:plumb)
  with plain words, the owner's message read by meaning, or the question tool and browser study room.
  No owner command takes a record id and there is no approval command. Every verb the installed command
  advertises runs. A pasted /plumb intent or /plumb clarify counts as typed; any other pasted /plumb command
  does not. Internal mechanisms (linking, repinning, hashing, test selection, log upkeep) stay internal,
  and an owner-only switch the agent starts on its own is refused.
examples:
- id: EX-1
  given: the plugin is installed in a repository
  when: the session lists skills
  then: plumb-records and plumb-clarify appear and /plumb:plumb runs the /plumb command (the host registers
    the plugin command under that name)
- id: EX-2
  given: the owner types /plumb:plumb intent the reminders should go by email
  when: the prompt hook reads it
  then: it behaves exactly as /plumb intent the reminders should go by email
- id: EX-3
  given: the owner types /plumbing intent something
  when: the prompt hook reads it
  then: 'it is not taken as a plumb command: no loop opens and nothing is released'
- id: EX-4
  given: the session start says to type /plumb init to adopt this repository
  when: the owner types /plumb:plumb init
  then: the agent runs plumb's adoption and reports what happened in the owner's terms
- id: EX-5
  given: no owner message asked for it
  when: the agent tries to turn automatic approval on
  then: it is refused and nothing changes
- id: EX-6
  given: two requirements about reminder timing
  when: the owner writes "the reminder timing looks right" in plain words
  then: the message is taken as the owner's answer about reminder timing, no record id or record text
    is shown to the owner, and no word list decided it
- id: EX-7
  given: the owner types "/plumb confirm the reminder timing" or "/plumb approve DEC-017"
  when: the command runs
  then: no approval command runs, no id is asked for, the records' states are unchanged by the command,
    and the words are taken as the owner's answer about reminder timing
- id: EX-8
  given: the list of plumb's capabilities, split into what the owner acts on and plumb's internal mechanisms
  when: the owner-entry-point table's test runs
  then: every owner action is listed with its plain-words way to reach it, none takes an id, and no internal
    mechanism appears in the table, in owner-facing text or as a step the owner is asked to take
- id: EX-9
  given: a stale link that only needs repinning because its target was reformatted
  when: the stop hook runs
  then: plumb or the agent repins it without telling the owner
- id: EX-10
  given: the installed /plumb command file
  when: each verb it advertises is run with --help
  then: each exits 0, and no verb is advertised that does not exist
- id: EX-11
  given: the owner pastes a message beginning with /plumb clarify followed by their words
  when: the prompt hook reads it
  then: it is taken as /plumb clarify with those words
- id: EX-12
  given: the owner pastes a message beginning with /plumb undo or /plumb auto-approve on
  when: the prompt hook reads it
  then: it is not taken as the command; those count only when typed
proof:
  plan: 'Recommended: in a live Claude Code session the agent walks the owner-entry-point table; for each
    owner capability the owner types /plumb (once as /plumb:plumb) with plain words and sees it answered
    with no id asked for, and /plumb approve with an id is shown read as an answer rather than run. The
    owner decides whether this live walk or a recorded transcript of it is the proof.'
  kind: live-session
