id: SR-171
title: A request is analysed only when the owner types /plumb clarify
statement: 'The request check runs only for typed /plumb clarify <words>: those words get the read-back,
  questions and the edit hold; an ordinary message runs no request check, raises no read-back or question
  card and closes no edit hold; the answer reader still reads a message for an answer while a card is
  waiting or the previous reply showed records, and nothing runs when neither is'
examples:
- id: EX-1
  given: no card is waiting and the previous reply showed no records
  when: you type 'make the status line show the branch name'
  then: no model runs, no card is raised and edits are not held
- id: EX-2
  given: no card is waiting
  when: you type '/plumb clarify make the status line show the branch name'
  then: 'the words are checked: a read-back card is raised; edits are held while the check runs and until
    any question it asks is answered'
- id: EX-3
  given: a question card is waiting
  when: you type 'go with the first option'
  then: the message is read as an answer to that card, and no request check runs
- id: EX-4
  given: the agent is asked to use a workflow for work you already asked for
  when: you type '/plumb clarify use a workflow to dispatch this update'
  then: no question about how to carry it out is raised; 'this update' is taken from your last message
proof:
  plan: You type an ordinary request and nothing is asked or held; you type /plumb clarify with words
    and a read-back card appears; you answer yes while it waits and it is read as the answer; the next
    ordinary message runs nothing.
