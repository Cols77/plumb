---
id: SR-115
title: The owner turns auto-approval on or off from Claude Code with a...
statement: /plumb auto-approve on|off, typed by the owner as a whole message and seen by the prompt hook,
  writes the owner's config event exactly as plumb config auto-approve does in the terminal; the SP7 settings
  button does the same. The agent running the command, or editing config.yaml, changes nothing.
examples:
- id: EX-1
  given: the owner types '/plumb auto-approve on' as a whole message
  when: the prompt hook reads it
  then: a config event by the owner via typed command is logged and auto-approval is on
- id: EX-2
  given: the agent runs plumb config auto-approve on under the session marker
  when: the command runs
  then: it is refused and nothing is logged
- id: EX-3
  given: the owner writes 'please turn auto-approve on, thanks' in a sentence
  when: the prompt hook reads it
  then: nothing changes; the reader may raise a card offering the switch
