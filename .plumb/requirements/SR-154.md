title: Only requests about the system being built raise a card
statement: The commanded request check (/plumb clarify) raises a read-back or question card only for a
  message that starts or changes something in the repository's own system (behaviour, code, tests, docs,
  records); a message that operates Claude Code, tools or the machine, or only asks a question, raises
  no card and opens the hold

  given: the owner types '/plumb clarify claude plugin marketplace update plumb' and '/plumb clarify claude

  when: the request check reads it
  then: no card is raised and the hold opens
- id: EX-2

  when: the request check reads it
  then: no card is raised
