---
id: SR-332
title: plumb's status shows once, in the band above the prompt
statement: A one-line status in plumb's small band above the prompt shows the state (aligned, awaits you,
  drift, failing, regression), the intent in plain words and the counts with how many the judge approved,
  read from the session state file without loading records or running tests; the band can be hidden; the
  mod pins no second copy of that line under the prompt, and a band that cannot connect says why in one
  line (SR-264).
examples:
- id: EX-1
  given: a snapshot with 12 of 14 requirements agreed, 2 of them approved by the judge, and one question
    waiting for the owner
  when: the band renders
  then: it shows "awaits you", the intent title and "12/14 agreed (2 by the judge)", with no record id
- id: EX-2
  given: no judge approval exists
  when: the status renders
  then: no "by the judge" count appears
- id: EX-3
  given: the ASCII setting is on
  when: the status renders
  then: it contains only ASCII characters
- id: EX-4
  given: a session state file written by the last hook
  when: the band draws its status
  then: it reads one line from that file without reading the records
- id: EX-5
  given: nothing awaits the owner
  when: the band draws
  then: it is one line (the state and a plain summary of the intent) with a Hide button
- id: EX-6
  given: records written this turn that the judges are still checking, and no question waiting
  when: the status renders
  then: it does not say "awaits you"
- id: EX-7
  given: the band is connected and drawing
  when: the status changes during a session
  then: no status notice is pinned under the prompt; the status shows only in the band
- id: EX-8
  given: the band cannot connect
  when: a session starts
  then: one line says why the band is off, as SR-264 states
proof:
  plan: In a live Claude Code session in this repository with the plugin enabled, the owner sees plumb's
    status once, in the band above the prompt, and no plumb line under the prompt; with the band unable
    to connect, one line says why.
