---
id: SR-078
title: The owner hears when another worktree or branch changes the same...
feature: FEAT-006
statement: The session brief, the prompt hook's delta and the status line warn when another worktree or
  local branch is changing a record this session changes or works on, one line per record ("SR-005 'relay
  checks' is also being changed on branch feat-x"); the delta repeats a warning only when the other side's
  version changed, and nothing is shown when there is no overlap.
examples:
- id: EX-1
  given: worktree feat-x has edited SR-005
  when: a session starts in main's worktree
  then: the brief says SR-005 "relay checks" is also being changed on branch feat-x
- id: EX-2
  given: that warning was injected once this session
  when: the next prompt is about relay checks again and feat-x has not changed SR-005 since
  then: no line is repeated
- id: EX-3
  given: a branch without a worktree whose commits changed SR-007
  when: a session starts
  then: the brief names SR-007 and that branch
- id: EX-4
  given: no other worktree or branch changes a record this session touches
  when: the hooks run
  then: no awareness line is injected and the status line shows no overlap
