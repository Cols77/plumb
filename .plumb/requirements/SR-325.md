---
id: SR-325
title: Every plumb failure opens a debug case at once
feature: FEAT-008
statement: 'When a plumb hook, job or command errors, a step refuses what a requirement says it handles,
  or a judge job fails for the third time, plumb writes one debug case (what failed, where, the log entry,
  state open) the moment it happens, in the background and without holding the turn; the turn-end line
  stays quiet about it. plumb debug lists the open cases and runs them on demand: it reruns each case''s
  step once, says what each did and what it still needs, and counts the cases open and resolved.'
examples:
- id: EX-1
  given: a plumb hook raises an error during a turn
  when: the error is caught
  then: one debug case is written with the error and its log entry, the turn is not held, and the turn-end
    line says nothing about it
- id: EX-2
  given: the repin step refuses a link it should handle (a decision pinned to a reworded requirement)
  when: the turn-end check runs
  then: one debug case is written naming the link and the refusal, and the owner is asked nothing
- id: EX-3
  given: three open cases
  when: the agent runs plumb debug
  then: each case's step is rerun once and the output lists each case as resolved, would resolve or open
    with why, and counts them
- id: EX-4
  given: a case whose rerun passes
  when: plumb debug finishes
  then: the case is marked resolved and the next plumb debug counts it resolved
- id: EX-5
  given: a judge job that failed at three turn ends in a row
  when: the third failure is logged
  then: one debug case is written for it and the job is not queued again by the turn end
proof:
  plan: 'Acceptance tests with the models stubbed: a planted hook error, a planted refusal and a thrice-failed
    job each leave one case file; plumb debug lists and reruns them and counts resolved and open.'
