id: SR-036
title: Escalation to an up-front spec is suggested on the concept's triggers, once
feature: FEAT-002
statement: plumb suggests an up-front spec when a request would change more than 3 requirements or touch
  more than one feature, contradicts a confirmed record, touches shared surfaces, has hard-to-undo effects,
  leaves two or more decisions that matter unconfirmed, or when the diff passes 400 lines or 10 files
  without a confirmed escalated set. The suggestion is one line and never a question; a declined suggestion
  is logged and not repeated for the same intent.
examples:
- id: EX-1
  given: a prompt matching records of FEAT-001 and FEAT-003
  when: the escalation check runs
  then: it suggests an up-front spec with the reason "touches 2 features"
- id: EX-2
  given: a turn whose diff has 450 changed lines and no confirmed escalated set
  when: the stop hook asks for suggestions
  then: the diff-size trigger fires
- id: EX-3
  given: the owner declined the suggestion for INT-021
  when: the same trigger fires again for INT-021
  then: no suggestion is shown and an escalation-declined event exists
