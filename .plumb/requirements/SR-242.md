---
id: SR-242
title: Verdicts come from one cascade, JEV first, else the judge model,...
feature: FEAT-002
statement: Every verdict, a record against the owner's words or a stale link's repin, asks JEV first;
  above its threshold calibrated on the owner's labels with no false accept, JEV's verdict stands; below
  it, with JEV not configured or its version drifted, the configured judge model gives it, logged with
  the model's name. judge_model governs verdicts, their evaluation run and the calibration fingerprint;
  understand.model reads the owner's words.
examples:
- id: EX-1
  given: JEV gives 0.95 for an intent's interpretation and the calibrated threshold is 0.43
  when: the verdict is asked
  then: the verdict is supported on JEV's answer, the judge model is not called, and the fast track may
    use it
- id: EX-2
  given: JEV gives 0.3 for a requirement's example restatement
  when: the verdict is asked
  then: the judge model judges it, logged with its name, and the record does not take the fast track on
    JEV
- id: EX-3
  given: judge_model is sonnet
  when: a verdict falls below JEV's threshold
  then: Sonnet gives it, logged with the model's name
- id: EX-4
  given: a JEV intent-change judgment with confidence 0.6, below the threshold
  when: the cascade runs
  then: the judge model judges it; no escalation request is written for the coding agent
- id: EX-5
  given: JEV's probability equals the calibrated threshold exactly
  when: the verdict is asked
  then: the judge model judges it; only a probability above the threshold stands on JEV
- id: EX-6
  given: thresholds validated against jev-1.13.0
  when: JEV resolves typesafe/jev-1.13-20260917, or jev-1.14
  then: the dated OpenRouter name is the same version and a confident answer is accepted with version_drift
    false; jev-1.14 is drift and the judge model judges
- id: EX-7
  given: judge_model is sonnet and understand.model is haiku
  when: the evaluation run over the labelled set is made
  then: Sonnet judges and the run log names sonnet
- id: EX-8
  given: the same settings
  when: a logged calibration records its fingerprint
  then: the fingerprint names sonnet as the judge model
- id: EX-9
  given: the same settings
  when: a clarify or read job runs
  then: Haiku reads the owner's words, as understand.model says
- id: EX-10
  given: judge_model changes after a logged calibration
  when: the stale check runs
  then: the fast track stays on at the 0.9 floor (DEC-143); the evaluation set is rerun before a calibrated
    threshold applies again, as for a prompt change
- id: EX-11
  given: an edit adds a new command to commands.py and JEV gives 0.95 that a requirement's repin path
    is untouched, above the calibrated threshold
  when: the stale link is resolved
  then: it is repinned on JEV's answer and the judge model is not asked
- id: EX-12
  given: JEV gives 0.4 for a requirement's stale link
  when: the link is resolved
  then: the judge model judges it with the requirement and the diff; on unchanged it is repinned
- id: EX-13
  given: no labelled set has set JEV's threshold yet, or JEV is unreachable
  when: a link is resolved
  then: JEV is skipped and the judge model judges; nothing is repinned on a guess
proof:
  plan: 'Recommended: in a live session with judge_model set to sonnet and JEV unsure on one of two small
    intents, the owner sees the plumb line say one record was approved on JEV''s verdict and the other
    on Sonnet''s, and /plumb jev status name Sonnet as the judge model. The owner decides whether this
    is the proof.'
  kind: command
