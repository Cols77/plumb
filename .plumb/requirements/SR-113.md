id: SR-113
title: A code change that no longer matches an aligned record goes to the...
statement: 'When a stale link''s change alters what a requirement relies on, plumb first checks whether
  the requirement still agrees with the intent it derives from. If the requirement and its intent disagree,
  the record is reworded or brought to the owner as before. If they agree, the code moved away from the
  owner''s intent: the owner gets a card by title, in the owner''s words, with two lines of context (SR-129),
  naming the intent, the requirement and the change, unless the change plainly should not have been made
  (it breaks an example with no request behind it), in which case it goes back to the agent with the change,
  its turn and the requirement it breaks, to be fixed as development work rather than asked about.'
examples:
- id: EX-1
  given: INT-029 and SR-038 agree, and a turn about cold-start timing edits the contradiction check so
    a contradicting prompt is no longer flagged
  when: the stale link is resolved
  then: the change goes back to the agent with that turn's request, the diff and SR-038's broken example,
    as development work, and the owner is not asked
- id: EX-2
  given: INT-008 and SR-012 agree, and a turn the owner asked for adds a list-style summary to the end-of-turn
    hook
  when: the stale link is resolved
  then: the owner gets a card by title and in plain words (SR-129) about the intent, the requirement,
    the change and the request behind it, with options such as keep the change and reword, or undo it
- id: EX-3
  given: SR-081 still says the heuristic judges compatibility while INT-029 says there is no heuristic
  when: its stale link is resolved
  then: the requirement is reworded to agree with INT-029 (or carded to the owner when the wording is
    a real question), not sent back to development
- id: EX-4
  given: a change to a shared file leaves what the requirement relies on as it was, and the tests pass
  when: the stale link is resolved
  then: the link is repinned and neither the owner nor the agent is asked
- id: EX-5
  given: it is unclear whether the change was wanted
  when: the stale link is resolved
  then: the owner gets the card; nothing is sent back to development on a guess
