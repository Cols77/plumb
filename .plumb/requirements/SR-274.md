---
id: SR-274
title: Background processes open no window and outlive the hook that...
feature: FEAT-008
statement: 'Every background process plumb starts goes through one launch helper: on Windows with no console
  window (CREATE_NO_WINDOW with a new process group, never a detached process), for it and for the commands
  it runs; on macOS and Linux in its own session. It keeps running after the hook that started it exits.
  It starts without the variables a git hook exports (GIT_DIR and kin), so git in it finds its repository
  from its own folder, and a scratch repository it creates never rewrites the host repository''s shared
  config; a test run drops them too.'
examples:
- id: EX-1
  given: a Windows machine
  when: the stop hook starts the understand worker
  then: no console window appears for the worker nor for the commands it runs
- id: EX-2
  given: a Windows machine
  when: the background test map starts
  then: no console window appears for it nor for its git and pytest calls
- id: EX-3
  given: the hook that started a background process has exited
  when: the process runs on
  then: it keeps running to the end of its work
- id: EX-4
  given: macOS or Linux
  when: a background process starts
  then: it starts in its own session, as before
- id: EX-5
  given: a post-commit hook in a worktree that exported the worktree's GIT_DIR and starts a background
    plumb process
  when: that process runs git init in a scratch folder
  then: the scratch folder gets its own repository and the host repository's core.bare and core.fileMode
    are unchanged
- id: EX-6
  given: a test run started from a git hook that exported GIT_DIR
  when: any test fixture runs git init in a temporary folder
  then: the host repository's config is unchanged, because the test run drops the hook's git variables
    before any fixture runs
proof:
  plan: 'Recommended for the owner to decide: in a live Claude Code session on this Windows machine the
    owner works through a turn that starts the worker and the background test map; no console window opens
    at any point.'
  kind: live-session
