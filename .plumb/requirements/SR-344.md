---
id: SR-344
title: plumb evaluate runs a task's scripted requests through a cheap...
statement: plumb evaluate <simple|complex> [--model haiku|sonnet] creates a fresh scratch repository (git
  init, plumb init, plumb hooks install), then sends the task's scripted owner requests one per turn to
  a headless Claude Code session resumed between turns, loading the scratch repository's own settings
  and the task's brief for the agent appended to its system prompt. The run's folder under .plumb/eval/runs/<stamp>-<task>-<model>/
  holds transcript.jsonl (every owner message and agent reply), score.json, issues.jsonl and a copy of
  the scratch repository's .plumb/ records and log. Without the claude command or the model, it prints
  one line saying what is missing and runs nothing.
examples:
- id: EX-1
  given: the claude command is on this machine
  when: plumb evaluate simple runs with a scripted model double
  then: a scratch repository is made with plumb set up, each of the task's requests is sent as one turn,
    and the run's folder holds transcript.jsonl, score.json, issues.jsonl and the copied .plumb/
  quote: from one plumb dev command like plumb evaluate simple or plumb evaluate complex to be able to
    run this benchmark test
  prompt: 1a57f3404cec914b
- id: EX-2
  given: --model sonnet
  when: the run starts
  then: every agent turn is run with the sonnet model and the run's folder is named for it
  quote: see how much haiku or Sonnet is able to implement autonomously using plumb tools
  prompt: 1a57f3404cec914b
- id: EX-3
  given: no claude command on this machine
  when: plumb evaluate simple runs
  then: one line says the claude command was not found and no scratch repository is made
- id: EX-4
  given: a request's agent turns reach the cap (25 turns or the time limit)
  when: the turn ends
  then: the request is marked capped in the transcript and the next request is sent
