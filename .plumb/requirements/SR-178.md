---
id: SR-178
title: Browser follow-up reaches the matching agent turn truthfully
statement: Browser answers queue their follow-up for the source agent session; that session's next prompt
  hook delivers the context once without treating generated text as a typed owner approval. The browser
  distinguishes queued and delivered follow-ups and does not claim autonomous execution or successful
  repair.
examples:
- id: EX-1
  given: A browser answer queues a source-session follow-up
  when: Another session starts a turn
  then: The message remains queued for its intended session
- id: EX-2
  given: The intended session has a queued follow-up
  when: Its next turn hook emits context
  then: The follow-up is included once and delivery is shown separately from verification
proof:
  plan: Run matching and mismatching prompt hooks against queued browser answers, capture emitted context
    and delivered states.
  kind: hook
