---
id: SR-210
title: The agent can never write an approval
feature: FEAT-008
statement: Only the judge worker's entries and plumb's reading of the owner's own answers write an approval.
  Every approval-writing step the agent runs (approve, confirm, revoke, relay, posting a study-room answer)
  is refused with exit 3 and writes nothing, also on a host that cannot mark the agent's session; an approval
  entry written by hand is rejected by validation.
examples:
- id: EX-1
  given: the agent's session
  when: the agent runs plumb approve, plumb confirm or plumb revoke on a requirement
  then: plumb refuses with exit 3 as no longer existing and writes nothing
- id: EX-2
  given: a host whose adapter cannot set the session marker, and an agent shell with no terminal
  when: the agent tries any approval-writing step with "y" piped in
  then: plumb refuses with exit 3 and writes nothing
- id: EX-3
  given: an agent writes an approval entry by hand with an owner quote, or one saying the owner answered
    in the study room with no question put at that version
  when: plumb checks the log
  then: 'the entry is not accepted and validation reports it: only the judge worker''s entries and plumb''s
    reading of the owner''s own answers approve'
- id: EX-4
  given: the agent's shell
  when: the agent tries to post a study-room answer
  then: it is refused and nothing is written
- id: EX-5
  given: the agent runs plumb relay
  when: the command is looked up
  then: it is refused as no longer existing, with no help line
proof:
  plan: 'Recommended: in a live session the agent is asked to approve a requirement itself, to relay an
    approval and to write one by hand; each attempt is shown refused or reported by validation, and the
    record stays proposed. The owner decides whether this is the proof.'
  kind: live-session
