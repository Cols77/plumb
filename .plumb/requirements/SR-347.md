title: The issues the model finds with plumb are kept in a file for later...
statement: 'The agent''s brief tells it that whenever plumb behaves wrongly (a refusal it cannot explain,
  an error, a command or a hook line that contradicts plumb''s skills or its own words, a question it
  cannot answer) it appends one JSON line to .plumb/eval-issues.jsonl in the scratch repository: when,
  the plumb command or hook, what it expected, what it got, and the context. After the run, these lines
  are copied to the run''s issues.jsonl and appended, with the run''s id, task and model, to .plumb/eval/issues.jsonl
  in plumb''s own repository, which accumulates across runs.'
