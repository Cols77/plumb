---
id: SR-103
title: The clarifier asks at most three questions up front, before building
feature: FEAT-008
statement: When the owner's message starts or changes intent, a model drafts the read-back with will,
  won't, assumptions and two or three concrete examples, and finds the gaps that change what gets built;
  the owner gets one card with at most three questions, each with suggested answers and a recommended
  one, and the smaller gaps as assumptions on the same card; more than three such questions escalate to
  a short spec session; a request with no such gap produces no card and work starts at once. The agent
  does not build until the card is answered.
examples:
- id: EX-1
  given: a request "let users export their data" with format and scope unspecified
  when: the clarifier runs
  then: one card asks which format and which data, each with suggested answers, and lists the remaining
    gaps as assumptions
- id: EX-2
  given: a request that fully maps to a confirmed requirement
  when: the clarifier runs
  then: no card; work starts
- id: EX-3
  given: a request with five gaps that each change what gets built
  when: the clarifier runs
  then: an escalation to a spec session is offered instead of a card
