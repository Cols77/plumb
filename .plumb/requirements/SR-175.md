title: Drift is checked for coverage before any card
statement: 'When code or tests linked to a requirement change and the requirement did not, plumb first
  checks the requirement is still covered: its linked tests pass and a model judges the meaning kept;
  then it repins and logs, with no card; a card is raised only when the requirement should change fundamentally
  (a confirmed example’s test weakened or deleted with no replacement, or the model says the statement
  or an example would now say something else) or when two confirmed records contradict'
