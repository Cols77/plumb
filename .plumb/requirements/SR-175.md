id: SR-175
title: Drift is checked for coverage before any card
statement: 'When code or tests linked to a requirement change and the requirement did not, plumb first
  checks the requirement is still covered: its linked tests pass and a model judges the meaning kept;
  then it repins and logs, with no card; a card is raised only when the requirement should change fundamentally
  (a confirmed example’s test weakened or deleted with no replacement, or the model says the statement
  or an example would now say something else) or when two confirmed records contradict'
examples:

  given: src/plumb/commands.py is refactored under confirmed SR-003
  when: the stale check runs
  then: SR-003’s tests pass, the model judges the meaning kept, the link is repinned and logged; no card
  quote: First the system should verify whether the requirement is still covered
  prompt: 03a951b08a8ba7c1
- id: EX-2
  given: a confirmed example’s test is deleted with no replacement
  when: the stale check runs
  then: a card asks whether the requirement should change
  quote: Only raise a card to change the requirement if the requirement should be changed fundamentally,
    or when two confirmed records contradict
  prompt: 03a951b08a8ba7c1
- id: EX-3

  when: the stale check runs
  then: one card asks which wins
- id: EX-4
  given: the model says the meaning changed in wording only
  when: the stale check runs
  then: a rewording is proposed as an unconfirmed edit and the link repinned; no card
