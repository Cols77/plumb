id: SR-223
title: The clarifier reads the owner's words in context and asks every...
feature: FEAT-008
statement: Inside the loop the clarifier reads the owner's words with the agent's last reply, the owner's
  recent messages and repository facts, and acts only on a change to the system being built. A gap with
  a better-supported option becomes a labelled, flippable assumption; every gap whose answer changes what
  gets built is asked as soon as it arises, specific, with options and a recommendation, through the question
  tool, those that hinge on one principle asked once as that principle, with no limit per turn (SR-361).
  The question rules are written once, in the plumb-records skill, and plumb-clarify points to it (SR-379);
  the hooks remind the agent to ask, and outside the intent loop a waiting question never denies a tool
  call; inside the loop, edits wait while the loop's gate is closed, because the loop does not build
  until its judge step passes (gate.sh; SR-378, DEC-391, DEC-410). The owner never reads the interpretation itself. The owner's answers are logged
  as their words and never asked again; nothing of the clarifier's self-questioning is recorded.
examples:
- id: EX-1
  given: the agent's last reply listed review findings
  when: the owner says 'resolve all of the findings using a workflow'
  then: 'no question asks which findings: the interpretation assumes the findings listed above and the
    work goes on'
- id: EX-2
  given: the agent diagnosed why the panel does not show
  when: the owner says 'apply the proposed fixes for this issue'
  then: no question asks which issue
- id: EX-3
  given: the owner refers to an issue found in another recent chat of the same project
  when: the clarifier runs
  then: it reads that chat's last reply and the owner's last messages there, and no question asks which
    issue
- id: EX-4
  given: the repository is a git repository
  when: the clarifier runs
  then: it never says the folder is not a git repository
- id: EX-5
  given: the transcript cannot be read
  when: the clarifier runs
  then: it runs on the owner's words alone
- id: EX-6
  given: the conversation was compacted
  when: the clarifier runs
  then: the agent's last reply and the compaction summary are given, and the summary is never taken as
    the owner's words
- id: EX-7
  given: the owner types '/plumb intent claude plugin update plumb@plumb' or '/plumb intent are there
    anything to merge on main?'
  when: the clarifier reads it
  then: it finds no change to the system being built, writes no record and asks nothing
- id: EX-8
  given: the owner types '/plumb intent make the status line show the branch name'
  when: the clarifier reads it
  then: a loop opens and its blocking questions, if any, come through the question tool in that turn
- id: EX-9
  given: a request that maps fully to a confirmed requirement
  when: the clarifier runs
  then: no question is asked and the loop goes on
- id: EX-10
  given: the request "reminders must always arrive instantly"
  when: the clarifier interprets it
  then: the interpretation carries the assumption "instantly means within a minute" and no question is
    asked
- id: EX-11
  given: a request with three open gaps, each with a recommended option
  when: the clarifier runs
  then: three labelled assumptions and no question
- id: EX-12
  given: the request "let users export their data" with format and scope unspecified, and four drafted
    questions, one answered by a confirmed record and one whose options build the same thing
  when: the clarifier settles its questions
  then: exactly the two that change what gets built are asked through the question tool, ranked, with
    suggested answers and a recommended one; the other gaps are labelled assumptions
- id: EX-13
  given: the request "never keep anyone's email address, and email them their reminders"
  when: the clarifier runs
  then: exactly one question is asked through the question tool, since the answer changes what gets built
- id: EX-14
  given: a request that could change a public interface two ways, neither favoured by any record or the
    conversation
  when: the clarifier runs
  then: one question is asked with both ways and what each costs to undo, through the question tool (no
    question goes to the study room, INT-114)
- id: EX-15
  given: a request with two or three gaps and no better-supported option for any
  when: the clarifier returns them
  then: all are asked with the question tool in the same turn, before building, not one per turn and never
    on a card; no spec session is offered for the count alone
- id: EX-16
  given: the agent needs to know now or later, a name, or which of two files the owner meant
  when: it asks
  then: the question tool asks it, as the rulebook (plumb-records) says and plumb-clarify points to (SR-379)
- id: EX-17
  given: the owner answers a question with 'whatever works'
  when: the agent reads the answer
  then: the question is asked again; no option is taken for the owner
- id: EX-18
  given: the owner answered the clarifier's questions through the question tool
  when: the loop goes on
  then: the answers are logged as the owner's words and carried by the interpretation, and nothing asks
    them again
- id: EX-19
  given: any clarification
  when: it ends
  then: nothing about the clarifier's self-questioning is recorded and nothing waits on it
- id: EX-20
  given: a question that needs the idea of a confirmed requirement
  when: it is put to the owner
  then: it explains that idea in one plain sentence before using it, and names no record id
- id: EX-21
  given: the interpretation has four will lines, one won't and two assumptions
  when: the owner is asked the remaining question
  then: the owner sees the question and its options only, never the will, won't or assumed lines
proof:
  plan: 'Recommended for the owner to decide: in a live session on a scratch repository, the owner types
    /plumb intent let users export their data right after the agent listed some findings; the owner sees
    exactly the questions that change what gets built through the question tool, all in one turn, with
    a recommended option each, and none about what the conversation already says; the plumb line lists
    the labelled assumptions.'
