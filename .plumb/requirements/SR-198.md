---
id: SR-198
title: Drift on linked code is resolved in the turn that makes it
feature: FEAT-002
statement: After each edit plumb tells the agent which links it made stale, and the end-of-turn hook holds
  the turn while a link this turn made stale is unresolved, at most hooks.stale_holds_max times (3 by
  default); after that the turn ends and the unresolved link becomes one question through the question
  tool. A check that waits on an unreachable judge never holds the turn. The link is repinned when covering
  tests pass and the judge says the meaning is kept, a record that disagrees with its intent is reworded,
  an unrequested intent-breaking change goes back to the agent, and the owner is asked through the question
  tool only when confirmed intent would change. Workflow agents get the same.
examples:
- id: EX-1
  given: the agent edits a function that SR-005's implemented_by link pins
  when: the edit hook runs
  then: the agent is told in one line that SR-005's link to that file is stale
- id: EX-2
  given: an intent is reworded and SR-032 derives from it
  when: the rewording is recorded
  then: the agent is told SR-032 may no longer agree with that intent
- id: EX-3
  given: a link this turn made stale and not yet resolved
  when: the agent tries to end its turn
  then: the end-of-turn hook keeps the turn open and names the link
- id: EX-4
  given: a link that was already stale before the turn began
  when: the turn's first edit is checked
  then: it is listed to the agent once and does not keep the turn open
- id: EX-5
  given: src/plumb/commands.py is refactored under confirmed SR-003 and SR-003's covering tests pass
  when: the agent resolves the stale link
  then: the judge (JEV above its calibrated threshold, else the configured judge model) is shown SR-003's
    statement and examples next to the diff, says the meaning is kept, and the link is repinned and logged
    with its one-sentence reason; the owner is not asked
- id: EX-6
  given: an edit only reformatted a file and its linked tests pass
  when: the agent resolves the link
  then: it is repinned without involving the owner
- id: EX-7
  given: a change removes the tests checking a confirmed example of SR-005 with no replacement
  when: the agent resolves those links
  then: each repin is refused with the judge's reason naming the examples no longer checked, and the link
    stays stale until the record is reworded or the owner answers, through the question tool, whether
    the requirement should change
- id: EX-8
  given: an edit changes what a requirement the owner confirmed says the system does, and the owner asked
    for that change
  when: the agent resolves the link
  then: the owner gets one question through the question tool naming the requirement, the change and the
    recommended resolution first
- id: EX-9
  given: the judge cannot be reached
  when: the agent resolves a stale link
  then: nothing is repinned, the link stays stale and plumb says once that judging is unavailable; no
    verdict is decided by rule, and the turn is not held for the check that waits on the judge
- id: EX-10
  given: the judge answers that the diff is too large to judge
  when: the agent resolves the link
  then: nothing is repinned and the refusal says why
- id: EX-11
  given: a link this turn made stale is still unresolved after the end-of-turn hook held the turn hooks.stale_holds_max
    times (3 by default), the last hold saying 'Held 3 of 3'
  when: the agent tries to end its turn again
  then: the turn ends, the link stays stale, and it becomes one question through the question tool with
    the recommended resolution first
- id: EX-12
  given: the judge says the meaning changed in wording only
  when: the stale link is resolved
  then: the record is reworded, the rewording passes the judge and is recorded as judge-approved, and
    the link is repinned; the owner is not asked
- id: EX-13
  given: INT-029 and SR-038 agree, and a turn about cold-start timing edits the contradiction check so
    a contradicting prompt is no longer flagged
  when: the stale link is resolved
  then: the change goes back to the agent with that turn's request, the diff and SR-038's broken example,
    as development work, and the owner is not asked
- id: EX-14
  given: SR-081 still says the heuristic judges compatibility while INT-029 says there is no heuristic
  when: its stale link is resolved
  then: the requirement is reworded to agree with INT-029, not sent back to development
- id: EX-15
  given: INT-008 and SR-012 agree, and a turn the owner asked for adds a list-style summary to the end-of-turn
    hook
  when: the stale link is resolved
  then: 'the owner gets one question through the question tool, in plain words, naming what SR-012 says
    and what changed, with the agent''s recommendation first: keep the change and reword SR-012, or undo
    it'
- id: EX-16
  given: it is unclear whether the change was wanted
  when: the stale link is resolved
  then: the owner is asked through the question tool; nothing is sent back to development on a guess
- id: EX-17
  given: a change to a shared file leaves what the requirement relies on as it was, and the tests pass
  when: the stale link is resolved
  then: the link is repinned and neither the owner nor the agent is asked
- id: EX-18
  given: a workflow agent changes code a requirement links to
  when: its work ends
  then: the stale link is reported to it to resolve, as it is to the main session
- id: EX-19
  given: a link pinned to a file version that was never committed
  when: the work is committed
  then: the pinned version stays readable, so the link shows stale after the commit, is held like any
    other new stale link, and a repin can judge the change from the pinned text
- id: EX-20
  given: the agent wants to know what would be repinned
  when: it asks plumb for a repin dry run
  then: the judge's verdicts are listed with their reasons; no test runs and no pin changes
proof:
  plan: 'Recommended for the owner to decide: in a live session on a scratch repository with one confirmed
    requirement, the agent refactors its code (the plumb line shows the link repinned with the judge''s
    reason, no question), then deletes the test of one confirmed example (the turn stays open naming the
    link for at most three holds, and one question reaches the owner through the question tool).'
  kind: live-session
