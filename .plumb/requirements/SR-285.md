title: plumb's MCP server is read-only
feature: FEAT-004
statement: plumb's MCP server speaks JSON-RPC 2.0 over stdio with the standard library only and exposes
  six read-only tools (brief, relevant, show, explain, impact, drift) returning what plumb shows the agent;
  it has no write tool and leaves .plumb outside its cache unchanged. Adding it to a host writes plumb's
  entry once into that host's config and keeps the owner's servers.
examples:
- id: EX-1
  given: a client sends initialize then tools/list
  when: the server answers
  then: the six tools are listed, each with readOnlyHint true, and nothing else
- id: EX-2
  given: a repository with records and logs
  when: every tool is called
  then: every file under .plumb outside cache is byte-identical afterwards
- id: EX-3
  given: a client calls an unknown method
  when: the server answers
  then: it returns JSON-RPC error -32601
- id: EX-4
  given: a .mcp.json, .codex/config.toml or Hermes config.yaml with the owner's own servers
  when: plumb's MCP entry is added for that host twice and then removed
  then: plumb's entry is written once and removed, and the owner's servers are untouched
proof:
  plan: 'Recommended: the agent adds plumb''s MCP server to a host, lists its tools there (six, all read-only),
    calls each, and shows the owner that .plumb outside the cache is unchanged and the owner''s other
    servers are still listed. The owner decides whether this is the proof.'
