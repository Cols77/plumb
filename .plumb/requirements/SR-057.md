id: SR-057
title: plumb mcp serve is a read-only MCP server on stdio
feature: FEAT-004
statement: plumb mcp serve speaks JSON-RPC 2.0 over stdio with the standard library only and exposes the
  read-only tools plumb_brief, plumb_relevant, plumb_show, plumb_explain, plumb_impact and plumb_drift,
  which return what the CLI shows; it has no write tool, and calling every tool leaves .plumb outside
  cache unchanged.
examples:
- id: EX-1
  given: a client sends initialize then tools/list
  when: the server answers
  then: the six tools are listed, each with readOnlyHint true, and nothing else
- id: EX-2
  given: a repository with records and logs
  when: every tool is called
  then: every file under .plumb outside cache is byte-identical afterwards
- id: EX-3
  given: a client calls an unknown method
  when: the server answers
  then: it returns JSON-RPC error -32601
