id: SR-389
title: plumb names the model of a stage by one of four capability levels
statement: 'Wherever plumb chooses a model for a stage (its judge, its link checks, its self-fix, its
  shipped workflows), the stage names one of four capability levels: Haiku-like, Sonnet-like, Opus-like,
  Fable-like. The model of each level is a setting, so a model that is not Anthropic''s can fill a level;
  unset, the levels are Haiku, Sonnet, Opus and Fable.'
examples:
- id: EX-1
  given: no level set
  when: a shipped workflow starts a stage at the Sonnet-like level
  then: the stage's agent runs on Sonnet
- id: EX-2
  given: a shipped workflow given another model for the Sonnet-like level
  when: it starts a stage at that level
  then: the stage's agent runs on the model given
- id: EX-3
  given: the Sonnet-like level set to another model in plumb's settings
  when: plumb's self-fix starts its fix stage
  then: the stage runs on that model
- id: EX-4
  given: a setting that names a level plumb does not know
  when: plumb reads its settings
  then: it refuses the setting and names the four levels
