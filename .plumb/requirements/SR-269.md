---
id: SR-269
title: A study-room answer applies to exactly what was shown and reaches...
feature: FEAT-007
statement: An answer in the study room is recorded against exactly the content shown and the room shows
  the resulting state, which survives a restart of the room's server; it is queued for the session the
  question came from and reaches that session's agent once, as the owner's answer to that question, never
  as words the owner typed, the room showing delivered apart from verified. An answer naming an option
  the question lacks is refused and leaves nothing; a requested custom combination keeps the question
  open. The band's registration and each answer's surface are kept.
examples:
- id: EX-1
  given: an answer is selected on a displayed question
  when: plumb records it
  then: it is recorded against exactly the displayed content and the room shows the actual resulting state
- id: EX-2
  given: plumb's band is registered in a Claude Code session
  when: the room opens and an answer is given
  then: the band's registration is kept and each answer records which surface it came from
- id: EX-3
  given: an answer queues a follow-up for its source session
  when: another session starts a turn
  then: the follow-up stays queued for its intended session
- id: EX-4
  given: the intended session has a queued follow-up
  when: its next turn hook runs
  then: the follow-up reaches the agent once, as the owner's answer to that question, never as words the
    owner typed, and the room shows delivered apart from verified
- id: EX-5
  given: an answer was given in the room
  when: the room's server restarts
  then: the answer is still recorded and the question shows under 'done'
- id: EX-6
  given: an answer names an option the question does not have
  when: the next prompt hook runs for that session
  then: the answer is refused, no follow-up is delivered and nothing durable remains
- id: EX-7
  given: a conflict question with no resolution yet
  when: the owner asks for a custom combination
  then: the question stays open awaiting the combination and is not shown as done
proof:
  plan: 'Recommended for the owner to decide: the owner answers one question in the study room and sees
    it move to ''done'' while the source Claude Code session receives the answer once on its next turn;
    the room''s browser interaction suite, run with screenshots, backs it.'
  kind: live-session
