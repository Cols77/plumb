id: SR-197
title: The proof of an intent is stated by the owner in the loop and...
statement: During the loop the owner states how they will see the intent working; the proof is recorded
  on the intent's requirements as a plan whose kind is live-session, hook, command or other; the plan
  of updates includes the code the proof needs; the build is called done only once the proof has been
  shown and its evidence recorded.
examples:
- id: EX-1
  given: the owner states the proof as 'I open the panel and see the card'
  when: the loop writes the plan
  then: the plan carries that proof as a live-session proof and the code it needs
  quote: Proof of intent should also be specified by the user and supported by the system.
  prompt: 38baaadbee5c1487
- id: EX-2
  given: the build is finished and the proof was not shown
  when: the agent calls the intent done
  then: plumb says the proof is missing and the intent stays open
proof:
  plan: state a proof on a scratch intent, finish the build without showing it, and see plumb refuse done;
    show it and see the evidence recorded
  kind: command
