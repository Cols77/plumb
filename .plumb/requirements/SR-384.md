id: SR-384
title: An agent cannot change main's checkout outside the expected process
statement: 'In an adopted repository''s main checkout (the default branch''s own checkout, not a worktree),
  plumb''s pre-tool hook refuses an agent''s file edit inside the repository, a shell command that writes
  inside the repository (a redirect, an editor or file command, git add, plumb''s record-writing commands),
  and a git commit that is not finishing a merge, and the refusal tells the agent to work on a branch
  in a worktree. Merges and aborting them, git''s clean-up commands, plumb''s landing, git-ignored paths,
  worktrees and paths outside the repository stay allowed. The owner working by hand is not touched. Shell
  parsing does not catch every writing command; the merge hold on stray edits stays behind it. merge.guard_main
  in plumb''s config, on by default, turns it off for a repository. In main''s checkout the end-of-turn
  hook no longer holds the turn for a stale link: it is resolved on a branch.'
examples:
- id: EX-1
  given: an agent in main's checkout
  when: it edits src/app.py with an edit tool
  then: the call is refused and the reason names a worktree
- id: EX-2
  given: an agent whose command begins by changing into a worktree
  when: it edits a file or commits there
  then: the call goes ahead
- id: EX-3
  given: an agent in main's checkout
  when: it runs a shell command that redirects into a repository file, or runs git add, or plumb capture
  then: the call is refused
- id: EX-4
  given: an agent in main's checkout
  when: it runs git commit with no merge in progress
  then: the call is refused; with a merge in progress it goes ahead
- id: EX-5
  given: an agent in main's checkout
  when: it reads files, runs tests, merges a branch, writes a scratch file outside the repository, or
    writes a git-ignored file
  then: the call goes ahead
- id: EX-6
  given: a repository whose config sets merge.guard_main to false
  when: an agent edits in main's checkout
  then: the call goes ahead
- id: EX-7
  given: the owner in their own terminal on main
  when: they edit and commit
  then: nothing refuses them
- id: EX-8
  given: a link goes stale in main's checkout at the end of a turn
  when: the stop hook runs
  then: it does not hold the turn for that link
