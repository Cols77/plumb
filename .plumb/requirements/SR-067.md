---
id: SR-067
title: plumb align judges each edge of a scope, weakest first, without changing any edge
feature: FEAT-005
statement: 'plumb align collects a scope deterministically along existing links (intent, feature, requirement,
  example, test, code, evidence) with a fingerprint. It names empty families as gaps, asks the judge one
  question per edge phrased for its class, and lists edges weakest first. It never creates or removes
  an edge, marks staleness or confirms. When no judge can answer (none set up, judgment disabled, no key,
  or unreachable), it lists every edge as unjudged with no score, says "judging unavailable: <cause>",
  and still reports the gaps. There is no rule-based or term-overlap score.'
examples:
- id: EX-1
  given: SR-034 with EX-2 linked to no test
  when: plumb align SR-034 runs
  then: it reports the gap "SR-034/EX-2 has no test"
- id: EX-2
  given: a backend answering no for the SR-034 to code edge
  when: plumb align runs
  then: that edge is listed first and every link state is unchanged
- id: EX-3
  given: no judge set up
  when: plumb align SR-034 runs
  then: 'every edge is listed as unjudged with no score, it prints "judging unavailable: no judge", and
    the gap "SR-034/EX-2 has no test" is still reported'
