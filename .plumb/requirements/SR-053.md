---
id: SR-053
title: One host-neutral turn API serves every host, with a CLI-only fallback
feature: FEAT-004
statement: Every host adapter turns its events into a TurnEvent and renders the TurnOutput of plumb.hosts.neutral.handle_event
  (agent context, owner lines, at most one block, the status line); plumb turn start and plumb turn end
  give the same output with no hook at all; the same scripted session yields the same agent context, owner
  lines and block for every host value.
examples:
- id: EX-1
  given: a scripted session of session start, a prompt naming SR-001, an edit and a stop
  when: it is driven with host claude-code, codex, pi and hermes
  then: agent_context, owner_lines and block are identical across hosts
- id: EX-2
  given: a host with no lifecycle hooks
  when: the agent runs plumb turn start with the prompt and plumb turn end
  then: the prompt digest is logged, the delta and the summary are printed and both exit 0
- id: EX-3
  given: a host whose prompts reach plumb only through plumb turn start (R13 Q4)
  when: the agent runs plumb turn start with the owner's message
  then: the prompt log entry says via turn, not hook, so a confirmation relayed from that message is labelled
    "self-recorded message"; a host's own prompt hook logs via hook
- id: EX-4
  given: a repository whose session brief reaches the watchdog's hard limit
  when: the agent runs plumb turn start, on the first turn or a later one, with the message on stdin or
    in --prompt-file
  then: 'the owner''s message is logged (via: turn) and turn.json written before the brief runs, so the
    cut brief never drops the prompt, and later turns do not repeat the brief'
