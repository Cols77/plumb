id: SR-196
title: Outside the loop, the edit gate closes only on an intent change
statement: 'Outside the intent loop the hooks keep grounding: the brief, the relevant records, drift at
  the edit, covering tests at the end of the turn. The edit gate closes when a request or an edit would
  contradict or extend what a confirmed record covers and no intent loop has run for that request; it
  opens when the loop reaches a clear intent for it, or when the owner releases it. A request that changes
  nothing a confirmed record covers never closes the gate.'
examples:
- id: EX-1
  given: SR-001 is confirmed with the example add(1, 2) returns 3 and no loop ran
  when: the prompt says make add subtract
  then: the edit gate closes and names SR-001 and its example
- id: EX-2
  given: the same prompt after /plumb intent reached a clear intent for it
  when: an edit tool is called
  then: the edit proceeds
- id: EX-3
  given: no confirmed record covers the status line's colour
  when: the prompt asks to change that colour
  then: the gate stays open and no model runs
