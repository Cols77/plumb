- id: EX-1
  given: the debug workflow cannot find the missing information in the log, the records or the repository
  when: it has exhausted what it can read
  then: it asks the owner one question-tool question about what it needs, in plain words, naming no ids
    or internals
- id: EX-2
  given: the debug workflow finds the missing information in the log
  when: it finishes
  then: the owner is asked nothing

    exactly one plain-words question reaches the owner at the end, and none when it is present.'
