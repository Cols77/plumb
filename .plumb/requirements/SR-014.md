---
id: SR-014
title: Hooks stay within their budgets and never block work on plumb's own failure
feature: FEAT-001
statement: Each hook finishes within its configured budget (session start 1400 ms, prompt 1200 ms, stop
  1400 ms, post-edit 300 ms, the defaults in the configuration) and keeps per-turn overhead well under
  2 seconds apart from model jobs, which run in the background; the settled line and the cards of the
  end-of-turn summary must fit the stop budget. On an internal error or a blown budget a hook exits 0
  and logs instead of blocking.
examples:
- id: EX-1
  given: plumb's own repository
  when: each hook runs as a subprocess
  then: each finishes within its budget
- id: EX-2
  given: a hook raises an internal error
  when: the host calls it
  then: it exits 0 and writes the error to the session error log
- id: EX-3
  given: settled records and open cards to show at the end of a turn
  when: the stop hook runs
  then: the summary with the settled line and the cards is produced within the stop budget
