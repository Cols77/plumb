  a blown budget it exits 0 and logs instead of blocking.

- id: EX-1
  given: plumb's own repository
  when: each hook runs as a subprocess
  then: each finishes within its budget
- id: EX-2
  given: a hook raises an internal error
  when: the host calls it
  then: it exits 0 and writes the error to the session error log
