---
id: SR-177
title: Issue explanations embed existing diagrams safely
statement: When an issue references a diagram-mod HTML or SVG artifact inside the project, the browser
  displays its extracted SVG in the explanation with text alternative and zoom controls. Missing, invalid,
  oversized or escaping artifacts are reported without disabling issue actions; diagram scripts never
  execute in the application DOM.
examples:
- id: EX-1
  given: A card references generated architecture HTML with toolbar icons
  when: The issue is opened
  then: The architecture SVG is displayed above its questions with readable labels
- id: EX-2
  given: A diagram is missing or its path escapes the project
  when: The issue is opened
  then: A clear fallback is shown and the owner's issue choices remain accessible
proof:
  plan: Show an issue diagram in the browser; exercise zoom/download/fallback and test path and script
    isolation.
  kind: live-session
