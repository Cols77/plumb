id: SR-018
title: Evidence is pinned to tree, import closure, test source and environment
feature: FEAT-001
statement: Each test run appends evidence pinned to the tree, the import closure, the test source and
  the environment key, and earlier evidence is reused only on an exact match of all of them.
examples:
- id: EX-1
  given: a test passed with recorded evidence
  when: nothing in its closure, source or environment changed
  then: the evidence is reused
- id: EX-2
  given: the same test
  when: a module it imports changes
  then: the evidence is not reused and the test is selected
