id: SR-282
title: One host-neutral core gives every host the same turn, with a...
feature: FEAT-004
statement: 'Every host''s adapter turns its events into the core''s turn events and shows the core''s
  turn output: agent context, owner lines, at most one block and the status. The same scripted session
  gives the same output on Claude Code, Codex, Pi and Hermes. A host without lifecycle hooks gets the
  same through plumb turn start and plumb turn end, which the agent runs. Events reach only the project
  the adapter was installed in.'
examples:
- id: EX-1
  given: a scripted session of session start, a prompt naming SR-001, an edit and a stop
  when: it is driven with host claude-code, codex, pi and hermes
  then: agent_context, owner_lines and block are identical across hosts
- id: EX-2
  given: a host with no lifecycle hooks
  when: the agent runs plumb turn start with the prompt and plumb turn end
  then: the prompt digest is logged, the delta and the summary are printed and both exit 0
- id: EX-3
  given: a host whose prompts reach plumb only through plumb turn start
  when: the agent runs plumb turn start with the owner's message
  then: the prompt log entry says via turn, not hook, so an approval resting on that message is labelled
    "self-recorded message"; a host's own prompt hook logs via hook
- id: EX-4
  given: a repository whose session brief reaches the watchdog's limit
  when: the agent runs plumb turn start, on the first turn or a later one, with the message on stdin or
    in --prompt-file
  then: 'the owner''s message is logged (via: turn) even when the brief is cut by the watchdog, and later
    turns do not repeat the brief'
proof:
  plan: 'Recommended: the agent drives one scripted session through each of the four hosts and shows the
    owner the four agent contexts, owner lines and blocks side by side, identical, then runs the same
    turn with plumb turn start and end on a host without hooks. The owner decides whether this side-by-side
    is the proof or wants a live session on a second host.'
