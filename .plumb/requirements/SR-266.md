---
id: SR-266
title: The agent gets everything as text
feature: FEAT-005
statement: The agent receives in its own channel, as text, everything plumb knows that bears on its work
  (the session brief, records with their ids, stale links, untraced files, warnings, conflicts and the
  owner's answers), whatever the owner's surface shows and on every host; nothing meant for the agent
  is shown to the owner as if the owner had typed it, and the full/compact/off card setting has no effect.
examples:
- id: EX-1
  given: plumb's band holds the session
  when: the session starts
  then: the agent still receives the brief as text
- id: EX-2
  given: a turn ends with stale links, untraced files and a warning
  when: the stop hook runs
  then: the agent's channel names them; the owner's text is at most one plumb line
- id: EX-3
  given: the full/compact/off setting is set
  when: a turn ends
  then: the setting has no effect and plumb tells the agent once that it is retired
- id: EX-4
  given: a merge conflict on a requirement
  when: the agent lists the conflicts
  then: it still gets the conflict id it needs to propose a resolution, while the owner's question about
    it shows no id
- id: EX-5
  given: the same turn on Codex, which has no band
  when: the stop hook runs
  then: the agent gets the same text as on Claude Code
- id: EX-6
  given: a stale link whose evidence says a test passed earlier and fails now
  when: plumb hands it to the agent
  then: its evidence line is given as text, as before
proof:
  plan: 'Recommended for the owner to decide: the AI shows the hook output of one turn ending with a stale
    link and a warning, side by side: the agent''s channel text naming both with their ids, and the owner''s
    view holding one plumb line; the same run with the band up shows the agent text unchanged.'
  kind: hook
