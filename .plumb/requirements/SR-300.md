---
id: SR-300
title: The agent runs the debug cases at its next turn
feature: FEAT-008
statement: 'The debug cases a landing job writes are given to the agent as text at its next turn, with
  the instruction to run them as a workflow on Sonnet: repin a stale link after its tests pass, relink
  when the code moved, rerun or fix a failing test, rerun a failed judge job, and card the owner only
  when a link''s meaning changed. The plumb line says how many cases are open and how many were resolved;
  a case it cannot resolve follows SR-220 and SR-221. Nothing runs while no session is open.'
examples:
- id: EX-1
  given: a landing left 3 debug cases
  when: the agent's next turn starts
  then: the agent is told the 3 cases and to run them as a workflow on Sonnet, and the owner is asked
    nothing
- id: EX-2
  given: a stale link whose tests pass
  when: the debug workflow handles it
  then: it is repinned and the plumb line counts one case resolved
- id: EX-3
  given: a stale link whose requirement no longer describes the code
  when: the debug workflow handles it
  then: the owner gets one question through the question tool about the behaviour, not about the link
- id: EX-4
  given: no session is open after a landing
  when: the cases are written
  then: nothing runs until the next session
proof:
  plan: After this work's landing, the next turn runs the cases and the status card ends with nothing
    stale, nothing waiting and no error.
  kind: live-session
