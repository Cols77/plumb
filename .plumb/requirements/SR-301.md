---
id: SR-301
title: A landing job never disturbs another intent loop
feature: FEAT-006
statement: 'The landing job writes only main''s tree and log: it never changes another branch or worktree,
  another session''s loop file or gate, or a card of a branch not merged; it keeps any document or record
  another in-flight branch changed until that branch lands; its repins and compaction merge into an in-flight
  branch without conflict.'
examples:
- id: EX-1
  given: a loop open in another worktree with its gate closed and two cards
  when: a different branch lands on main
  then: that worktree's gate, loop file and cards are unchanged
- id: EX-2
  given: a superseded document that an in-flight branch changed
  when: the tidy runs at another landing
  then: the document stays until that branch lands
- id: EX-3
  given: the landing repinned links and compacted the log
  when: an in-flight branch later merges main
  then: git merges with no conflict and plumb validate is clean
proof:
  plan: 'This work''s landing with the hand clean-up''s worktree still present: its files, loop and gate
    are unchanged afterwards.'
  kind: command
