---
id: SR-302
title: A session can take over an intent loop from another session
feature: FEAT-006
statement: A plumb command lets the agent of a new session take over an open intent loop of another session,
  in the same checkout or the main checkout from a worktree; the loop's stages, gates passed and tasks
  carry over, the old session's copy is marked handed over and its edit gate released.
examples:
- id: EX-1
  given: a loop with clarify passed in session A
  when: session B takes it over
  then: B's intent status shows clarify passed and the plan gate open, and A's copy says handed over
- id: EX-2
  given: a loop opened from the main checkout
  when: a session in a worktree takes it over
  then: the gates run from the worktree
- id: EX-3
  given: no open loop matches
  when: the take-over is asked
  then: it says so and changes nothing
proof:
  plan: A loop opened in one session is taken over in another and its next gate passes there.
  kind: command
