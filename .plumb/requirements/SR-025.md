---
id: SR-025
title: plumb init adopts any repository in one idempotent command
feature: FEAT-001
statement: plumb init creates .plumb/ (record directories, config.yaml, claims.yaml, .gitignore, .gitattributes
  and empty logs) in any repository, and running it again changes nothing.
examples:
- id: EX-1
  given: a git repository without .plumb/
  when: plumb init runs
  then: it creates the record directories, config, claims, ignore and attributes files and empty logs
- id: EX-2
  given: an initialized repository
  when: plumb init runs again
  then: it reports already initialized and changes nothing
