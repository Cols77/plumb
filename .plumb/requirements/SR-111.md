id: SR-111
title: Drift is caught at the edit that causes it and resolved before the...
statement: 'Right after an edit, plumb tells the agent which links that edit made stale (from the hash
  cache, within the edit hook''s budget), including the records derived from a record the edit reworded.
  Before the turn can end, the agent resolves each one: it reruns the linked tests and repins when a model
  judges the meaning unchanged (INT-029), or rewords the dependent record so it agrees, or, when what
  the owner intended is in question, brings it to the owner as a card. The end-of-turn hook keeps the
  turn open while a link this turn made stale is unresolved, and says which. Links stale before the turn
  are listed to the agent once, not blocking.'
examples:
- id: EX-1
  given: the agent edits a function that SR-005's implemented_by link pins
  when: the edit hook runs
  then: the agent is told that SR-005's link to that file is stale, in one line, within the hook budget
- id: EX-2
  given: INT-016 is reworded through plumb capture and SR-032 derives from it
  when: the capture finishes
  then: the agent is told SR-032 may no longer agree with INT-016
- id: EX-3
  given: a link this turn made stale and not yet resolved
  when: the agent tries to end its turn
  then: the end-of-turn hook keeps the turn open and names the link
- id: EX-4
  given: the edit only reformatted the file and its linked tests pass
  when: the agent resolves the link
  then: it is repinned without involving the owner
- id: EX-5
  given: the edit changes what a requirement the owner confirmed says the system does
  when: the agent resolves the link
  then: the owner gets a card naming the requirement, the change and the suggested resolutions, and the
    turn may end with the card waiting
- id: EX-6
  given: an edit to src/plumb/commands.py that adds a new command and leaves the repin command SR-003
    describes as it was
  when: the agent resolves SR-003's stale link to that file
  then: the model (Sonnet by default) is shown SR-003's statement and examples next to the diff, answers
    that what SR-003 relies on is unchanged, and the link is repinned with its one-sentence reason in
    the repin note
- id: EX-7
  given: a change that removes the tests checking SR-005's relayed-approval examples
  when: the agent resolves those links
  then: each is refused with the model's reason naming the examples no longer checked, and stays stale
    for a reword or a card
- id: EX-8
  given: the model answers that the change alters what the requirement relies on, cannot be reached, or
    the diff is too large to judge
  when: the agent resolves the link
  then: nothing is repinned and the refusal says why; the model's self-reported confidence is not used
    (it is not calibrated)
- id: EX-9
  given: the agent wants to know what would be repinned
  when: it runs plumb repin --after-tests --dry-run <ID>
  then: the model's verdicts are listed with their reasons, no test runs and no pin changes
