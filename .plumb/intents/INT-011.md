id: INT-011
title: JEV as an optional judgment backend
quote: what about JEV development work? I think it might be usefull to integrate it in this new version
  too?
readback: JEV is a judgment backend for the background loop (intent-change detection, drift triage and
  a cheap scoped fidelity score), handing off to an LLM when its confidence is low. When the configured
  judge (JEV or a judge model) is missing or unreachable, plumb says so and raises an error; no rule-based
  judge stands in for it (INT-029).
will:
- Offer a judgment interface with a JEV adapter and judge models, each raising an error when unreachable.
- Hand low-confidence judgments to the host agent (the cascade).
wont:
- Fall back to a rule-based (heuristic) judge when a model is missing or unreachable.
assumptions:
- Parts of plumb that need no judgment keep working without JEV; only judging raises the error.
mode: incremental
