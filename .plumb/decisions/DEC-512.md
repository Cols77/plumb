question: What does a row of the loops class hold, and where is a loop's full detail read?
chosen: The expanded row holds the loop's main details (its steps with gate marks and findings left, the
  task done of total and what is left, what it waits for, its branch); the records it wrote and each proof
  are read in the loop's own window, which the row's action brings to the front or opens
alternatives:
- The expanded row holds everything the old loop pane showed, records and proofs included
- The row holds only goal, progress, done, left, waits and branch, as every other loop
rationale: the owner's answer to the judge's question on 2026-11-08; the pane keeps one row shape and
  the loop's own window keeps the long lists
matters: true
quote: What I know is that we don't want to loose the access to loop's main details. Of course if the
  user wants full detail it can simply open the loop in a new window. Also btw it is not necessarily a
  new window, if the loop is already opened in some window, plumb should put it in the foreground of the
  computer (if possible)
