id: DEC-025
title: A button press is proven by a secret only the panel holds
question: How does plumb know a Confirm press came from the owner and not the agent?
chosen: At session start the panel makes a random secret and keeps it in memory; plumb learns only enough
  to recognise it, never the secret itself; the first panel to register in a session wins; a press sends
  the secret with what was pressed; the agent's shell is not allowed to run the button steps.
alternatives:
- Ask the owner again in a terminal.
- Trust any call that says it came from a button.
rationale: Simple and quick; an agent cannot press by accident, and a deliberate bypass shows up, as plumb's
  trust model already states.
