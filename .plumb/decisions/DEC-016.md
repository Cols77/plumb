id: DEC-016
title: Auto-approval is on only through the owner's logged config event
question: What turns auto-approval on, given that the agent can edit .plumb/config.yaml?
chosen: The latest config event written by plumb config auto-approve in the owner's terminal (no session
  marker); config.yaml is a mirror, and a yaml saying on without that event is off with a validate warning.
alternatives:
- The config.yaml key alone.
- A deny rule on editing config.yaml.
rationale: R8 says the command is owner-terminal only and logged in the event log; the agent cannot write
  that event on the normal path, while it could edit the yaml.
