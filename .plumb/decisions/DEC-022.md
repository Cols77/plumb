title: On an ID collision the branch merged into keeps its IDs
question: Which record keeps the ID when two clones created the same one?
chosen: the first parent (the branch merged into) keeps its IDs and the incoming record is renumbered
alternatives:
- the older record keeps its ID
- the owner picks each time
rationale: Deterministic and mechanical; renumbering changes no intent, so it needs no owner question.
