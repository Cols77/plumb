id: DEC-020
title: An intent conflict lives inside the conflicted record
question: Where is an intent conflict recorded?
chosen: inside the conflicted record file, as a conflict block with an IC-### ID
alternatives:
- a separate .plumb/conflicts/IC-###.md record file
rationale: git runs a merge driver while it holds the index lock, so the driver can write only its own
  output file; a separate file would not enter the merge commit. One file keeps both versions with the
  record and keeps the record unconfirmed.
