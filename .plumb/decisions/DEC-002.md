title: Guard by deny rules and the session marker
question: How is plumb approve kept from the agent?
chosen: Declarative permissions.deny rules in .claude/settings.json plus the CLI session-marker check.
alternatives:
- A PreToolUse hook on every shell call (concept 4.6).
rationale: A Python hook on every shell call costs about 250 ms each; ten calls would break the 2-second
  per-turn budget. Deny rules cost nothing and are inspectable.
matters: true
