question: Who runs the covering tests each turn?
chosen: The stop hook blocks once per turn asking the agent to run plumb tests run --changed; the hook
  never runs pytest itself.

- The stop hook runs the tests itself.
- The stop hook asks for plumb verify (concept 6.4).
rationale: Hooks stay under 2 s while the covering tests still run every coding turn within verify.turn_budget_s.
