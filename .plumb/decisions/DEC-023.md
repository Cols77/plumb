id: DEC-023
title: The plugin carries a ready-built plumb and sets up a private copy of its tools
question: How does the plugin get its own plumb, independent of the project it runs in?
chosen: The plugin carries a ready-built copy of plumb, checked to match plumb's source; on first use
  it sets up a private copy of plumb's tools per user and per plugin version; git's checks call one stable
  plumb launcher in the user's own folder.
alternatives:
- Make the whole plumb repository the plugin and run plumb straight from its source.
- Download plumb from its repository when the plugin is installed.
rationale: Works offline and from any plugin list; the installed plugin stays small; plumb never uses
  the project's own setup.
