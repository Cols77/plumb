question: When the plumb plugin is reinstalled mid-session, what should plumb do while the new version's
  private copy is not ready?
chosen: Keep running checks on the previous version's copy until the new one is ready; a check that still
  cannot run writes one line to .plumb/session/errors.log, in adopted projects only
alternatives:
- Only log the checks that could not run; answers in the window are lost
- Keep checks silent and write nothing; restarting the session is the cure
