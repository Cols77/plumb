title: When is a message delivered to a session that is waiting at its...
question: When is a message delivered to a session that is waiting at its prompt?
chosen: 'At once: the waiting session''s own band starts its turn so it reads the message, whoever sent
  it; where that session runs no band it reads it at its next turn, the row saying sent, not read yet
  until then'
alternatives:
- At once only when the sender is an agent that Claude Code lets wake the target; otherwise at the target's
  next turn
- Always wait for the target's next turn
- Refuse a message to a waiting session
rationale: 'Changed at the plan step on 2026-11-06. The first choice assumed a plugin could not make a
  waiting session start a turn; the plan found that the session''s own band can. A message that waits
  until the owner goes to that session and types there does not let them steer a loop from the list, which
  is what they asked for. The cost: a waiting session spends a turn on each message sent to it.'
matters: false
recommended: At once when the sender is an agent that Claude Code lets wake the target; otherwise at the
  target's next turn, the row saying sent, not read yet until then
