# Glossary

- band: the owner's status line in Claude Code; it shows the loop's step, the current task and what awaits them.
- room: the owner's browser workspace (`plumb ui`) for reading studies, records and evidence; only the owner opens it.
- loop pane: the part of the band that names the open intent loop's current task and the plan items not built yet.
- stale link: a link from a record to code or a test whose pinned content has changed since it was pinned.
- repin: pin a stale link to the current content, once its tests pass.
- relink: move a link from a superseded record to the record that replaces it, with a note.
- reword: put one of the judge's questions into the owner's terms (`question reword`) before asking it.
- intent conflict: a new intent that contradicts a confirmed record, or the same intent in flight on another branch.
