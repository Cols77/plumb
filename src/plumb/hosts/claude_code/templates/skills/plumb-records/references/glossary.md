# Glossary

- band: the owner's status line in Claude Code: the loop's step, the task, what awaits them.
- room: the owner's browser workspace (`plumb ui`) for studies, records, evidence; owner only.
- loop pane: the band's part naming the open intent loop's task and the plan items not built.
- stale link: a record's link to code or a test whose content changed since it was pinned.
- repin: pin a stale link to the current content, once its tests pass.
- relink: move a link from a superseded record to the record that replaces it, with a note.
- reword: put a judge question in the owner's terms (`question reword`) before asking it.
- intent conflict: a new intent against a confirmed record, or in flight on another branch.
